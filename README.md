# miniapps

Разработка мини-приложений ВКонтакте.

## Приложения

| Приложение | Что делает |
|---|---|
| [`apps/vk-audit`](apps/vk-audit/README.md) | мини-приложение: аудит страницы ВК — метрики, зоны роста, план на 4 недели, сравнение с конкурентами. Считает без сервера, прямо в браузере |
| [`apps/vk-bot`](apps/vk-bot/README.md) | бот сообщества: присылает разборы в личные сообщения раз в неделю или в месяц. Текст пишет DeepSeek, цифры — тот же движок |

Как пользоваться и как запустить:

- **[КАК-ПОЛЬЗОВАТЬСЯ.md](КАК-ПОЛЬЗОВАТЬСЯ.md)** — пошаговый разбор по экранам, на примере личной страницы
- **[С-ТЕЛЕФОНА.md](С-ТЕЛЕФОНА.md)** — только браузер телефона, ничего скачивать не нужно
- **[КАК-ЗАПУСТИТЬ.md](КАК-ЗАПУСТИТЬ.md)** — с компьютера, без терминала: архив и хостинг
- **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)** — полностью: свой домен, бот, обслуживание

Материалы для запуска и продвижения — в отдельной папке
**[`АВТОРУ/`](АВТОРУ/README.md)**: план раскатки и монетизации, готовые
посты, сторис, тексты для карточки в каталоге, анкеты обратной связи.
