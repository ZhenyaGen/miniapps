# Как запустить с телефона

Ничего скачивать и распаковывать не нужно. Всё делается в браузере телефона
за три захода: подключить сборку → получить адрес → вписать его во ВКонтакте.

Понадобится: аккаунт GitHub (у вас уже есть) и 15 минут.

---

## Какую площадку выбрать

Все три делают одно и то же: берут код из репозитория, собирают и выдают
адрес. Разница — в том, что они спрашивают при регистрации.

| Площадка | Что спросит | Когда брать |
|---|---|---|
| **Cloudflare Pages** | почту | **если Vercel требует телефон** — здесь его нет |
| **Netlify** | вход через GitHub | тоже без телефона, настройки уже в репозитории |
| **Vercel** | иногда телефон | если подтверждение прошло |

> **Vercel пишет «The verification phone number has been temporarily
> blocked»?** Это их защита от накруток, к приложению отношения не имеет.
> Ждать 12 часов не нужно — берите Cloudflare Pages или Netlify ниже,
> результат тот же.

---

## Заход 1, вариант А · Cloudflare Pages (телефон не нужен)

1. Откройте **[dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)**,
   зарегистрируйтесь по почте и подтвердите её
2. Слева **Workers & Pages** → **Create** → вкладка **Pages** →
   **Connect to Git**
3. Разрешите доступ к GitHub, выберите репозиторий **miniapps**
4. Заполните четыре поля:

   | Поле | Значение |
   |---|---|
   | Production branch | `claude/vk-mini-apps-knowledge-base-kos6be` |
   | Framework preset | `Vite` |
   | Build command | `npm run build` |
   | Build output directory | `dist` |

5. Разверните **Root directory (advanced)** и впишите `apps/vk-audit`
6. **Save and Deploy**

Через пару минут получите адрес вида `https://miniapps-xyz.pages.dev`.

---

## Заход 1, вариант Б · Netlify (вход через GitHub)

1. Откройте **[app.netlify.com](https://app.netlify.com)** →
   **Sign up** → **GitHub**
2. **Add new site** → **Import an existing project** → **GitHub** →
   репозиторий **miniapps**
3. **Branch to deploy** → `claude/vk-mini-apps-knowledge-base-kos6be`
4. Остальное менять не нужно: в корне репозитория лежит `netlify.toml`,
   из него Netlify возьмёт и папку сборки, и команду
5. **Deploy**

Адрес будет вида `https://имя-сайта.netlify.app`.

## Заход 1, вариант В · Vercel

Vercel сам возьмёт код из репозитория, соберёт его и выдаст адрес.
И будет пересобирать сам при каждом изменении.

1. Откройте в браузере телефона **[vercel.com](https://vercel.com)**
2. **Sign Up** → **Continue with GitHub** → разрешите доступ
3. **Add New…** → **Project**
4. В списке репозиториев найдите **miniapps** → **Import**

   > Если репозитория нет в списке — нажмите **Adjust GitHub App Permissions**
   > и дайте доступ к нему.

5. Откроется экран настроек. Нужно поменять **одно** поле:

   | Поле | Значение |
   |---|---|
   | **Root Directory** | нажмите **Edit** и выберите `apps/vk-audit` |

   Остальное Vercel определит сам (Framework: Vite, сборка, папка `dist`) —
   в репозитории для этого лежит файл настроек.

6. **Deploy** и подождите 1–2 минуты.

Когда закончится, Vercel покажет адрес вида:

```
https://miniapps-xxxx.vercel.app
```

Нажмите на него — должен открыться экран «Аудит страницы ВК».
Проверьте кнопкой **«Открыть демо-отчёт»**: если отчёт показался — сборка
рабочая.

> Кнопка «Войти» на этом адресе работать не будет — это нормально.
> Вход возможен, только когда приложение открывает сам ВКонтакте (заход 3).

### Если Vercel собрал не ту ветку

Работа лежит в ветке `claude/vk-mini-apps-knowledge-base-kos6be`, а Vercel
по умолчанию берёт `main`. Если после сборки открывается пустая страница
или старая версия:

**Settings** → **Git** → **Production Branch** → вписать
`claude/vk-mini-apps-knowledge-base-kos6be` → **Save** →
вкладка **Deployments** → у верхней сборки меню **⋯** → **Redeploy**.

## Заход 2. Скопировать адрес

На странице проекта адрес показан крупно сверху — у любой из трёх площадок.
Нажмите на него и скопируйте целиком, вместе с `https://`.

Должно получиться что-то вроде:

```
https://miniapps-abc123.vercel.app
```

---

## Заход 3. Вписать адрес во ВКонтакте (5 минут)

1. Откройте в браузере телефона **[dev.vk.ru](https://dev.vk.ru/)**
2. Войдите своей страницей ВК
3. **Мои приложения** → приложение **54693601**
4. **Настройки** и заполните три поля:

   | Поле | Что вписать |
   |---|---|
   | Адрес приложения | адрес из захода 2 |
   | Адрес для мобильных | тот же адрес |
   | Доверенный redirect URI | `http://localhost:8910/callback` |

5. **Сохранить**

> Третье поле нужно не мини-приложению, а десктопной версии — чтобы она
> работала на этом же приложении ВК. Впишите сразу, чтобы потом не возвращаться.

---

## Готово. Открыть

В браузере телефона или в приложении ВКонтакте:

```
https://vk.com/app54693601
```

Нажмите **«Войти»** → ВК спросит разрешение на доступ к сообществам
и статистике → появится список ваших сообществ.

Нажимаете сообщество — через полминуты готов отчёт: сводка, зоны роста,
план на 4 недели, контент и конкуренты.

## Что делать, если

**«Приложение недоступно» или пустая рамка в ВК.**
Адрес в настройках не совпадает с тем, что выдал Vercel. Проверьте, что
скопировали целиком, с `https://` и без пробела в конце.

**Открывается страница «Файл открыт напрямую с диска».**
Это сообщение появляется, только если открыть файл с диска. Значит в поле
адреса попало что-то не то — вернитесь к заходу 2.

**Кнопка «Войти» ничего не делает.**
Вы открыли приложение по адресу Vercel, а не через `vk.com/app54693601`.
Вход работает только внутри ВКонтакте.

**Vercel пишет `Error: No Output Directory named "dist"`.**
Не поменяли **Root Directory** на `apps/vk-audit`.
**Settings** → **General** → **Root Directory** → исправить → **Redeploy**.

**Vercel требует подтверждение по телефону, номер заблокирован.**
Возьмите Cloudflare Pages (вариант А) — там регистрация по почте.
Приложение и настройки те же, разницы в результате нет.

**Cloudflare пишет, что не нашёл `package.json`.**
Не заполнено **Root directory** — оно спрятано под ссылкой
**(advanced)** на экране настройки сборки. Впишите `apps/vk-audit`.

**Сборка падает на тестах.**
Так и задумано: тесты сверяют расчёт с десктопной версией, и упавший тест
означает, что цифры разошлись. Напишите мне — разберусь.

**Хочу обновить приложение после изменений.**
Ничего делать не нужно: площадка пересоберёт сама при каждом изменении
в ветке. Адрес останется прежним.

**Совсем ничего не выходит, нужен адрес прямо сейчас.**
Скачайте архив `vk-audit-app.zip` из переписки, откройте
[app.netlify.com/drop](https://app.netlify.com/drop) и загрузите **сам архив**
(кнопка выбора файла работает и на телефоне). Регистрация не нужна вовсе,
адрес выдаётся сразу. Минус один: при следующих правках архив придётся
загружать заново.
