# Общее описание

**Раздел:** VK ID Captcha → Web → Общее описание  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

[VK ID Captcha](https://dev.vk.ru/ru/vkcaptcha/overview) поставляется как отдельный SDK. В веб-браузере капча отображается через  `iframe` в виде всплывающего окна или блока.

Для работы с капчей используются методы API ВКонтакте и VK ID Captcha SDK Web.

Перед началом работы  интегрируйте VK ID Captcha SDK Web с помощью [обработчика](https://dev.vk.ru/ru/vkcaptcha/web/autointegration). Обработчик ошибки капчи встраивается в API, автоматически проверяет наличие ошибки капчи и отображает капчу при наличии ошибки. Подробнее – в [сценарии взаимодействия](https://dev.vk.ru/ru/vkcaptcha/web/scenario) с VK ID Captcha SDK Web.
