## Общее описание

Капча позволяет определить, кем является пользователь системы: человеком или компьютером. Капча отображается в виде всплывающего окна или блока.

VK ID Captcha поставляется как отдельный SDK.

VK ID Captcha SDK содержит интерфейсы и классы для взаимодействия с капчей и обеспечивает:

- Отображение капчи.
- Взаимодействие с методами [VK Bridge](https://dev.vk.ru/ru/bridge/overview).
- Отправку callback-уведомлений с результатом прохождения капчи.

Подробнее о подключении для разных платформ — в инструкциях:

- [Веб](https://dev.vk.ru/ru/vkcaptcha/web/autointegration)
- [iOS](https://dev.vk.ru/ru/vkcaptcha/iOS/integration)
- [Android](https://dev.vk.ru/ru/vkcaptcha/Android/integration)
