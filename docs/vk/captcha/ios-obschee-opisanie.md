# Общее описание

**Раздел:** VK Captcha → iOS → Общее описание  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

[VK ID Captcha](https://dev.vk.ru/ru/vkcaptcha/overview) поставляется как отдельный SDK. В iOS-приложении капча отображается через  `WebView` в виде всплывающего окна.

Для работы с капчей используются методы API ВКонтакте и VK ID Captcha SDK iOS.

Перед началом работы [интегрируйте](https://dev.vk.ru/ru/vkcaptcha/iOS/integration) VK ID Captcha SDK iOS.
