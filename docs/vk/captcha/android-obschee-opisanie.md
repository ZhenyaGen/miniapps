# Общее описание

**Раздел:** VK Captcha → Android → Общее описание  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

[VK ID Captcha](https://dev.vk.ru/ru/vkcaptcha/overview) поставляется как отдельный SDK. В Android-приложении капча отображается через  `WebView` в виде всплывающего окна.

Для работы с капчей используются методы API ВКонтакте и VK ID Captcha SDK Android.

Перед началом работы [интегрируйте](https://dev.vk.ru/ru/vkcaptcha/Android/integration) VK ID Captcha SDK Android.
