# Общее описание

**Раздел:** VK Pay → Платёжное окно → Общее описание  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Платёжное окно VK Pay — это всплывающее окно, в котором указана сумма платежа, способ оплаты, комментарий к платежу и данные продавца.

Платёжное окно отображается внутри интерфейса ВКонтакте.

В этом разделе описано подключение платёжного окна для разработчиков мини-приложений и порядок оплаты через платёжное окно для пользователей ВКонтакте.

## Платёжное окно для плательщиков

В платёжном окне для пользователя будут отображаться способы оплаты, которые вы указали при [подключении](https://dev.vk.ru/ru/pay/connection).

Доступные способы оплаты: банковская карта и VK Кошелёк.

Подробнее о процессе оплаты для пользователя читайте в разделе [Платёжное окно для](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-users) [плательщиков](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-users).

## Платёжное окно для разработчиков

Если вы разрабатываете мини-приложение, вы можете вызвать платёжное окно в своём приложении с помощью событий [библиотеки VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9A%D0%B0%D0%BA%20%D0%B8%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D1%8C%20%D0%B1%D0%B8%D0%B1%D0%BB%D0%B8%D0%BE%D1%82%D0%B5%D0%BA%D1%83%20VK%20Bridge).

VK Bridge позволяет мини-приложениям взаимодействовать с API ВКонтакте и API операционной системы, установленной на устройстве пользователя.

Для вызова платёжного окна потребуется инициализировать своё приложение, отправить запрос для вызова платёжного окна с параметрами продавца и [мини-приложения](https://dev.vk.ru/ru/mini-apps/getting-started#%D0%9E%20%D0%BC%D0%B8%D0%BD%D0%B8-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%D1%85), проверить результат вызова и получить платёжное уведомление о результате оплаты.

Подробности — в [сценарии взаимодействия](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers#%D0%A1%D1%86%D0%B5%D0%BD%D0%B0%D1%80%D0%B8%D0%B9%20%D0%B2%D0%B7%D0%B0%D0%B8%D0%BC%D0%BE%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D1%8F%20%D1%81%20%D0%BF%D0%BB%D0%B0%D1%82%D1%91%D0%B6%D0%BD%D1%8B%D0%BC%20%D0%BE%D0%BA%D0%BD%D0%BE%D0%BC) и [пошаговом руководстве по вызову платёжного окна](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/payment-create).

Вы можете [протестировать](https://dev.vk.ru/ru/pay/payment-form-for-developers/payment-form/testing) работу платёжного окна перед проведением настоящих платежей.

Чтобы делать отмену и возврат платежей, запрашивать статус транзакции и информацию о ней, используйте [API-запросы к платёжной системе](https://dev.vk.ru/ru/pay/seller/general-description).

## Отправка сообщений плательщику

ВКонтакте удобно общаться с вашими клиентами через сообщения сообществ. Например, присылать подробные данные и статус заказа, уточнять информацию о доставке или реагировать на обратную связь. Узнать подробнее о том, как их использовать, вы можете в [документации](https://dev.vk.ru/ru/api/community-messages/getting-started).

Если вы принимаете оплату через VK Pay внутри ВКонтакте (в сервисе VK Mini Apps или в приложении сообщества), после платежа от имени пользователя в ваше сообщество отправляется сообщение с данными платежа. Это даёт вашему сообществу автоматическое разрешение на отправку ответных сообщений пользователю — вам не нужно отдельно запрашивать у него права.

Важно! Отправка данных платежа работает только после добавления вашего приложения в каталог VK Mini Apps или VK Pay. Нужно учитывать это при тестировании — если вы общаетесь с

пользователем в сообщениях сообщества, до размещения в каталоге вам необходимо запрашивать права для отправки ему первого сообщения или написать в сообщения группы от имени этого пользователя.
