# Тестирование платёжного окна

**Раздел:** VK Pay → Платёжное окно → Для разработчиков → Тестирование платёжного окна  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Вы можете протестировать работу [платёжного окна](https://dev.vk.ru/ru/pay/payment-form/general-description). Для этого убедитесь, что всё готово, проверьте работу платежей с тестовыми данными, а затем — с боевыми.

При тестировании всё происходит как при настоящих платежах, но деньги никуда не переводятся.

Если вы хотите протестировать работу [API платёжной системы](https://dev.vk.ru/ru/pay/seller/general-description), напишите в техническую поддержку по адресу `vkpay_solutions@vk.team`.

## Ограничения

1. Протестировать можно только платежи банковской картой.

2. При тестировании нужно использовать тестовую банковскую карту с тестовой валютой платежа — реквизиты можно получить у технической поддержки.

## Подготовка к тестированию

Перед тестированием проверьте, что выполнили все пункты.

1. Создали приложение ВКонтакте.

2. [Подключили VK Pay](https://dev.vk.ru/ru/pay/connection).

3. [Подключили платёжные уведомления](https://dev.vk.ru/ru/pay/seller/notifications).

4. Получили от технической поддержки идентификатор продавца, реквизиты тестовой банковской карты и ключи доступа для тестирования: приватный ключ для формирования подписи запроса и публичный ключ для проверки подписи ответа.

5. [Интегрировали платёжное окно](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers).

## После тестирования

1. Запросите у технической поддержки ключи доступа для работы в боевой среде: приватный ключ для формирования подписи запроса и публичный ключ для проверки подписи ответа.

2. [Проверьте работу платёжного окна](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers) в боевой среде.
