# Общее описание

**Раздел:** VK Pay → API платёжной системы → Общее описание  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

С помощью API платёжной системы (далее — API системы) вы можете:

- [Получать уведомления](https://dev.vk.ru/ru/pay/seller/notifications).
- [Узнавать о статусе транзакции](https://dev.vk.ru/ru/pay/seller/transaction-status).
- [Запрашивать информацию о транзакции](https://dev.vk.ru/ru/pay/seller/transaction-get).
- [Делать отмену и возврат платежей](https://dev.vk.ru/ru/pay/seller/refunds).

Формат данных и синтаксис запросов отличаются от [API ВКонтакте](https://dev.vk.ru/ru/api/overview). Протокол взаимодействия — HTTPS с использованием шифрования не ниже TLS 1.2.

API системы поддерживает [`POST`](https://dev.vk.ru/ru/pay/seller/request-create) [-запросы](https://dev.vk.ru/ru/pay/seller/request-create). Ответ от платёжной системы возвращается в [формате](https://dev.vk.ru/ru/pay/seller/response) [JSON](https://dev.vk.ru/ru/pay/seller/response).

Авторизация не используется. Вместо этого каждый запрос и ответ сопровождается подписью данных, что позволяет обнаружить возможную подмену.

## URL для запросов

```
https://api.money.mail.ru/money/2-03/{ваш-api-запрос}
```

## Как подключить

1. Чтобы зарегистрировать новый аккаунт продавца, напишите в техническую поддержку по адресу `vkpay_solutions@vk.team`.

2. После регистрации получите от технической поддержки идентификатор продавца, приватный ключ доступа для формирования подписи запроса и публичный ключ для проверки подписи ответа. Эти данные понадобятся для всех взаимодействий с API системы.

3. Чтобы подключить [платёжные уведомления](https://dev.vk.ru/ru/pay/seller/notifications), сообщите технической поддержке URL-адрес, по которому вы хотите их получать. Можно указать сразу несколько адресов.

4. Протестируйте работу API системы: [отправьте запрос](https://dev.vk.ru/ru/pay/seller/request-create), получите ответ и обработайте его в зависимости от результата запроса ([успех](https://dev.vk.ru/ru/pay/seller/response#%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B7%D0%B0%D0%B3%D0%BE%D0%BB%D0%BE%D0%B2%D0%BA%D0%B0%20header%20%D0%BF%D1%80%D0%B8%20%D1%83%D1%81%D0%BF%D0%B5%D1%88%D0%BD%D0%BE%D0%B9%20%D0%BE%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B5%20%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D0%B0) или [неуспех](https://dev.vk.ru/ru/pay/seller/response#%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B7%D0%B0%D0%B3%D0%BE%D0%BB%D0%BE%D0%B2%D0%BA%D0%B0%20header%20%D0%BF%D1%80%D0%B8%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B5%20%D0%BE%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B8%20%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D0%B0)), получите платёжное уведомление и [ответьте на него](https://dev.vk.ru/ru/pay/seller/notifications#%D0%A8%D0%B0%D0%B3%204.%20%D0%9E%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D1%8C%D1%82%D0%B5%20%D0%BE%D1%82%D0%B2%D0%B5%D1%82%20%D0%BD%D0%B0%20%D1%83%D0%B2%D0%B5%D0%B4%D0%BE%D0%BC%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5).
