# Обработка ошибок

**Раздел:** VK Pay → Платёжное окно → Для разработчиков → Обработка ошибок  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Если при вызове платёжного окна некорректно передан один из параметров, в консоли браузера отобразится ошибка.

| Ошибка | Описание | Рекомендации |
|---|---|---|
| `Bad sign` В параметре `params.sign` передано некорректное значение [подписи приложения](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/app-sign-calculation). | 1. Проверьте защищённый ключ | приложения `app secure key`. 2. Проверьте, что строка для подписи, которая формируется на стороне VK Pay, и строка на серверной стороне вашего приложения совпадают. Если вы проводите платёж с тестовыми учётными данными, в консоли браузера в описании ошибки вы можете увидеть, как должна выглядеть строка для подписи приложения перед конкатенацией с защищённым ключом приложения |

`app secure key`.
3. Проверьте, чтобы браузер не экранировал двойные кавычки при формировании подписи.
4. Попробуйте [сформировать](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/app-sign-calculation) [подпись](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/app-sign-calculation) ещё раз.

| `Параметры запроса и` `параметры партнёра` `отличаются` | В объекте `params.data` передано некорректное значение подписи продавца | Проверьте приватный ключ продавца |
|---|---|---|

`merchant_private_key` и попробуйте [сформировать подпись](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/merchant-sign-calculation) ещё раз.

`merchant_sign`.

| `Invalid parameter:` `ts` | В объекте `params.data` передано некорректное значение временной метки формирования запроса `ts`. | Проверьте значение `ts`: оно должно быть меньше времени отправки запроса на отображение платёжного окна, но не более чем на час. Отправьте запрос с корректным значением `ts`. |
|---|---|---|
| `Invalid parameter:` `cashback` | В объекте | Проверьте параметры и отправьте запрос ещё раз. |
| `params.data.cashback` | передано некорректное | значение параметров кешбэка. |
| `Invalid_parameter:` `amount` | В параметре `params.amount` отсутствует или передано некорректное значение суммы платежа. | Проверьте значение `amount` и отправьте запрос ещё раз. |

| Ошибка | Описание | Рекомендации |
|---|---|---|
| `Не удалось найти` `получателя по` `заданным параметрам` | В параметре | Проверьте значение идентификатора |
| `params.merchant_id` некорректно указан ваш идентификатор продавца, который был выдан при подключении к системе VK Pay. | `merchant_id` и отправьте запрос | ещё раз. |
