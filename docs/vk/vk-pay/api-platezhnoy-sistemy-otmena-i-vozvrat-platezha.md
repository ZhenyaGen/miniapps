# Отмена и возврат платежа

**Раздел:** VK Pay → API платёжной системы → Отмена и возврат платежа  
**Источник:** документация VK для разработчиков (dev.vk.com)

## Как сделать отмену или возврат платежа

С помощью [API платёжной системы](https://dev.vk.ru/ru/pay/seller/general-description) (далее — API системы) вы можете сделать отмену, возврат или частичный возврат платежа — подробнее в разделе Условия отмены и возврата платежей.

Полный и частичный возврат доступны для способов оплаты: банковская карта и VK Кошелёк.

Если вы хотите вернуть платёж, [подключитесь к платёжной системе](https://dev.vk.ru/ru/pay/seller/general-description#%D0%9A%D0%B0%D0%BA%20%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C) и отправьте запрос для возврата денег методом `POST` `/transaction/refund`.

## Условия отмены и возврата платежей

Возвраты и отмены проводит оператор платёжной системы — РНКО «ВК Платёжные решения» (далее — оператор).

### Чем отличаются отмена и возврат платежа

| Отмена | Возврат |
|---|---|
| Ограничение по времени проведения операции. | До 23:00:00 по московскому времени того же дня, когда был проведён платёж. | С 23:00:00 по московскому времени того же дня, когда был проведён платёж. Вернуть деньги можно в течение 365 дней с момента проведения платежа. |
| Запись в [реестре](https://money.mail.ru/help/regreestr) [успешных платежей и](https://money.mail.ru/help/regreestr) [возвратов](https://money.mail.ru/help/regreestr). | Нет Да |
| Частичный возврат платежа. | Нет Да |
| Возврат комиссии за платёж. | Да Нет |

Подробнее об условиях отмены и возвратов можно прочитать в [п. 4.6 Условий оказания платёжных](https://money.mail.ru/img/partners/dmr_pay_serv.pdf) [услуг](https://money.mail.ru/img/partners/dmr_pay_serv.pdf).

### Отмена платежа

Отмена — это отмена платежа до 23:00:00 по московскому времени того же дня, когда он был проведён.

В этом случае операции платежа и отмены не попадают в [реестр успешных платежей и возвратов](https://money.mail.ru/help/regreestr). Частично отменить платёж нельзя — вернуть средства можно только полностью. При отмене платежа оператор возвращает комиссию за проведённый платёж.

Например, покупатель заплатил за товар 100 ₽. Эта сумма включает 3 ₽ комиссии, которую магазин платит оператору за услуги. При отмене платежа оператор вернёт покупателю всю сумму вместе с

комиссией — 100 ₽.

Важно! Чтобы подключить возврат комиссии при отмене платежа, напишите в техническую поддержку по адресу `vkpay_solutions@vk.team`.

### Возврат платежа

Возврат — это отмена платежа после 23:00:00 по московскому времени того же дня, когда он был проведён.

В этом случае операции платежа и возврата попадают в [реестр успешных платежей и возвратов](https://money.mail.ru/help/regreestr). При возврате платежа вернуть средства можно как частично, так и полностью. Комиссия при возврате и частичном возврате не возвращается. Возврат возможен в течение 365 дней с момента проведения платежа.

Например, покупатель заплатил за товар 100 ₽. Эта сумма включает 3 ₽ комиссии, которую магазин платит оператору за услуги. При возврате оператор оставит 3 ₽ комиссии себе, а 97 ₽ вернёт покупателю. Магазину нужно будет доплатить 3 ₽, чтобы покупатель получил обратно 100 ₽.

## Как вернуть платёж

1. Отправьте запрос на возврат.

2. Получите ответ и [платёжное уведомление о результате проведения транзакции](https://dev.vk.ru/ru/pay/seller/notifications).

3. Ответьте на уведомление: сформируйте тело ответа с информацией об успехе или неуспехе обработки уведомления, подпишите ответ и отправьте его платёжной системе.

### Шаг 1. Отправьте запрос на возврат

[Сформируйте](https://dev.vk.ru/ru/pay/seller/request-create) `POST` -запрос к API системы, [подпишите его](https://dev.vk.ru/ru/pay/seller/request-create/request-sign-creating) и отправьте его по URL:

`https://api.money.mail.ru/money/2-03/transaction/refund`.

В запросе передайте обязательный параметр `transaction_id` — идентификатор транзакции. Параметр `amount` — опциональный:

- Если вы хотите вернуть платёж целиком, параметр `amount` можно не передавать. По умолчанию сумма платежа вернётся полностью.
- Если вы хотите вернуть платёж частично, в запросе укажите сумму `amount` и валюту платежа

`currency`. В этом случае вернётся та сумма, которую вы указали, за вычетом комиссии.

### Шаг 2. Получите ответ платёжной системы

В ответ на запрос платёжная система вернёт ответ со статусом транзакции в поле `action.status` и платёжное уведомление. [Проверьте подпись ответа](https://dev.vk.ru/ru/pay/seller/response/sign), обработайте данные и ответьте на уведомление.

Параметры поля `body` ответа на запрос возврата платежа

| Параметр | Тип | Описание |
|---|---|---|
| `transaction_id` | `string` | Идентификатор транзакции возврата. Формат: UUID по [RFC 4122](https://datatracker.ietf.org/doc/html/rfc4122). |

`action` `string` Статус проведения возврата:
- `wait` — транзакция не завершена, запрашивайте статус транзакции с разумным интервалом запросом

[`transaction/status`](https://dev.vk.ru/ru/pay/seller/transaction-status), пока статус не перейдёт в `stop`.
- `stop` — статус транзакции окончательный, значение содержится в `action_param`.

`action_param` `object` При `action`  =  `stop` платёжная система вернёт дополнительные параметры для `action`: статус транзакции и признак отмены платежа. При `action`  =  `wait` вернётся пустое значение.

Параметры объекта `action_param`

Дополнительные параметры для сценария `action`, возвращаются в теле ответа на запрос о возврате платежа.

**Параметр | Тип | Описание**

`status` `string` Уточнение статуса транзакции для `action = stop`. Возможные значения `status`:
- `success` – транзакция успешна.
- `fail` — транзакция неуспешна.

`is_reverse` `boolean` Признак того, что проведённая транзакция — это отмена платежа:
- `true` – проведена отмена платежа.
- `fail` — проведён возврат.

### Шаг 3. Ответьте на платёжное уведомление

После проведения транзакции платёжная cистема вернёт [уведомление](https://dev.vk.ru/ru/pay/seller/notifications) с результатом транзакции.

[Проверьте подпись уведомления](https://dev.vk.ru/ru/pay/seller/notifications#%D0%A8%D0%B0%D0%B3%202.%20%D0%9F%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D1%8C%D1%82%D0%B5%20%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D1%83%D0%B2%D0%B5%D0%B4%D0%BE%D0%BC%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F) с помощью публичного ключа платёжной системы, который вы получили при подключении. Затем расшифруйте данные уведомления, обработайте и отправьте API системы ответ с результатом обработки. Подробнее — в [ответе на платёжное уведомление](https://dev.vk.ru/ru/pay/seller/notifications#%D0%A8%D0%B0%D0%B3%204.%20%D0%9E%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D1%8C%D1%82%D0%B5%20%D0%BE%D1%82%D0%B2%D0%B5%D1%82%20%D0%BD%D0%B0%20%D1%83%D0%B2%D0%B5%D0%B4%D0%BE%D0%BC%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5).

## Ошибки при возврате платежа

| Ошибка | Описание |
|---|---|
| `ERR_ACCESS_DENIED` | Нельзя сделать возврат по чужой транзакции. Проверьте |
| `transaction_id` | и повторите запрос. |
| `ERR_ALREADY_REFUNDED` | Платёж уже полностью возвращён. |
| `ERR_AMOUNT_GREATER_THAN_ALLOWED` | Запрошенная сумма возврата больше, чем сумма платежа. |
| `ERR_CONFIG` | Ошибка конфигурации — обратитесь в техническую поддержку по адресу `vkpay_solutions@vk.team`. |
| `ERR_CURRENCY_MISMATCH` | Валюта возврата отличается от валюты платежа. Укажите ту же валюту, с которой был проведён платёж, и повторите запрос. |
| `ERR_NOMONEY` | Недостаточно средств для возврата запрошенной суммы. |
| `ERR_PARTIAL_REFUND_DENIED` | Частичный возврат запрещён. |
| `ERR_PAY_METHOD_DISABLED` | Платёжный метод отключен или недоступен — обратитесь в техническую поддержку по адресу |

`vkpay_solutions@vk.team`.

`ERR_PAYER_AWAITING_FOR_CLOSING` Операция невозможна: VK Кошелёк получателя ожидает закрытия.

`ERR_PAYER_BANNED` Операция невозможна: получатель платежа заблокирован.

`ERR_PAYER_CLOSED` Операция невозможна: VK Кошелёк получателя закрыт.

`ERR_PAYER_PWD_BANNED` Операция невозможна: получатель платежа заблокирован.

`ERR_PAYER_UNVERIFIED` Операция невозможна: получатель платежа не прошёл идентификацию.

`ERR_RATE_LIMIT` Превышено максимально допустимое количество возвратов по одной транзакции: по умолчанию — один возврат в 15 минут. Попробуйте повторить запрос позже.

`ERR_REFUND_FAILED` Проведение возврата закончилось с ошибкой. Попробуйте повторить запрос ещё раз.

`ERR_REFUND_TTL` Транзакция не может быть возвращена: истекло время, когда можно вернуть платёж. Сделать возврат можно в течение 365 дней с даты проведения платежа.

| Ошибка | Описание |
|---|---|
| `ERR_TRANSACTION_NOT_FOUND` | Транзакция не найдена. Проверьте `transaction_id` и повторите запрос. |
| `ERR_WALLET_LIMIT` | Операция невозможна: превышены лимиты по переводам через VK Кошелёк. |
| `ERR_WRONG_TRANSACTION_STATUS` | Операция невозможна: некорректный статус транзакции. |
