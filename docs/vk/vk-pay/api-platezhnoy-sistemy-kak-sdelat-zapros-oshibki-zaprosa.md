# Ошибки запроса

**Раздел:** VK Pay → API платёжной системы → Как сделать запрос → Ошибки запроса  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

В случае [ошибки запроса](https://dev.vk.ru/ru/pay/seller/response#%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B7%D0%B0%D0%B3%D0%BE%D0%BB%D0%BE%D0%B2%D0%BA%D0%B0%20header%20%D0%BF%D1%80%D0%B8%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B5%20%D0%BE%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B8%20%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D0%B0) к API платёжной системы в ответе вернётся код и описание ошибки.

| Код | Описание |
|---|---|
| `ERR_SIGNATURE` | Некорректная подпись запроса. [Сформируйте подпись заново](https://dev.vk.ru/ru/pay/seller/request-create/request-sign-creating) и повторите запрос. |
| `ERR_ARGUMENTS` | Некорректные параметры запроса. При получении этой ошибки поле |
| `error.message` | будет содержать JSON-список в виде пары `ключ:значение`, где `ключ` – название некорректно переданного параметра в XPath-формате, `значение` – описание ошибки для этого параметра. |
| `ERR_NOAUTH` | Переданный в запросе `client_id` не найден. Проверьте данные и повторите запрос. |
| `ERR_ACCESS_DENIED` | Доступ запрещён — обратитесь в техническую поддержку по адресу |

`vkpay_solutions@vk.team`.

`ERR_IP_ACCESS_DENIED` Запрещены запросы с этого IP-адреса.

`ERR_BUSY` Система занята. Пожалуйста, повторите запрос позже.

`ERR_SYSTEM` Системная ошибка, повторите запрос позже. Если ошибка повторяется, обратитесь в техническую поддержку по адресу

`vkpay_solutions@vk.team`.
