# Другие площадки

**Раздел:** VK Games → Панель управления → Настройки → Другие площадки  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Другие площадки (настройки игр)

В разделе Другие площадки вы можете привязать профиль разработчика из других социальных сетей VK, например из [Одноклассников](https://ok.ru), чтобы настроить там публикацию вашей игры.

Для публикации игры также понадобится пройти модерацию. Подробнее — в разделе [Модерация (настройки игр)](https://dev.vk.ru/ru/games/settings/moderation).

#### Чтобы открыть настройки других площадок:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Настройки → Другие площадки.

## Доступ

Настраивать другие площадки может создатель игры.

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Привязать OK ID

Чтобы игру можно было опубликовать в Одноклассниках, вам понадобится профиль в этой социальной сети.

Если у вас уже есть профиль в Одноклассниках, свяжите его с игрой в VK Mini Apps:

1. Нажмите Привязать OK ID.

2. Если вы ещё не авторизовались в Одноклассниках, появится диалоговое окно для входа. Заполните поля и нажмите Войти.

## • Если вы подключаете игру к Одноклассникам впервые, на экране появится диалоговое окно с соглашением о предоставлении вам [прав разработчика](https://ok.ru/devaccess). Прочитайте соглашение и нажмите Получить права разработчика. • Если вы уже подключали любую игру к Одноклассникам и получили права разработчика, вы увидите сообщение: «Права разработчика выданы». Чтобы подключить вашу игру, нажмите Подтвердить.

3. Идентификатор подключённого профиля разработчика из Одноклассников отобразится в разделе Другие площадки.

В течение 15 минут VK Mini Apps создаст игру в Одноклассниках. Пока не пройдена модерация, игру в Одноклассниках сможет запустить только её создатель. Подробнее — в разделе [Публикация в](https://dev.vk.ru/ru/ok/publishing#%D0%A8%D0%B0%D0%B3%203.%20%D0%9F%D1%80%D0%BE%D1%82%D0%B5%D1%81%D1%82%D0%B8%D1%80%D1%83%D0%B9%D1%82%D0%B5%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5) [Одноклассниках](https://dev.vk.ru/ru/ok/publishing#%D0%A8%D0%B0%D0%B3%203.%20%D0%9F%D1%80%D0%BE%D1%82%D0%B5%D1%81%D1%82%D0%B8%D1%80%D1%83%D0%B9%D1%82%D0%B5%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5).
