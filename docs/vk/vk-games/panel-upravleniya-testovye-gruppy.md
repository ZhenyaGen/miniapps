# Тестовые группы

**Раздел:** VK Games → Панель управления → Тестовые группы  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Тестовые группы (настройки игр)

С помощью тестовых групп можно проверить новую функциональность на ограниченной аудитории или продемонстрировать изменения в игре друзьям и коллегам.

В процессе разработки игры вы можете публиковать её версии на разных адресах:

- Адрес для запуска официальной версии игры, которая доступна всем пользователям. Подробнее — в разделе [Настройки → Размещение](https://dev.vk.ru/ru/games/settings/general/placement).
- Адрес для тестирования версии игры, доступной только участникам тестовой группы.

Уникальный адрес версии игры работает вне зависимости от способа запуска: из каталога, по прямой ссылке или из панели управления.

#### Чтобы открыть настройки тестовых групп:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Тестовые группы.

## Доступ

Настраивать тестовые группы может:

- Создатель игры.
- Администратор с полным доступом.

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Ограничения

- Максимальное количество тестовых групп для одной игры — 25.
- В тестовую группу можно добавить только пользователей ВКонтакте.
- Пользователь может находиться только в одной тестовой группе игры.
- Одновременно можно добавить только 100 пользователей.

Даже если часть пользователей добавляется из списка, а часть — через поиск, их общее количество не должно превышать 100.
- Всего в группе может быть не более 1 000 пользователей.

## Работа с группами

### Создать группу

Нажмите Создать группу и укажите параметры:

1. Введите название группы — любой текст не более 48 символов.

2. Укажите URL для загрузки игры. ВКонтакте будет открывать именно этот URL, когда пользователи из группы будут запускать игру.

Чтобы передать параметры, укажите их в URL после символа `?`, например `https://my-` `game.com/new-design/start?param1=value1`.

URL тестовой группы имеет приоритет над всеми другими адресами загрузки, включая URL режима разработки. Например: пользователь — администратор игры, и для этой игры включён режим разработки в разделе [Размещение](https://dev.vk.ru/ru/games/settings/general/placement). Для запуска игры будет использоваться URL режима разработки. Если этот же пользователь включён в какую-либо тестовую группу, при запуске игры будет использован адрес, указанный в тестовой группе.

3. Выберите платформы ВКонтакте, на которых будет использоваться URL. Для создания группы укажите хотя бы одну платформу.

### Добавить участников

#### В интерфейсе

По умолчанию в списке отображаются все ваши друзья. Чтобы добавить пользователей в тестовую группу, поставьте галочки напротив их имён.

Чтобы найти пользователя в списке, введите в строке поиска:

- Имя или его часть, например `Пинг`, `Пингви` или `Пинг Пингвин`.
- Идентификатор аккаунта, например `id743784486`.
- Адрес страницы пользователя, например `https://vk.com/id743784486` или

`https://vk.com/ping_pingvin`.

Чтобы добавить в тестовую группу только администраторов, используйте переключатель справа от списка.

#### Из списка

Если вы часто создаёте тестовые группы для проверки различных изменений в игре, можете подготовить списки с идентификаторами пользователей, сохранить их в файлах и копировать идентификаторы из этих списков.

1. Создайте список в любом текстовом редакторе.

Список должен включать только номера идентификаторов (без префикса `id`) по одному в каждой строке.

#### Пример списка

```
743784474
743784479
743784486
743784490
```

2. В панели управления игрой начните создавать новую группу, затем в меню справа нажмите Загрузить список ID.

3. Введите идентификаторы пользователей либо нажмите Загрузить CSV и выберите подготовленный файл.

Одновременно можно добавить 100 пользователей. Подробнее — в разделе Ограничения.

### Посмотреть добавленных участников

Используйте переключатель Показывать в списке → Выбранных.

### Удалить участников

Найдите пользователя в списке и снимите галочку рядом с его именем.
