# Ключи доступа

**Раздел:** VK Games → Панель управления → Разработка → Ключи доступа  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Ключи доступа (настройки игр)

В этом разделе вы можете просмотреть и обновить ключи доступа, необходимые для работы с игрой. Значения ключей генерируются автоматически при создании игры.

#### Чтобы открыть раздел

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Разработка → Ключи доступа.

## Доступ

Редактировать ключи доступа может:

- Создатель игры.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Защищённый ключ

Библиотеки ВКонтакте могут использовать защищённый ключ на стороне пользователя для различных целей. Например, для [проверки подписи параметров запуска](https://dev.vk.ru/ru/games/development/parameters-sign) или для [проверки](https://dev.vk.ru/ru/mini-apps/development/protect-with-signature) [подлинности данных](https://dev.vk.ru/ru/mini-apps/development/protect-with-signature).

## Сервисный ключ

[Сервисный ключ](https://dev.vk.ru/ru/api/access-token/getting-started) используется для отправки запросов API ВКонтакте из серверной части игры, например запросов группы [secure](https://dev.vk.ru/ru/method/secure).

Важно! Не передавайте и не используйте сервисный ключ в коде на стороне пользователя. Это небезопасно. Работайте с сервисным ключом доступа только в серверной части игры.

## Публичный ключ

Публичный ключ используется совместно с защищённым ключом для взаимодействия с методами [API Одноклассников](https://apiok.ru/dev/methods/rest/) от имени приложения. Ключ отобразится после того, как игра будет подключена к Одноклассникам в разделе [Другие площадки](https://dev.vk.ru/ru/games/settings/general/other-sites).

Подробнее об использовании ключа – в разделе [Вызовы API на стороне сервера](https://dev.vk.ru/ru/ok/development/api#%D0%92%D1%8B%D0%B7%D0%BE%D0%B2%D1%8B%20API%20%D0%BD%D0%B0%20%D1%81%D1%82%D0%BE%D1%80%D0%BE%D0%BD%D0%B5%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%B0).

## Работа с ключами

### Скопировать ключ

Чтобы скопировать ключ, нажмите Показать → Просмотреть и затем подтвердите действие предложенным способом.

### Изменить ключ

Чтобы обновить значение ключа, нажмите Создать новый → Сменить и затем подтвердите действие предложенным способом.

После создания нового старый ключ восстановить невозможно. Обновите значение ключа в коде вашей игры.
