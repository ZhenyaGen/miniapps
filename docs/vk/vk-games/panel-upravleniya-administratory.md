# Администраторы

**Раздел:** VK Games → Панель управления → Администраторы  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Администраторы (настройки игр)

Администраторы — пользователи, авторизованные на [единой платформе](https://dev.vk.com/ru/admin/apps-list) по VK ID, которые занимаются разработкой, тестированием и поддержкой работы игры. Они могут, например, менять настройки игры, запускать её, когда она отключена для остальных пользователей, проверять работу платежей.

В разделе Администраторы вы можете просматривать список администраторов и работать с ним: добавлять новых пользователей, изменять настройки у существующих, передавать доступ.

#### Чтобы открыть настройки администраторов:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Администраторы.

## Доступ

Редактировать список администраторов может:

- Создатель игры.
- Администратор с полным доступом.

Для администраторов с частичным доступом раздел недоступен. Вместо него они видят другой раздел — [Доступ к приложению](https://dev.vk.ru/ru/games/settings/access-to-app).

## Виды администраторов

Всеми правами на игру обладает пользователь с правами создателя. Остальные администраторы могут иметь полный или частичный доступ к настройкам игры.

### Создатель

Создатель — это главный администратор игры. Он обладает доступом ко всем настройкам. Только он может:

- Выводить средства, полученные за показы рекламы или продажу товаров.
- Публиковать игру на [других площадках](https://dev.vk.ru/ru/games/settings/general/other-sites).
- Удалить игру с платформы.

Управлять списком администраторов может не только создатель, но и администратор с полным доступом.

В списке администраторов может быть только один пользователь с правами создателя. Изначально это пользователь, который зарегистрировал игру на платформе VK Mini Apps.

### Администратор с полным доступом

У администраторов этого типа есть доступ к настройкам игры, но они не обладают исключительными правами создателя.

У администраторов с полным доступом есть права на все разделы настроек, которые присутствуют в частичном доступе. Кроме того, администратор с полным доступом может:

- Редактировать список администраторов (но не может переназначить создателя).
- Редактировать [список тестировщиков](https://dev.vk.ru/ru/games/settings/test-groups).
- Подавать [заявку на размещение в каталоге](https://dev.vk.ru/ru/games/settings/moderation).
- Тестировать игру до прохождения модерации на всех подключённых площадках.
- Обращаться в Поддержку.

### Администратор с частичным доступом

Права администратора с частичным доступом складываются из одного или нескольких прав, которые им выдал создатель или администратор с полным доступом.

## Редактирование списка администраторов

Добавлять новых администраторов, изменять их права или удалять может создатель либо администратор с полным доступом.

Создателю доступны все операции над списком. Администраторам с полным доступом — все действия над другими администраторами, кроме создателя.

### Добавить администратора

## • Для добавления нового администратора нажмите Добавить и укажите ссылку на его страницу ВКонтакте. Подойдёт как обычная ссылка вида `https://vk.com/id743784474`, так и ссылка с [никнеймом](https://vk.com/faq18038).

- После того как вы подтвердите добавление администратора, платформа отправит ему приглашение. Пользователь станет администратором только после того, как примет приглашение.

Пользователи, которые пока не приняли приглашение, отображаются в списке администраторов, но администраторами не являются.

### Удалить администратора

Удалить администраторов из списка могут создатель или администратор с полным доступом. Для этого нажмите иконку с мусорной корзиной напротив нужного администратора.

Удалить создателя из списка администраторов нельзя. Если создатель хочет выйти из администрирования, он должен передать свои права кому-либо из администраторов с полным доступом и затем отказаться от администрирования самостоятельно либо попросить нового создателя об удалении.

## Передать права создателя

Создатель может передать права администратору с полным доступом. Для этого в разделе Администраторы нужно нажать Передать доступ и выбрать из списка одного из администраторов с полным доступом.

Выбранный администратор должен принять приглашение и подтвердить переход прав к нему. До этого момента исключительные права остаются за текущим создателем.

После подтверждения перехода прав создатель становится администратором с полным доступом.

#### Важно!

- Если для игры настроена [интеграция с Одноклассниками](https://dev.vk.ru/ru/ok/publishing#%D0%A8%D0%B0%D0%B3%202.%20%D0%9F%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D0%B5%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%BA%20%D0%9E%D0%B4%D0%BD%D0%BE%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%BD%D0%B8%D0%BA%D0%B0%D0%BC), создателем можно назначить только пользователя, который имеет права разработчика на платформе Одноклассники. Подробнее — в разделе [Администрирование приложений](https://dev.vk.ru/ru/ok/administrators#%D0%A1%D0%B2%D1%8F%D0%B7%D0%B0%D1%82%D1%8C%20%D0%B0%D0%BA%D0%BA%D0%B0%D1%83%D0%BD%D1%82%D1%8B%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D0%B0%20VK%20ID%20%D0%B8%20OK%20ID).
- Если в приложении подключена монетизация, при передаче прав создателя укажите актуального исполнителя в кабинете выплат, чтобы продолжить зарабатывать на подключённых инструментах и выводить средства. Подробнее — в разделе [Вывод средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).

## Выход из администрирования

Администраторы с полным и частичным доступом могут отказаться от администрирования самостоятельно. Чтобы сделать это, просто нажмите Отказаться от доступа напротив своего имени в списке администраторов.

Администраторы с полным доступом видят эту кнопку в разделе Администрирование. Администраторам с частичным доступом кнопка доступна в разделе [Доступ к приложению](https://dev.vk.ru/ru/games/settings/access-to-app).

Создатель игры выйти из администрирования не может. Сначала он должен передать свои права кому-либо из администраторов с полным доступом.
