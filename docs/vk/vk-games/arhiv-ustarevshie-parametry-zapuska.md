# Устаревшие параметры запуска

**Раздел:** VK Games → Архив → Устаревшие параметры запуска  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Параметры запуска

Параметры, перечисленные в этом разделе, устарели. Перейдите на страницу с обновлённой документацией:

► [Параметры запуска](https://dev.vk.ru/ru/games/development/parameters)

При старте игры ВКонтакте передаёт ей дополнительные параметры, содержащие данные о пользователе и источнике запуска. Значения передаются как URL-параметры на [указанный в](https://dev.vk.ru/ru/games/getting-started#%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20URL%20%D0%B4%D0%BB%D1%8F%20%D0%B7%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B8%20%D0%B8%D0%B3%D1%80%D1%8B) [настройках игры адрес](https://dev.vk.ru/ru/games/getting-started#%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20URL%20%D0%B4%D0%BB%D1%8F%20%D0%B7%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B8%20%D0%B8%D0%B3%D1%80%D1%8B).

Чтобы получить параметры запуска в коде игры на стороне пользователя, используйте свойство

`href` объекта `window.location`.

## Параметры

**Параметр | Тип | Описание**

`access_token` `string` Ключ доступа для отправки API-запросов. Подробнее — в разделе [API — Ключ доступа — Общие сведения](https://dev.vk.ru/ru/api/access-token/getting-started).

`access_token_settings` `string` Список прав доступа пользователя, который запустил игру. Каждое значение в списке соответствует области данных пользователя, к которой можно получить доступ. Значения в списке разделены запятыми, например

`friends,stories,wall`. Список используемых строковых констант приведён в разделе [Права доступа](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0).

Значение параметра `access_token_settings` аналогично значению `api_setting`, но использует другой тип данных.

`ads_app_id` `string` Для служебного использования.

`api_id` `integer` Идентификатор запущенной игры. Вы можете найти его в [настройках вашей игры](https://dev.vk.ru/ru/games/getting-started#%D0%A1%D0%BA%D0%BE%D0%BF%D0%B8%D1%80%D1%83%D0%B9%D1%82%D0%B5%20%D0%B8%D0%B4%D0%B5%D0%BD%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%BE%D1%80%20%D0%B8%D0%B3%D1%80%D1%8B).

`api_result` `string` Результат первого запроса к API, который выполняется при загрузке игры. Содержимое запроса вы можете указать в настройках игры (раздел Настройки → Запрос прав → Первый запрос к API).

`api_settings` `integer` Целое число, которое является битовой маской прав доступа пользователя, запустившего игру. Маска формируется так же, как и [маски прав доступа для API-](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) [запросов](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0).

Значение параметра `api_settings` аналогично

**Параметр | Тип | Описание**

значению `access_token_settings`, но использует другой тип данных.

`api_url` `string` URL сервиса API ВКонтакте, которому необходимо отправлять API-запросы.

`auth_key` `string` Значение, которое использовалось ранее для проверки подмены параметров `api_id` и `viewer_id`.

Важно! Параметр `auth_key` будет упразднён. Вместо него для проверки подмены используйте параметр `sign`.

ВКонтакте пока что продолжает передавать `auth_key` играм при старте для обратной совместимости.

`group_id` `integer` Идентификатор сообщества, если игра была запущена со страницы сообщества. Если игра была запущена не из сообщества, то параметр равен `0` либо не передаётся.

`group_whitelist_scope` `string` Для служебного использования.

`hash` `string` Данные, переданные игре в URL после символа `#`. Такие параметры могут быть переданы при запуске игры [по](https://dev.vk.ru/ru/games/access/#%D0%9A%D0%B0%D0%BA%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D1%82%D0%B8%D1%82%D1%8C%20%D0%B8%D0%B3%D1%80%D1%83%20%D0%BF%D0%BE%20%D0%BF%D1%80%D1%8F%D0%BC%D0%BE%D0%B9%20%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B5) [прямой ссылке](https://dev.vk.ru/ru/games/access/#%D0%9A%D0%B0%D0%BA%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D1%82%D0%B8%D1%82%D1%8C%20%D0%B8%D0%B3%D1%80%D1%83%20%D0%BF%D0%BE%20%D0%BF%D1%80%D1%8F%D0%BC%D0%BE%D0%B9%20%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B5).

Параметр `hash` является последним в списке передаваемых URL-параметров. Все символы после него
— это символы, указанные после `#` в прямой ссылке.

`is_app_user` `integer` `1`, если пользователь установил игру, иначе — `0`.

`is_favorite` `integer` `1`, если пользователь добавил игру в левое меню ВКонтакте и запускает её из левого меню, иначе —  `0`.

`is_play_machine` `integer` `1`, если игра была запущена через [Play Machine](https://dev.vk.ru/ru/games/faq#%D0%9F%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%B8%D0%B2%D0%B0%D1%8E%D1%82%D1%81%D1%8F%20%D0%BB%D0%B8%20Flash-%D0%B8%D0%B3%D1%80%D1%8B?) (специальное приложение для запуска Flash-игр). В ином случае параметр равен `0` или не передаётся.

`is_secure` `integer` `1`, если используется защищённое соединение, иначе — `0`.

`is_widescreen` `integer` `1`, если игра запущена в [широкоформатном режиме](https://dev.vk.ru/ru/games/settings/general/display#%D0%A8%D0%B8%D1%80%D0%BE%D0%BA%D0%BE%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%82%D0%BD%D1%8B%D0%B9%20%D1%80%D0%B5%D0%B6%D0%B8%D0%BC), иначе — `0`.

Параметр используется только для [Web-игр](https://dev.vk.ru/ru/games/getting-started#Direct%20Games%20%D0%B8%20Web-%D0%B8%D0%B3%D1%80%D1%8B).

`language` `integer` Идентификатор языка пользователя, просматривающего приложение. Возможные значения — те же, что используются в [API-запросах](https://dev.vk.ru/ru/api/api-requests#%D0%9E%D0%B1%D1%89%D0%B8%D0%B5%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B).

| Параметр | Тип | Описание |
|---|---|---|
| `lc_name` | `string` | Для служебного использования. |

`odr_enabled` `integer` Используется на iOS. `1` означает, что игра поддерживает [технологию On-Demand Resources (ODR)](https://dev.vk.ru/ru/games/direct-games/on-demand-resources). Если игра не поддерживает эту технологию, то параметр не передаётся.

`parent_language` `integer` Идентификатор языка, которым можно заменить язык пользователя (возвращается для неофициальных языковых версий). Возможные значения — те же, что используются в [API-запросах](https://dev.vk.ru/ru/api/api-requests#%D0%9E%D0%B1%D1%89%D0%B8%D0%B5%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B).

`platform` `string` Идентификатор платформы, на которой запускается игра. Возможно одно из следующих значений:
- `html5_ios` — мобильное приложение ВКонтакте для iOS.
- `html5_android` — мобильное приложение ВКонтакте для Android.
- `html5_mobile` — мобильная версия сайта ВКонтакте.
- `web` — десктопная версия сайта ВКонтакте.

`ref_notification_id` `integer` Используется при старте игры из сообщения рассылки. Указывает идентификатор рассылки.

Если рассылка была выполнена с помощью API-запроса

[`secure.sendNotification`](https://dev.vk.ru/ru/method/secure.sendNotification), значение параметра совпадает с параметром `notification_id` этого запроса.

Если рассылка была создана в настройках игры, параметр содержит идентификатор подписки, сгенерированный ВКонтакте.

Идентификаторы рассылок разных типов могут совпадать, поэтому при анализе значений проверяйте и параметр `ref_notification_type`.

`ref_notification_type` `string` Используется при старте игры из сообщения рассылки. Указывает тип рассылки. Возможно одно из следующих значений:
- `auto` — массовая рассылка, созданная в настройках игры.
- `custom` — рассылка выполнена с помощью API- запроса [`secure.sendNotification`](https://dev.vk.ru/ru/method/secure.sendNotification) [.](https://dev.vk.ru/ru/method/secure.sendNotification)
- `trigger` — автоматическое уведомление, созданное в настройках игры.

`referrer` `string` Обозначение источника перехода в игру. Возможные значения — те же, что используются в [API-запросах](https://dev.vk.ru/ru/api/app-run-parameters#referrer).

**Параметр | Тип | Описание**

`request_key` `string` Используется при старте игры из [запроса о помощи](https://dev.vk.ru/ru/games/promotion/game-mechanics/requests) или [приглашения](https://dev.vk.ru/ru/games/promotion/game-mechanics/invites) друга. Указывает ключ запроса или приглашения. Это то же самое значение, которое было передано в параметре `requestKey` при вызове события

[`VKWebAppShowRequestBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowRequestBox) или [`VKWebAppShowInviteBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowInviteBox) библиотеки [VK Bridge](https://dev.vk.ru/ru/bridge/overview).

Используйте это значение в игре, чтобы предусмотреть сценарий, соответствующий запросу или приглашению, а также для отслеживания конверсии.

`secret` `string` Для служебного использования.

`sid` `string` Для служебного использования.

`sign` `string` base64-строка — подпись параметров запуска. Используется для обнаружения подмены параметров третьими лицами. Подробнее — в разделе Подпись параметров.

`sign_keys` `string` Список имён параметров, которые необходимы для вычисления подписи в параметре `sign`.

Имена параметров в списке разделены запятой.

`stats_hash` `string` Для служебного использования.

`timestamp` `integer` Время создания подписи в параметре `sign`. Это время представлено в Unix-формате — целое число, обозначающее количество миллисекунд, прошедших с 00:00:00 1 января 1970 года.

`user_id` `integer` Идентификатор пользователя, со страницы которого игра была запущена. Если игра стартовала не со страницы пользователя, то параметр равен `0`.

`viewer_id` `integer` Идентификатор пользователя, который запустил игру.

`viewer_type` `integer` Тип пользователя, который запустил игру.

Если пользователь `viewer_id` запускает игру со страницы сообщества, то есть если `group_id` не равен

`0`, то значение `viewer_type` может быть следующим:
- `0` — пользователь не состоит в сообществе.
- `1` — пользователь — участник сообщества.
- `2` — пользователь — модератор сообщества.
- `3` — пользователь — редактор сообщества.
- `4` — пользователь — создатель или администратор сообщества.

**Параметр | Тип | Описание**

Если пользователь запускает игру не со страницы сообщества, то есть если `user_id` не равен `0`, а

`group_id` равен `0`, то `viewer_type` может иметь одно из следующих значений:
- `1` — пользователь `viewer_id` находится в друзьях у пользователя `user_id`.
- `2` — пользователь `viewer_id` — администратор игры либо запустил игру со своей страницы.
- `0` или параметр не указан — остальные случаи. `0` используется, например, когда игру запускает любой пользователь по прямой ссылке.

`whitelist_scopes` `string` Для служебного использования.

## Подпись параметров

### Что такое подпись

Игры ВКонтакте используют подпись параметров, чтобы защититься от подмены значений и возможной утечки данных.

1. При запуске игры ВКонтакте вычисляет подпись с помощью [защищённого ключа доступа](https://dev.vk.ru/ru/games/settings/development/keys#%D0%97%D0%B0%D1%89%D0%B8%D1%89%D1%91%D0%BD%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BB%D1%8E%D1%87) из настроек игры. Этот ключ известен авторам игры, но неизвестен третьим лицам.

Полученное значение передаётся игре в параметре `sign`.

2. Игра при старте может вычислить подпись по такому же алгоритму и сравнить это значение с переданным `sign`.

Разница будет означать подмену.

Ранее для такой проверки использовался параметр `auth_key`, но он защищал только от подмены значений `api_id` и `viewer_id`.

### Как вычислить подпись

Для вычисления подписи используются параметры, имена которых переданы в `sign_keys`. Чтобы получить подпись, выполните следующие шаги:

1. Извлеките параметры, перечисленные в `sign_keys`, и объедините пары `параметр=значение` в одну строку в том же порядке, в котором они следуют в `sign_keys`. Используйте амперсанд ( `&`) в качестве разделителя.

Обратите внимание, что строковые значения должны быть в URL-кодировке. Например, запятые должны быть представлены как `%2C`, пробелы — как `%20`.

2. Для получившейся строки вычислите хеш-код, используя алгоритм SHA256 с методом HMAС. При расчётах используйте защищённый ключ из настроек вашей игры (раздел Настройки, поле Защищённый ключ).

3. Результирующее значение закодируйте в base64-строку.

Получившаяся строка должна совпадать с переданной в параметре `sign`.

## Примеры проверки подписи

### PHP

```php
<?php
```

```
$client_secret = 'xxxxx';
```

```
$url = (isset($_SERVER['HTTPS']) && $_SERVER['HTTPS'] === 'on' ? "https" :
"http") . "://$_SERVER[HTTP_HOST]$_SERVER[REQUEST_URI]";
```

```
// Получаем параметры из URL
$query_params = [];
$parsed = parse_url($url, PHP_URL_QUERY);
parse_str($parsed, $query_params);
```

```
$sign_params = [];
$sign_keys = explode(',', $query_params['sign_keys']);
foreach ($sign_keys as $key) {
  $sign_params[$key] = $query_params[$key];
}
```

```
// Формируем строку вида "param1=value1&param2=value2"
$sign_params_query = http_build_query($sign_params);
```

```
// Вычисляем подпись, используя защищённый ключ приложения
$sign = rtrim(strtr(base64_encode(hash_hmac('sha256', $sign_params_query,
$client_secret, true)), '+/', '-_'), '=');
```

```
// Сравниваем полученную подпись со значением параметра sign
$sign_status = $sign === $query_params['sign'];
```

```
echo 'status: ' . ($sign_status ? 'ok' : 'fail')."\n";
```

```
?>
```

### JavaScript (Node.js)

```js
const qs = require('querystring');
const crypto = require('crypto');
```

```
// Получаем параметры из URL
const urlParams = qs.parse(URL_PARAMS);
const signKeys = new URLSearchParams(URL_PARAMS)
    .get('sign_keys')
    .split(',');
```

```
const ordered = {};
```

```
signKeys.forEach(key => ordered[key] = urlParams[key]);
```

```
// Формируем строку вида "param1=value1&param2=value2"
const stringParams = qs.stringify(ordered);
```

```
// Вычисляем подпись, используя защищённый ключ приложения
const paramsHash = crypto
    .createHmac('sha256', secretKey)
    .update(stringParams)
    .digest()
    .toString('base64')
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=$/, '');
```

```
// Сравниваем полученную подпись со значением параметра sign
if (paramsHash == urlParams.sign) {
    console.log("Подпись верна.");
} else {
    console.log("Подпись невалидна, возможна подмена параметров.");
}
```

## Передача произвольных параметров

При необходимости вы можете передавать произвольные параметры в игру.

#### Запуск по прямой ссылке

При запуске игры по прямой ссылке укажите параметры после символа `#` в адресной строке, например:

```
https://vk.com/app1234567#param1=12345
```

Символы после `#` будут переданы игре в URL-параметре `hash`. Этот параметр всегда идёт последним среди остальных передаваемых параметров. Все символы после него являются символами, которые были указаны после `#` в URL игры.

Получить параметры можно и с помощью свойства `hash` объекта `window.location`. Для отслеживания изменений этого значения в игре используйте события [`VKWebAppLocationChanged`](https://dev.vk.ru/ru/bridge/VKWebAppLocationChanged) и [`VKWebAppChangeFragment`](https://dev.vk.ru/ru/bridge/VKWebAppChangeFragment) библиотеки [VK Bridge](https://dev.vk.ru/ru/bridge/overview).

Использование знака вопроса ( `?`) для передачи параметров при запуске по прямой ссылке не работает.

#### Параметры запуска в настройках игры

Чтобы указать параметры запуска в настройках игры, добавьте в URL знак вопроса и параметры, например:

```
https://my-game.example.com/start-page?param1=12345
```

Получить эти параметры вы можете так же, как и обычные параметры веб-страниц, например с помощью свойства `window.location.search`.

Использовать символы `#` в URL-адресах, которые указываются в настройках игры, нельзя.
