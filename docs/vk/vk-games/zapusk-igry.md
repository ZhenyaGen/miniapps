# Запуск игры

**Раздел:** VK Games → Запуск игры  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Сразу после добавления в панели управления игру могут запускать только её администраторы. Чтобы игра стала доступна всем пользователям, нужно изменить настройки видимости. Для игр в Одноклассниках игра станет доступна всем только после прохождения модерации в каталог.

## Доступность игры

Видимость игры настраивается в разделе [Размещение](https://dev.vk.ru/ru/games/settings/general/placement) и также зависит от публикации в каталоге.

### Настройки в панели управления

## • Состояние: Отключено. Состояние игры сразу после создания. ВКонтакте игра с таким состоянием доступна только администраторам. Запустить игру в Одноклассниках может только создатель.

## Чтобы опубликовать игру в Одноклассниках, нужно привязать OK ID в разделе [Другие площадки](https://dev.vk.ru/ru/games/settings/general/other-sites). Игра станет доступна в Одноклассниках в течение 15 минут. • Состояние: Включено. Игра ВКонтакте станет доступна по ссылке всем пользователям. В Одноклассниках доступ будет только у создателя игры. Чтобы игра стала доступна всем пользователям, нужно пройти [модерацию](https://dev.vk.ru/ru/games/settings/moderation).

Тестовые сборки можно сделать доступными только для тестировщиков игры. Для этого используйте [тестовые группы](https://dev.vk.ru/ru/games/settings/test-groups).

Подробнее о добавлении администраторов в игру — в разделе [Панель управления |](https://dev.vk.ru/ru/games/settings/managers#%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B0%D0%B4%D0%BC%D0%B8%D0%BD%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%82%D0%BE%D1%80%D0%B0) [Администраторы](https://dev.vk.ru/ru/games/settings/managers#%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B0%D0%B4%D0%BC%D0%B8%D0%BD%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%82%D0%BE%D1%80%D0%B0).

### Публикация в каталоге

- [Публикация в каталоге ВКонтакте](https://dev.vk.ru/ru/games/catalog/overview) не влияет на доступность игры пользователям. Когда игра опубликована, пользователи могут найти её в каталоге и запустить через интерфейс ВКонтакте. Без публикации они могут пользоваться только прямой ссылкой на игру.
- [Публикация в каталоге Одноклассников](https://dev.vk.ru/ru/ok/publishing) делает игру доступной для всех пользователей. Её можно найти и запускать из каталога.

## Запуск игры

Когда игра попала в каталог, запустить её можно из интерфейса социальной сети. Пока игра не опубликована, используйте другие способы для удобного запуска.

### В браузере

## • По прямой ссылке. Ссылки на игру можно найти в панели управления:

Чтобы запустить игру в мобильной версии, добавьте в адрес `m`, например:

## `https://m.vk.com/app535566**`. • Через «Закладки» или Избранное ВКонтакте. Запустите игру по прямой ссылке и выберите действие Сохранить в закладках или Добавить в избранное.

## • Игру, добавленную в избранное, можно запустить из левого меню. • Игру, сохранённую в закладках, можно запустить из пункта Закладки в левом меню.

### В мобильном приложении

## • Из личных сообщений.

1. Перейдите в раздел Мессенджер и откройте диалог Избранное — поместите курсор в поле поиска чатов.

Затем отправьте ссылку на игру. Её можно найти в панели управления игрой.

2. В мобильном приложении перейдите в диалог Избранное и нажмите на отправленную ссылку. ВКонтакте запустит игру в элементе управления WebView.

При отправке сообщения мессенджер определяет, что ссылка указывает на игру, и добавляет сниппет игры к сообщению. Вы можете запустить игру, нажав на кнопку в сниппете.

## • Из списка недавно запущенных ВКонтакте.

1. Запустите игру в десктопной версии сайта ВКонтакте. После этого она попадёт в список игр, которые были запущены недавно.

2. Откройте мобильное приложение ВКонтакте для Android и перейдите на последнюю вкладку.

3. Запустите игру из блока Обзор.

## Как скрыть игру

Измените Состояние на Отключено. Игра станет доступна только её администраторам.
