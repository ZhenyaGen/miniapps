# Дополнительные

**Раздел:** VK Games → Панель управления → Настройки → Дополнительные  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Дополнительные (настройки игр)

В этом разделе вы можете указать дополнительные настройки, которые используются для отладки, продвижения и работы игры на площадке ВКонтакте.

#### Чтобы открыть раздел:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Дополнительные.

## Доступ

Редактировать настройки может:

- Создатель игры.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Консоль Eruda

Консоль [Eruda](https://github.com/liriliri/eruda) упрощает отладку игр. Она подобна инструментам разработчика в браузерах и особенно полезна при создании и отладке игр, которые будут работать в мобильном приложении ВКонтакте для Android и iOS. Подробнее о консоли — в разделе [Отладка на мобильных устройствах](https://dev.vk.ru/ru/games/development/debugging#%D0%9E%D1%82%D0%BB%D0%B0%D0%B4%D0%BA%D0%B0%20%D0%BD%D0%B0%20%D0%BC%D0%BE%D0%B1%D0%B8%D0%BB%D1%8C%D0%BD%D1%8B%D1%85%20%D1%83%D1%81%D1%82%D1%80%D0%BE%D0%B9%D1%81%D1%82%D0%B2%D0%B0%D1%85).

В этом блоке вы можете подключить или отключить Eruda для своей игры. При включении платформа автоматически добавит кнопку для вызова консоли в интерфейс игры. Писать какой- либо код для этого не нужно. Кнопка будет видна только [администраторам](https://dev.vk.ru/ru/games/settings/managers) игры и не видна другим пользователям.

## Страница «Помощь»

Раньше игры могли использовать страницу «Помощь», чтобы предоставить пользователям дополнительную информацию об игровом процессе или поддержке. Ссылка на страницу отображалась на экране игры. Платформа добавляла её для игр, которые работали не в [широкоформатном режиме](https://dev.vk.ru/ru/games/settings/general/display#%D0%A8%D0%B8%D1%80%D0%BE%D0%BA%D0%BE%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%82%D0%BD%D1%8B%D0%B9%20%D1%80%D0%B5%D0%B6%D0%B8%D0%BC).

Сейчас такая страница признана устаревшей и отключена для игр, которые создаются на платформе.

Раздел настроек «Помощь» оставлен для обратной совместимости и доступен для игр, в которых страница уже была создана.

## Таблица результатов

[Таблица результатов](https://dev.vk.ru/ru/games/promotion/game-mechanics/leaderboards) показывает достижения пользователя в игре относительно его друзей, которые тоже играют в эту игру. Эта социальная механика важна для продвижения. Она привносит атмосферу соревнования и помогает приглашать друзей в игру.

С помощью настройки Таблица результатов вы можете выбрать, как таблица будет сортировать пользователей:

- По набранным очкам.
- По пройденным уровням.
- По баллам за [миссии](https://dev.vk.ru/ru/games/promotion/game-mechanics/missions).

Подробнее о работе с таблицей — в разделе [Таблица результатов](https://dev.vk.ru/ru/games/promotion/game-mechanics/leaderboards).

## Кастомные сниппеты

[Сниппет](https://dev.vk.ru/ru/games/promotion/game-mechanics/snippets) — блок с названием, описанием, изображением игры и кнопкой для запуска. ВКонтакте добавляет сниппеты к личным сообщениям, если в них указана ссылка на игру. Платформа может создать сниппет автоматически из настроек игры либо использовать сниппеты, которые вы создали с помощью API-запроса [`apps.addSnippet`](https://dev.vk.ru/ru/method/apps.addSnippet) [.](https://dev.vk.ru/ru/method/apps.addSnippet)

Настройка указывает вид сниппетов, которые платформа будет использовать:

## • Отключены — Платформа будет использовать сниппет, созданный из настроек игры. Значение используется по умолчанию. • Включены — Платформа будет использовать сниппеты, созданные с помощью API-запроса

[`apps.addSnippet`](https://dev.vk.ru/ru/method/apps.addSnippet), а также сниппет, созданный в настройках.

Подробнее — в разделе [Сниппеты игр](https://dev.vk.ru/ru/games/promotion/game-mechanics/snippets).
