# Аудитория

**Раздел:** VK Games → Панель управления → Статистика → Аудитория  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Аудитория (настройки игр)

В разделе вы можете просматривать статистику по пользователям и запускам игры на площадках ВКонтакте и Одноклассники.

#### Чтобы открыть статистику по аудиториям:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Статистика → Аудитория.

## Доступ

Просматривать статистику по пользователям и запускам игры может:

- Создатель мини-приложения.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Статистика».

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## ARPU и Retention

## • ARPU — показатель того, сколько голосов в среднем приносит один пользователь. • Retention — коэффициент удержания пользователей. Показывает долю аудитории, которая продолжает открывать игру на 1 (следующий), 7 и 30-й день после первого запуска.

Значения рассчитываются на основе статистики, собранной за 30 или 60 дней для одной или нескольких платформ и площадок, которые выбраны в блоке. Данные фильтров, указанные справа на странице, в расчётах не учитываются.

## Графики

На графиках вы можете:

## • Изменять период. Для этого наведите курсор на график, зажмите клавишу Ctrl и крутите колёсико мыши. • Отображать и скрывать данные. Для этого установите или снимите галочки под графиком. • Просматривать данные за определённый день. Наведите курсор на точку на графике — во всплывающем окне отобразится информация с данными и датой.

### Охват и запуски

На графике отображается количество уникальных пользователей и совершённых ими запусков за указанный период.

### Темпы роста и оттока

Показывает количество новых пользователей, начавших играть, и количество пользователей, которые удалили игру, за указанный период.

### Источники установок

Показывает количество пользователей, которые впервые запустили игру из определённого источника, за указанный период.

### Источники запусков

Показывает количество пользователей, которые запускали игру из выбранных источников, за указанный период.

## Использование фильтров

На графиках по умолчанию отображается статистика за 30 дней. Используйте фильтры для настройки графиков: установите период, выберите платформы и площадки, укажите пол и возраст пользователей. Фильтры применяются ко всем данным на странице.

## Экспорт данных

1. Нажмите Экспорт.

2. Укажите временной период и выберите данные для экспорта. Нажмите Экспортировать CSV.

Платформа сгенерирует файл с данными и начнёт загрузку автоматически.
