# Параметры запуска

**Раздел:** VK Games → Разработка → Параметры запуска  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

При старте игры или мини-приложения ВКонтакте передаёт им дополнительные параметры, содержащие данные о пользователе и источнике запуска. Значения передаются как URL-параметры на адрес, указанный в настройках игры или мини-приложения.

- [URL запуска игры](https://dev.vk.ru/ru/games/settings/general/placement#URL)
- [URL запуска мини-приложения](https://dev.vk.ru/ru/mini-apps/settings/general/placement#URL)

Чтобы получить параметры запуска в коде игры на стороне пользователя, воспользуйтесь одним из способов:

- Извлеките значение свойства `href` объекта `window.location`.
- Вызовите событие [`VKWebAppGetLaunchParams`](https://dev.vk.ru/ru/bridge/VKWebAppGetLaunchParams) [.](https://dev.vk.ru/ru/bridge/VKWebAppGetLaunchParams)

## Подпись параметров

Чтобы защититься от подмены значений возможной утечки данных, используйте подпись параметров. Подробности — в разделе [Подпись параметров запуска](https://dev.vk.ru/ru/games/development/parameters-sign).

## Параметры

Некоторые параметры передаются только для игр или только для мини-приложений. Это указано в таблице.

**Параметр | Тип | Описание**

`sign` `string` base64-строка — подпись параметров запуска. Используется для обнаружения подмены параметров третьими лицами. Подробнее — в разделе [Подпись параметров запуска](https://dev.vk.ru/ru/games/development/parameters-sign).

`vk_access_token_settings` `string` Список прав доступа пользователя, который запустил приложение. Каждое значение в списке соответствует области данных пользователя, к которой можно получить доступ. Значения в списке разделены запятыми, например

`friends,stories,wall`. Список используемых строковых констант приведён в разделе [Права](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) [доступа](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0).

`vk_app_id` `integer` Идентификатор запущенного приложения из его настроек. Подробнее:
- [Где найти ID игры](https://dev.vk.ru/ru/games/settings/overview#%D0%93%D0%B4%D0%B5%20%D0%BD%D0%B0%D0%B9%D1%82%D0%B8%20ID%20%D0%B8%D0%B3%D1%80%D1%8B?)
- [Где найти ID мини-приложения](https://dev.vk.ru/ru/mini-apps/settings/overview#%D0%93%D0%B4%D0%B5%20%D0%BD%D0%B0%D0%B9%D1%82%D0%B8%20ID%20%D0%BC%D0%B8%D0%BD%D0%B8-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F?)

`vk_are_notifications_enabled` `integer` Информация о разрешённых уведомлениях от приложения:

**Параметр | Тип | Описание**

- `0` — отправка уведомлений запрещена.
- `1` — отправка уведомлений разрешена.

`vk_chat_id` `string` Идентификатор чата. Передаётся, если приложение было запущено из чата.

`vk_group_id` `integer` Идентификатор сообщества, в котором установлено приложение. Передаётся, если мини-приложение:
- Запущено с помощью кнопок в сообществе или из блока приложений сообщества.
- Запущено по ссылке вида:

`vk.com/app6909581_-166562603`.

Параметр не используется в играх.

`vk_has_profile_button` `integer` Информация о том, установил ли пользователь кнопку в профиле, по которой запускается мини- приложение. Значение `1` означает, что пользователь установил кнопку в профиле, иначе параметр не передаётся.

Параметр не используется в играх.

`vk_is_app_user` `integer` Информация о том, установил ли пользователь приложение:
- `0` — приложение не установлено.
- `1` — приложение установлено.

После того, как пользователь впервые запустил игру или мини-приложение, они считаются установленными.

`vk_is_favorite` `integer` Информация о добавлении приложения в избранное:
- `0` — приложение не добавлено в избранное.
- `1` — приложение добавлено в избранное.

`vk_is_play_machine` `integer` `1`, если игра была запущена через [Play Machine](https://dev.vk.ru/ru/games/faq#%D0%9F%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%B8%D0%B2%D0%B0%D1%8E%D1%82%D1%81%D1%8F%20%D0%BB%D0%B8%20Flash-%D0%B8%D0%B3%D1%80%D1%8B?) (специальное приложение для запуска Flash-игр). В ином случае параметр равен `0` или не передаётся.

Параметр не используется в мини-приложениях.

`vk_is_recommended` `integer` Информация о том, [рекомендовал](https://dev.vk.ru/ru/mini-apps/promotion/user-recommendation) ли пользователь, указанный в параметре

`vk_user_id`, мини-приложение своим друзьям:
- `0` — мини-приложение не порекомендовано.
- `1` — мини-приложение порекомендовано.

**Параметр | Тип | Описание**

Если параметр не передан, значит, что приложение ещё не порекомендовано.

Параметр не используется в играх.

`vk_is_widescreen` `integer` `1`, если игра запущена в [широкоформатном](https://dev.vk.ru/ru/games/settings/general/display#%D0%A8%D0%B8%D1%80%D0%BE%D0%BA%D0%BE%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%82%D0%BD%D1%8B%D0%B9%20%D1%80%D0%B5%D0%B6%D0%B8%D0%BC) [режиме](https://dev.vk.ru/ru/games/settings/general/display#%D0%A8%D0%B8%D1%80%D0%BE%D0%BA%D0%BE%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%82%D0%BD%D1%8B%D0%B9%20%D1%80%D0%B5%D0%B6%D0%B8%D0%BC), иначе — `0`. Параметр используется только для [Web-игр](https://dev.vk.ru/ru/games/getting-started#Direct%20Games%20%D0%B8%20Web-%D0%B8%D0%B3%D1%80%D1%8B).

Параметр не используется в мини-приложениях.

`vk_language` `string` Язык пользовательского интерфейса приложения. Возможные значения:
- `ru` — русский.
- `uk`, `ua` — украинский.
- `en` — английский.
- `be` — белорусский.
- `kz` — казахский.
- `pt` — португальский.
- `es` — испанский.

`vk_platform` `string` Платформа, на которой было запущено приложение:
- `desktop_web` — десктопная версия сайта ВКонтакте.
- `mobile_android` — мобильное приложение ВКонтакте для Android.
- `mobile_ipad` — мобильное приложение ВКонтакте для iPadOS.
- `mobile_iphone` — мобильное приложение ВКонтакте для iOS.
- `mobile_web` — мобильная версия сайта ВКонтакте.

Если мини-приложение было запущено из VK Мессенджера:
- `desktop_app_messenger` — десктопное приложение VK Мессенджер.
- `desktop_web_messenger` — десктопная версия VK Мессенджера (web.vk.me).
- `mobile_android_messenger` — мобильное приложение VK Мессенджер для Android.
- `mobile_iphone_messenger` — мобильное приложение VK Мессенджер для iOS.

Если мини-приложение было запущено не из ВКонтакте или VK Мессенджера, то параметр содержит следующие значения:
- `android_external` — приложение для Android.
- `iphone_external` — приложение для iOS.
- `ipad_external` — приложение для iPadOS.

**Параметр | Тип | Описание**

- `mvk_external` — сайт, открытый в мобильном браузере.
- `web_external` — сайт, открытый в десктопном браузере.

`vk_profile_id` `integer` Идентификатор пользователя, по кнопке в профиле которого запускается мини- приложение. Если мини-приложение запущено не по кнопке в профиле, параметр не передаётся.

Параметр не используется в играх.

`vk_ref` `string` Источник запуска приложения. Для игр и мини- приложений есть свой возможный список значений:
- [Список значений для игр](https://dev.vk.ru/ru/games/development/parameters/vk_ref)
- [Список значений для мини-приложений](https://dev.vk.ru/ru/mini-apps/development/launch-params/vk_ref)

`vk_request_key` `string` Используется при старте игры из [запроса о](https://dev.vk.ru/ru/games/promotion/game-mechanics/requests) [помощи](https://dev.vk.ru/ru/games/promotion/game-mechanics/requests) или [приглашения](https://dev.vk.ru/ru/games/promotion/game-mechanics/invites) друга. Указывает ключ запроса или приглашения. Это то же самое значение, которое было передано в параметре

`requestKey` при вызове события [`VKWebAppShowRequestBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowRequestBox) или [`VKWebAppShowInviteBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowInviteBox) библиотеки [VK](https://dev.vk.ru/ru/bridge/overview) [Bridge](https://dev.vk.ru/ru/bridge/overview).

Используйте это значение в игре, чтобы предусмотреть сценарий, соответствующий запросу или приглашению, а также для отслеживания конверсии.

Параметр не используется в мини-приложениях.

`vk_testing_group_id` `integer` Идентификатор тестовой группы, в которой состоит пользователь. Если пользователь не состоит в тестовой группе, параметр не передаётся.

`vk_ts` `integer` Время генерации подписи параметров запуска. Подпись передаётся в параметре `sign`.

`vk_user_id` `integer` Идентификатор пользователя, запустившего приложение. Параметр `vk_user_id` нужно использовать для авторизации пользователя в мини-приложении или игре. Чтобы проверить подлинность полученных данных, вычислите подпись и сравните с полученным значением sign.

**Параметр | Тип | Описание**

`vk_viewer_group_role` `string` Роль пользователя в сообществе, из которого запущено мини-приложение:
- `admin` — администратор или создатель сообщества.
- `editor` — редактор сообщества.
- `member` — подписчик сообщества.
- `moder` — модератор сообщества.
- `none` — не состоит в сообществе.

Информация о сообществе возвращается, если:
- Мини-приложение запущено с помощью кнопок в сообществе.
- Исходная ссылка на приложение имела вид:

`vk.com/app6909581_-166562603`.

Параметр не используется в играх.

## Передача произвольных параметров

При необходимости вы можете передавать произвольные параметры в игру или мини-приложение.

#### Запуск по прямой ссылке

При запуске игры по прямой ссылке укажите параметры после символа `#` в адресной строке, например:

```
https://vk.com/app1234567#param1=12345
```

Символы после `#` будут переданы игре в URL-параметре `hash`. Этот параметр всегда идёт последним среди остальных передаваемых параметров. Все символы после него являются символами, которые были указаны после `#` в URL игры.

Получить параметры можно и с помощью свойства `hash` объекта `window.location`. Для отслеживания изменений этого значения в игре используйте события [`VKWebAppLocationChanged`](https://dev.vk.ru/ru/bridge/VKWebAppLocationChanged) и [`VKWebAppChangeFragment`](https://dev.vk.ru/ru/bridge/VKWebAppChangeFragment) библиотеки [VK Bridge](https://dev.vk.ru/ru/bridge/overview).

Использование знака вопроса ( `?`) для передачи параметров при запуске по прямой ссылке не работает.

#### Параметры запуска в настройках игры

Чтобы указать параметры запуска в настройках игры, добавьте в URL знак вопроса и параметры, например:

```
https://my-game.example.com/start-page?param1=12345
```

Получить эти параметры вы можете так же, как и обычные параметры веб-страниц, например с помощью свойства `window.location.search` или с помощью события

[`VKWebAppGetLaunchParams`](https://dev.vk.ru/ru/bridge/VKWebAppGetLaunchParams) [.](https://dev.vk.ru/ru/bridge/VKWebAppGetLaunchParams)

Использовать символы `#` в URL-адресах, которые указываются в настройках игры, нельзя.
