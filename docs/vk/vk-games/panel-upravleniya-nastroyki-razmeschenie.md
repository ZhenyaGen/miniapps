# Размещение

**Раздел:** VK Games → Панель управления → Настройки → Размещение  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Размещение (настройки игр)

Раздел содержит настройки, необходимые для запуска игры из интерфейса площадок ВКонтакте и Одноклассники.

Важно! Если настройки размещения не указаны, игра не будет работать.

#### Чтобы открыть раздел:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Размещение.

## Доступ

Редактировать настройки размещения может:

- Создатель игры.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Состояние для пользователей

Настройка указывает, кому доступна игра.

**Состояние | Описание**

Отключено Состояние игры сразу после создания. ВКонтакте игра с таким состоянием доступна только администраторам. Запустить игру в Одноклассниках может только создатель.

Чтобы опубликовать игру в Одноклассниках, нужно привязать OK ID в разделе [Другие](https://dev.vk.ru/ru/games/settings/general/other-sites) [площадки](https://dev.vk.ru/ru/games/settings/general/other-sites). Игра станет доступна в Одноклассниках в течение 15 минут.

Включено Игра ВКонтакте станет доступна по ссылке всем пользователям. В Одноклассниках доступ будет только у создателя игры. Чтобы игра стала доступна всем пользователям, нужно пройти [модерацию](https://dev.vk.ru/ru/games/settings/moderation).

Подробнее о доступности игры — в разделе [Запуск игры](https://dev.vk.ru/ru/games/launch-game).

## Настройки платформ

Раздел содержит настройки запуска игры для различных платформ. Вы можете настроить запуск игры на всех доступных платформах или выбрать только необходимые.

| Раздел | Описание |
|---|---|
| Мобильное приложение (ранее Direct Games) | Настройки для запуска игры из мобильного приложения ВКонтакте и Одноклассники для Android и iOS. |
| Игра будет открываться в элементе управления WebView и будет выглядеть | похожей на обычные приложения для Android и iOS. |

Web Настройки для запуска игры из десктопной версии сайта ВКонтакте ([vk.com](https://vk.com)) и Одноклассники ([ok.ru](https://ok.ru)).

В браузере у пользователя будет открыта страница сайта vk.com, а игра будет загружена в HTML-элемент `<iframe>` на этой странице.

| Мобильная версия сайта | Настройки для запуска игры из мобильной версии сайта ВКонтакте ([m.vk.com](https://m.vk.com)) и Одноклассники ([m.ok.ru](https://m.ok.ru)). |
|---|---|
| Игра будет открываться в элементе управления WebView и будет выглядеть | похожей на обычные приложения для Android и iOS. |

### URL

Адрес для запуска игры. Площадка отправит этот адрес в WebView или для загрузки.

Чтобы передать параметры, укажите их в URL после символа `?`, например `https://my-` `game.com/start?param1=value1`.

### Режим разработки

Используйте эту настройку, чтобы включить или отключить режим разработки. В поле укажите адрес, по которому будет доступна версия игры только для администраторов.

Режим разработки полезен, когда игра уже опубликована в каталоге, но вам надо проверить изменения в ней. Этот режим работает для всех [администраторов](https://dev.vk.ru/ru/games/settings/managers) игры. Когда они запустят игру, она будет загружена из адреса, указанного в настройке Режим разработки, а не из настройки URL. Для остальных пользователей игра продолжит открываться по URL, для них подмены не произойдёт.

### Приоритеты URL для загрузки игры

Когда администратор запускает игру, URL для загрузки приложения определяется в следующем порядке:

1. URL, указанный в настройках [тестовой группы](https://dev.vk.ru/ru/games/settings/test-groups), если администратор включён в какую-либо тестовую группу. Этот URL имеет наивысший приоритет относительно остальных.

2. URL, указанный для режима разработки, если режим разработки включён для выбранной платформы.

3. URL, указанный в настройке URL. Приоритет этого URL ниже адресов, указанных в тестовой группе или в режиме разработки.

## Удалить игру

Чтобы удалить игру с платформы, в правом нижнем углу страницы нажмите Удалить приложение. Кнопка доступна только [создателю](https://dev.vk.ru/ru/games/settings/managers#%D0%A1%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D0%B5%D0%BB%D1%8C) игры.

Удалённую игру нельзя восстановить. Можно создать новую с другим идентификатором.
