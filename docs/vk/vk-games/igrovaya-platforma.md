## VK Games

VK Games — это единая игровая платформа для пользователей социальных сетей ВКонтакте и Одноклассники. Она позволяет легко запускать игры прямо из интерфейса, без необходимости скачивания, установки или регистрации.

Создайте свою игру на [dev.vk.com](https://dev.vk.com), и после проверки модераторы опубликуют её на выбранных площадках. Затем вы сможете привлекать пользователей, используя бесплатные методы продвижения.

## Преимущества для разработчиков и издателей

- Возможность продвижения и монетизации в нескольких социальных сетях.
- Свыше 500 операций API ВКонтакте и Одноклассников для интеграции.
- Бесплатные методы продвижения.
- Рекомендации и лучшие практики от платформы.

[Узнайте больше](https://dev.vk.ru/ru/games/benefits)

## Первые шаги

Игры VK Games — это HTML5-приложения для мобильных устройств и компьютеров. Начните с создания и регистрации игры в [Панели управления](https://dev.vk.com/ru/admin/apps-list). Подробнее — в разделе [Первые шаги](https://dev.vk.ru/ru/games/getting-started).
