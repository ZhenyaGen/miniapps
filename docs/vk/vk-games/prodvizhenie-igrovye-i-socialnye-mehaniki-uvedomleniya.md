# Уведомления

**Раздел:** VK Games → Продвижение → Игровые и социальные механики → Уведомления  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Игра может отправлять пользователям уведомления — сообщения, которые напоминают пользователю об игре, помогают удерживать постоянных игроков и возвращать неактивных.

Уведомления можно увидеть в ленте в разделе Игры → Профиль десктопной версии сайта ВКонтакте. Также уведомления могут приходить в колокольчик и в виде push-уведомлений в Одноклассниках и ВКонтакте.

По умолчанию уведомления в игре включены. При первом запуске игры ВКонтакте пользователь увидит всплывающее сообщение о получении уведомлений.

## • ВКонтакте пользователь может нажать Настройки во всплывающем сообщении и отключить уведомления. Либо сделать это позже из меню Действия → Настройки. • В Одноклассниках пользователь может отключить уведомления, выбрав Ещё → Оповещения.

## Типы уведомлений

Игры ВКонтакте поддерживают уведомления следующих типов:

| Тип | Описание |
|---|---|
| [Разовые](https://dev.vk.ru/ru/games/promotion/game-mechanics/notifications/single) | Сообщают пользователям об отдельных событиях, связанных с игрой, таких как: конкурсы, кампании или предложения к праздникам. |
| [Неактивным](https://dev.vk.ru/ru/games/promotion/game-mechanics/notifications/automatic) [пользователям](https://dev.vk.ru/ru/games/promotion/game-mechanics/notifications/automatic) | Напоминают пользователям об игре, если они не запускали её в течение нескольких дней. |
| C помощью этих уведомлений игра также может сообщать пользователю, | что его друг выполнил какую-либо миссию. |
| [Всем пользователям](https://dev.vk.ru/ru/games/promotion/game-mechanics/notifications/mass) | Используются для массовой рассылки оповещений активным пользователям в честь какого-либо события. |
| Далее в документации рассказывается о настройке уведомлений для игр ВКонтакте. Подробнее об | уведомлениях в Одноклассниках — в [документации API OK](https://apiok.ru/dev/methods/rest/notifications/). |

## Ограничения

## • Уведомления можно использовать в игре только после того, как она прошла модерацию и была [опубликована в каталоге](https://dev.vk.ru/ru/games/catalog/moderation). • Для создания уведомлений [состояние игры](https://dev.vk.ru/ru/games/settings/general/placement#%D0%A1%D0%BE%D1%81%D1%82%D0%BE%D1%8F%D0%BD%D0%B8%D0%B5%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D0%B5%D0%B9) должно быть Включено. • У пользователя должны быть включены уведомления от игр и приложений в настройках ВКонтакте и Одноклассники.
