# Работа кеша приложений

**Раздел:** VK Games → Разработка → Работа кеша приложений  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Чтобы предоставить пользователям комфортное взаимодействие с играми на Android и iOS, платформа ВКонтакте использует кеш. Он помогает платформе восстановить последний используемый экран игры, когда пользователь возвращается в эту игру после выхода из неё.

Кеш используется неявно, разработчику не надо заботиться о взаимодействии с ним. Библиотека [VK Bridge](https://dev.vk.ru/ru/bridge/overview) не содержит событий, связанных с кешем. Мы решили рассказать об использовании кеша, чтобы предоставить более полную картину работы и помочь понять, почему игра показывает тот или иной экран, а VK Bridge отправляет то или иное событие.

## Как это выглядит для пользователя

- Представьте, что пользователь получает ссылку на игру от друга. Эта ссылка может представлять собой адрес самой игры или адрес игры и экрана в ней. Например:

- `https://vk.ru/app12345` — ссылка, содержащая только адрес игры.
- `https://vk.ru/app12345/#/page1` — ссылка с указанием на экран в игре.
- Когда пользователь переходит по экранам игры, текущий URL игры может меняться.
- Если пользователь выйдет из игры, а потом нажмёт на изначальную ссылку, чтобы в неё вернуться, то ВКонтакте запустит игру, но покажет последний экран, на котором был пользователь, а не тот экран, на который указывает ссылка.

Такой подход в большей мере соответствует ожиданиям пользователей и обеспечивает комфортную работу с приложением.

Для реализации подобного подхода ВКонтакте использует кеш приложений.

## Как работает кеш

1. При запуске игры мобильное приложение ВКонтакте сохраняет информацию о URL, используемом для запуска.

2. Когда пользователь выходит из игры любым способом — сворачивает мобильное приложение ВКонтакте, переключается в другое мобильное приложение, возвращается на главный экран, выходит из игры, нажав «Закрыть», — платформа ВКонтакте выполняет следующие действия:

- Отправляет игре событие [`VKWebAppViewHide`](https://dev.vk.ru/ru/bridge/VKWebAppViewHide) [.](https://dev.vk.ru/ru/bridge/VKWebAppViewHide)

Вы можете использовать его, чтобы [приостановить действия](https://dev.vk.ru/ru/games/how-to/handle-minimize-and-restore-events), которые не должны выполняться в фоновом режиме, например воспроизведение музыки.
- Помещает в кеш данные игры и текущий URL.

3. Информация в кеше хранится 15 минут.

Если в течение этого периода пользователь вернётся в игру или запустит её снова, ВКонтакте будет использовать кеш.

## • Если для входа в игру используется тот же самый URL, который был использован для запуска ранее, ВКонтакте загрузит информацию из кеша. Визуально для пользователя это будет выглядеть так, как будто игра открылась на экране, который был активен в момент выхода.

После запуска ВКонтакте сначала отправит игре событие [`VKWebAppChangeFragment`](https://dev.vk.ru/ru/bridge/VKWebAppChangeFragment), а затем [`VKWebAppViewRestore`](https://dev.vk.ru/ru/bridge/VKWebAppViewRestore). `VKWebAppChangeFragment` сообщает игре об экране, на который надо перейти. Если во время отсутствия пользователя на экране произошли изменения, то это даст игре возможность обновить экран. `VKWebAppViewRestore` сигнализирует о возврате пользователя в игру.

## • Если для входа используется другой URL, то игра запустится заново.

## Какие игры кешируются

Платформа ВКонтакте использует кеш и для игр, и для мини-приложений. Кеш имеет два слота, то есть хранит информацию для двух последних открытых мини-приложений или игр. Наши исследования показали, что этого достаточно для комфортной работы.
