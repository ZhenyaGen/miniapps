# Отображение

**Раздел:** VK Games → Панель управления → Настройки → Отображение  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Отображение (настройки игр)

Раздел содержит настройки, которые влияют на отображение игры и элементов управления на экране устройства.

#### Чтобы открыть настройки отображения:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Настройки → Отображение.

## Доступ

Настраивать отображение игры может:

- Создатель игры.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Мобильный формат

Настройки на этой вкладке применяются к играм, которые запускаются из мобильного приложения для Android и iOS, а также из мобильной версии сайта ВКонтакте или Одноклассники.

### Ориентация экрана

Вы можете выбрать предпочтительную ориентацию экрана при запуске игры на мобильных устройствах.

Процедура запуска зависит от платформы:

- При запуске в мобильном приложении для Android или iOS пользователи увидят экран игры в выбранной ориентации и повернут устройство.
- При запуске в мобильном браузере будет показано предупреждение, что экран надо повернуть. После поворота игра стартует автоматически.

### Элементы управления

На мобильных устройствах отображаются системные элементы управления игрой: её название, кнопка «Закрыть» и кнопка вызова меню. Вы можете выбрать расположение таких элементов:

## • Поверх окна — элементы управления отобразятся в окне игры. • Над окном — элементы управления отобразятся в виде полосы над окном игры.

### Адаптация под iPhone

Указывает, использует ли игра нижнюю часть экрана на iPhone. Опция не влияет на игры, которые запускаются на других устройствах.

## Десктопная версия сайта

При запуске в десктопной версии ВКонтакте игра открывается в HTML-элементе. Вы можете настроить параметры этого элемента.

### Широкоформатный режим

Указывает, будет ли подстраивать свою ширину под ширину вкладки браузера или будет использовать значение, указанное в настройке Размер iframe.

Высота не зависит от того, включён широкоформатный режим или нет. Она всегда будет равна высоте, указанной в настройке Размер iframe.

Игра может работать в широкоформатном режиме только после [публикации в каталоге](https://dev.vk.ru/ru/games/catalog/moderation). До этого момента она доступна в широкоформатном режиме только [создателю](https://dev.vk.ru/ru/games/settings/managers#%D0%A1%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D0%B5%D0%BB%D1%8C), [администраторам](https://dev.vk.ru/ru/games/settings/managers#%D0%90%D0%B4%D0%BC%D0%B8%D0%BD%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%82%D0%BE%D1%80%20%D1%81%20%D0%BF%D0%BE%D0%BB%D0%BD%D1%8B%D0%BC%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%BE%D0%BC) [с полным доступом](https://dev.vk.ru/ru/games/settings/managers#%D0%90%D0%B4%D0%BC%D0%B8%D0%BD%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%82%D0%BE%D1%80%20%D1%81%20%D0%BF%D0%BE%D0%BB%D0%BD%D1%8B%D0%BC%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%BE%D0%BC) и [администраторам с частичным доступом, с правом «Тестирование»](https://dev.vk.ru/ru/games/settings/managers#%D0%90%D0%B4%D0%BC%D0%B8%D0%BD%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%82%D0%BE%D1%80%20%D1%81%20%D1%87%D0%B0%D1%81%D1%82%D0%B8%D1%87%D0%BD%D1%8B%D0%BC%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%BE%D0%BC).

### Размер iframe

Определяет размер в пикселях для HTML-элемента, в котором работает игра. Размер указывается в формате: <ширина> × <высота>.

Минимальный размер: 630×600 px. Максимальный размер: 1 000×4 050 px.

Указанное значение ширины будет игнорироваться, если игра запускается в широкоформатном режиме.
