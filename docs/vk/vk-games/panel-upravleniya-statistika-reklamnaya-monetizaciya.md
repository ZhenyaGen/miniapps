# Рекламная монетизация

**Раздел:** VK Games → Панель управления → Статистика → Рекламная монетизация  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Рекламная монетизация (настройки игр)

Вы можете монетизировать вашу игру с помощью [показов рекламы](https://dev.vk.ru/ru/games/monetization/ad/overview).

В разделе Рекламная монетизация отображается статистика по начислениям и показам рекламы на площадках ВКонтакте и Одноклассники.

Для подключения монетизации зарегистрируйтесь в [кабинете выплат](https://cashout.vk.com/). Подробнее о регистрации и получении вознаграждения — в разделе [Вывод средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).

Подробная информация о видах рекламы и её подключении — в разделе [Реклама в играх](https://dev.vk.ru/ru/games/monetization/ad/overview).

#### Чтобы открыть статистику по рекламной монетизации:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Статистика → Рекламная монетизация.

## Доступ

Просматривать статистику по рекламной монетизации может:

- Создатель мини-приложения.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Рекламная монетизация».

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Информация на странице

На странице вверху выводится информация по общему количеству всех начислений и показов рекламы за указанный период.

На графиках отображаются данные по видам рекламы:

## • Сумма — суммарный доход по всем видам рекламы. • Interstitial — рекламные материалы, которые показываются при переходе от одного экрана к другому. • Banner — графический блок с текстом, который занимает только часть экрана. • Rewarded — видео, за просмотр которого пользователь получает вознаграждение внутри приложения.

## Графики

На графиках вы можете:

## • Изменять период. Для этого наведите курсор на график, зажмите клавишу Ctrl и крутите колёсико мыши. • Отображать и скрывать данные. Для этого установите или снимите галочки под графиком.

- Просматривать данные за определённый день. Наведите курсор на точку на графике — во всплывающем окне отобразится информация с данными и датой.

### Начисления

На графике отображаются начисления по выбранным видам рекламы за указанный период.

### Показы

На графике отображаются показы по выбранным видам рекламы за указанный период.

## Использование фильтров

На графиках по умолчанию отображается статистика за 30 дней. Используйте фильтры для настройки графиков: установите период, выберите платформы и площадки, укажите виды рекламы. Фильтры применяются ко всем данным на странице.

## Вывод средств

Нажмите Вывести деньги. Вы будете перенаправлены в административную панель для вывода средств по прямому договору.

Подробнее — в разделе [Вывод средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).
