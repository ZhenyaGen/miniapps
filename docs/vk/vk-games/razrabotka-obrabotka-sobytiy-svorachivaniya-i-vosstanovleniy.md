# Обработка событий сворачивания и восстановления экрана игры

**Раздел:** VK Games → Разработка → Обработка событий сворачивания и восстановления экрана игры  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Игра может выполнять какие-либо действия в фоновом режиме во время игрового процесса: проигрывать мелодию, показывать видео, производить вычисления, загружать данные.

В зависимости от вида фоновой активности вам может потребоваться приостанавливать её, когда пользователь переключается на другое приложение или переходит на другую вкладку браузера. Такой подход экономит ресурсы и позволяет приложению не выполнять действия, когда оно свёрнуто. Кроме того, он избавляет вашу игру от неприятного эффекта, когда пользователь, например, перешёл в мессенджер, чтобы ответить на сообщение, но продолжает слышать фоновую музыку.

Прекращённые фоновые действия надо восстанавливать, когда пользовать возвращается в игру.

Для приостановки и возобновления фоновых действий добавьте в игру программный код, который будет реагировать на изменение видимости окна игры. Добавлять его надо в ту часть игры, которая работает на стороне пользователя.

Современные браузеры прекращают фоновые действия автоматически, когда мобильное приложение или вкладка десктопного браузера закрывается. Специально отключать фоновые действия при этом не нужно. Ваш код должен работать, именно когда игра меняет свою видимость, то есть когда пользователь переключается на другое приложение или вкладку браузера и когда он возвращается в игру.

Способ обработки событий зависит от того, работает ли игра в мобильном приложении ВКонтакте для Android и iOS или в десктопной и мобильной версии сайта ВКонтакте.

## При работе из мобильного приложения ВКонтакте

При запуске из мобильного приложения ВКонтакте игра работает в WebView. Чтобы отслеживать переключение пользователя из игры и возвращение в неё, используйте события

[`VKWebAppViewHide`](https://dev.vk.ru/ru/bridge/VKWebAppViewHide) и [`VKWebAppViewRestore`](https://dev.vk.ru/ru/bridge/VKWebAppViewRestore) библиотеки [VK Bridge](https://dev.vk.ru/ru/bridge/overview).

В обработчике `VKWebAppViewHide` вы можете ставить фоновые действия на паузу, в обработчике

`VKWebAppViewRestore` — продолжать их. Пример ниже демонстрирует работу событий.

```html
<audio id="my_audio" src="some-song.mp3" controls>
```

```js
// Подписываемся на события
bridge.subscribe(eventHandler);
```

```
// ...
```

```
function eventHandler(e) {
```

```
const { type, data } = e.detail;
switch(type) {
  case 'VKWebAppViewHide':
    my_audio.pause(); // Останавливаем воспроизведение аудио
    break;
  case 'VKWebAppViewRestore':
    my_audio.play(); // Запускаем воспроизведение
    break;
```

```
// Обработчики других событий
// ...
```

```
    }
}
```

Обратите внимание, что при работе на Android событие `VKWebAppViewHide` приходит в случае, когда пользователь сворачивает игру или когда она переключается в режим «картинка в картинке» (picture-in-picture). В обработчик события платформа передаёт объект с полем

`reason`, которое содержит информацию о типе переключения. В примере выше для простоты мы не проверяли его, но в общем случае это надо делать перед тем, как выполнить нужные действия.

## При работе в десктопной и мобильной версии сайта

При запуске в десктопной и мобильной версии сайта ВКонтакте игра работает в iframe. Чтобы отслеживать видимость игры пользователю, используйте событие [`document.visibilitychange`](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API) и свойство [`document.hidden`](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API). Они поддерживаются почти всеми современными браузерами.

Ниже приведён пример использования свойства и события.

```html
<audio id="my_audio" src="some-song.mp3" controls>
```

```js
document.addEventListener('visibilitychange', eventHandler);
```

```
function eventHandler() {
  // Проверяем, скрыта ли страница
  if (document.hidden) {
    my_audio.pause(); // Останавливаем воспроизведение аудио
  } else {
    my_audio.play(); // Запускаем воспроизведение
  }
}
```

Обратите внимание, что браузер генерирует событие `visibilitychange` всегда, когда происходит изменение видимости HTML-страницы на экране: при сворачивании или разворачивании окна

браузера, а также при переходе на другую вкладку. Если вы хотите оставлять фоновую музыку при переключении на соседнюю вкладку, обрабатывайте такую ситуацию специальным образом.

Событие и свойство также работают и в играх, которые запускаются в мобильном приложении ВКонтакте для Android и iOS. Однако для игр на мобильных устройствах мы рекомендуем пользоваться событиями библиотеки VK Bridge, так как они учитывают определённые особенности работы в таком режиме.
