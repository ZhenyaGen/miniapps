# Миссии

**Раздел:** VK Games → Панель управления → Соц. механики → Миссии  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Миссии (настройки игры)

В разделе Миссии вы можете добавить задания для игроков и настроить, какие уведомления будут появляться у их друзей. Миссия — последовательность действий в игре, которая приводит к определённому результату. Когда игрок завершает миссию, ВКонтакте отправляет сообщения об этом в [ленту активности](https://dev.vk.ru/ru/games/promotion/game-mechanics/feed) друзей.

Подробнее о создании и использовании миссий — в разделе [Миссии](https://dev.vk.ru/ru/games/promotion/game-mechanics/missions).

Настройка миссий доступна только для игр ВКонтакте.

#### Чтобы открыть раздел:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Соц. механики → Миссии.

## Доступ

- Раздел отображается только для игр, которые прошли [модерацию](https://dev.vk.ru/ru/games/catalog/moderation) и опубликованы в [каталоге](https://vk.com/games).
- Получить доступ к разделу может:

- Создатель игры.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Редактирование».

## Настройки миссии

Чтобы добавить миссию в игру, нажмите Создать и укажите параметры миссии:

- Начните название миссии с глагола в неопределённой форме, например «поставить», «построить», «завершить», «исследовать», «найти».
- Установите количество баллов за миссию — от 1 до 100 включительно.
- В тексте о прохождении миссии используйте глаголы совершенного вида в прошедшем времени, например «построил», «построила», «нашёл», «нашла».

Текст о прохождении миссии зависит от пола игрока, который завершил миссию. Укажите текст для каждого пола.

В тексте допускается использовать следующие переменные. Платформа автоматически заменит их на соответствующие значения при отправке уведомлений.

| Переменная | Описание |
|---|---|
| `{user}` | Имя игрока, который завершил миссию. Подтянется только имя пользователя, без фамилии — так, как оно указано в профиле пользователя ВКонтакте. |
| `{name}` | Название игры, как оно указано в настройках игры, в разделе [Информация](https://dev.vk.ru/ru/games/settings/general/information). |

Совет. Посмотрите [наши рекомендации](https://dev.vk.ru/ru/games/promotion/game-mechanics/missions#%D0%A0%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8) о количестве баллов за прохождение миссии и стилистических особенностях текста, которые помогут вашим сообщениям органично вписаться в ленту.

## Ограничения

- Каждая игра может иметь до 200 миссий.
- Максимальное общее количество баллов на все созданные и ещё не созданные миссии —  2 000.

## Проверка миссии

Перед публикацией все миссии проходят модерацию. Отправьте созданную миссию на проверку. Когда модераторы проверят тексты, результаты будут видны в списке миссий.

Важно! Проверьте название, тексты и другие параметры миссии перед её отправкой на модерацию. После прохождения модерации изменить параметры будет невозможно.

Миссия готова к использованию сразу после прохождения модерации.

## Идентификатор миссии

После создания миссии платформа автоматически присвоит ей идентификатор — целое число, которое отображается в блоке миссии.

Вы будете использовать этот идентификатор при отправке API-запросов ВКонтакте, чтобы сообщить платформе о том, что пользователь прошёл миссию. Подробности — в разделе [Миссии](https://dev.vk.ru/ru/games/promotion/game-mechanics/missions).

Изменить идентификатор нельзя.
