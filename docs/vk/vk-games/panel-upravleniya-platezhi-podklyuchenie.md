# Подключение

**Раздел:** VK Games → Панель управления → Платежи → Подключение  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Подключение (настройки игр)

Игры могут предоставлять [виртуальные ценности](https://dev.vk.ru/ru/mini-apps/glossary#%D0%92%D0%B8%D1%80%D1%82%D1%83%D0%B0%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F%20%D1%86%D0%B5%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D1%8C) за [голоса ВКонтакте](https://dev.vk.ru/ru/mini-apps/glossary#%D0%93%D0%BE%D0%BB%D0%BE%D1%81) и [ОКи в Одноклассниках](https://dev.vk.ru/ru/mini-apps/glossary#%D0%9E%D0%9A%D0%B8).

В разделе Подключение вы можете указать параметры для выполнения платежей и просмотреть журнал платёжных уведомлений.

Если вы планируете предоставлять виртуальные ценности за голоса и ОКи, зарегистрируйтесь в [кабинете выплат](https://cashout.vk.com/).

Подробнее:

- О регистрации в кабинете выплат и получении вознаграждения — в разделе [Вывод средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).
- О продаже виртуальных товаров — в разделе [Платежи виртуальной валютой](https://dev.vk.ru/ru/api/payments/overview).

#### Чтобы открыть раздел:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Платежи → Подключение.

## Доступ

Получить доступ к разделу может:

- Создатель игры.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Платежи».

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).

## Настройки

Вкладка содержит настройки, необходимые для работы платежей.

### URL для платёжных уведомлений ВКонтакте

При продаже виртуальных ценностей площадка запрашивает у игры информацию о товарах, а также отправляет уведомления о покупке или возврате.

Эта настройка указывает URL на сервере игры, на который будут отправляться запросы о товарах и уведомления о платежах. Сервер игры должен обрабатывать запросы, поступающие на этот адрес, и предоставлять ответы.

- Для игр ВКонтакте на этот URL оправляются все уведомления для получения информации о товаре и подписке, а также уведомления о покупке. Подробнее — в разделе [Обработка платёжных](https://dev.vk.ru/ru/api/payments/notifications/vk) [уведомлений ВКонтакте](https://dev.vk.ru/ru/api/payments/notifications/vk).
- Для игр в Одноклассниках на этот URL оправляется только уведомление [`get_item`](https://dev.vk.ru/ru/api/payments/notifications/get-item) для получения информации о виртуальном товаре. Подробнее — в разделе [Обработка платёжных уведомлений в](https://dev.vk.ru/ru/api/payments/notifications/ok) [Одноклассниках](https://dev.vk.ru/ru/api/payments/notifications/ok).

- URL-адреса для платёжных уведомлений ВКонтакте и Одноклассников должны быть разными.

### URL для платёжных уведомлений Одноклассников

Эта настройка указывает URL на сервере игры, на который будут отправляться запросы о покупке виртуальных ценностей и подписок в Одноклассниках. Подробнее — в разделе [Обработка](https://dev.vk.ru/ru/api/payments/notifications/ok) [платёжных уведомлений в Одноклассниках](https://dev.vk.ru/ru/api/payments/notifications/ok).

### Тестировщики платежей

Список [администраторов игры](https://dev.vk.ru/ru/games/settings/managers), для которых платежи будут работать в тестовом режиме. Средства со счетов этих пользователей при выполнении платежей не списываются.

Если игра не прошла модерацию и не попала в каталог, то платежи доступны только пользователям, указанным в списке Тестировщики платежей. После модерации и публикации в каталоге платежи становятся доступны всем пользователям, но для тестировщиков платежей они продолжают работать в тестовом режиме.

Подробнее о тестировании платежей ВКонтакте и в Одноклассниках — в разделе [Тестирование](https://dev.vk.ru/ru/api/payments/testing) [платежей](https://dev.vk.ru/ru/api/payments/testing).

### Версия API

Формат платёжных уведомлений может меняться при изменении API ВКонтакте. Используйте эту настройку, чтобы указать версию API ВКонтакте, ожидаемую сервером игры. Платформа ВКонтакте будет отправлять серверу игры уведомления в формате, который поддерживается в указанной версии.

Настройка особенно актуальна для игр, которые были зарегистрированы на платформе до января 2024 года. Игры, зарегистрированные позже, используют формат платёжных уведомлений, принятый в версии 5.132 API ВКонтакте. Описание формата — в разделе [Платежи](https://dev.vk.ru/ru/api/payments/overview) [виртуальной валютой](https://dev.vk.ru/ru/api/payments/overview).

## Логи

При продаже товаров и подписок платформа ВКонтакте отправляет серверу игры запросы для получения информации о товарах и уведомления об оплате или возврате.

Вкладка Логи содержит журнал таких сообщений. Используйте эту информацию для отладки платежей в вашей игре и проверки обмена данными.

Описание параметров и форматов данных — в разделе [Платежи виртуальной валютой](https://dev.vk.ru/ru/api/payments/overview).

## Оплата голосами

Игра может принимать платежи виртуальной валютой после того, как она будет размещена в [каталоге игр](https://dev.vk.ru/ru/games/catalog/overview).

Чтобы опубликовать игру в каталоге, отправьте её на проверку модераторам ВКонтакте. Подробности добавления в каталог — в разделе [Как попасть в каталог](https://dev.vk.ru/ru/games/catalog/moderation).

Важно! До отправки заявки убедитесь, что зарегистрировались в [кабинете выплат](https://cashout.vk.com/) и что платежи в вашей игре работают правильно. Они заработают для всех пользователей сразу после прохождения модерации.

Подробнее о регистрации в кабинете выплат и получении вознаграждения — в разделе [Вывод](https://dev.vk.ru/ru/games/monetization/withdrawal/overview) [средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).
