# Вывод

**Раздел:** VK Games → Панель управления → Платежи → Вывод  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Вывод (настройки игр)

В разделе Вывод вы можете посмотреть баланс голосов и перейти в кабинет выплат, чтобы вывести голоса и ОКи.

Подробнее — в разделе [Вывод средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).

Чтобы открыть раздел:

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).

2. Откройте настройки нужной игры.

3. В меню слева выберите Платежи → Вывод.

## Доступ

- Раздел отображается только после того, как модераторы одобрят заявку на размещение игры в каталоге. Отправить заявку вы можете в разделе [Модерация](https://dev.vk.ru/ru/games/settings/moderation).
- Раздел доступен:

- Создателю игры.
- Администратору с полным доступом.

Подробнее о правах — в разделе [Администраторы](https://dev.vk.ru/ru/games/settings/managers).
