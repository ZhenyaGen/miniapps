# Библиотека VK Bridge

**Раздел:** VK Games → Библиотека VK Bridge  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Платформа HTML5-игр Direct Games и платформа игр на vk.com используют для взаимодействия с ВКонтакте библиотеку VK Bridge. Подробнее о том, как подключить и использовать библиотеку, читайте в разделе [VK Bridge | Первые шаги](https://dev.vk.ru/ru/bridge/getting-started).

## События VK Bridge

Библиотека VK Bridge включает события для реализации различных механик в игре: управления доступом, монетизации, взаимодействия с пользователями, работы с датчиками мобильных устройств и многого другого. Эти механики обеспечивают широкие возможности для создания функциональных и интересных игр на платформе ВКонтакте.

Подробнее обо всех событиях, которые доступны в библиотеке, – в разделе [VK Bridge | Обзор](https://dev.vk.ru/ru/bridge/overview).
