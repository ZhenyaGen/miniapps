# Права доступа

**Раздел:** VK Games → Архив → Права доступа  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Информация на странице устарела. Теперь игра будет запрашивать права доступа во время своей работы — перед первым использованием функциональности, для которого нужно разрешение.

Игре могут потребоваться разрешения пользователя на выполнение различных действий, например на получение информации о друзьях пользователя или на отправку уведомлений.

## Режимы запроса прав

Игра может запрашивать разрешения при первом запуске, во время игрового процесса либо использовать комбинированный подход.

Администраторы игры устанавливают режим запроса в настройках игры. Доступны следующие варианты:

- При запуске игры
- По мере необходимости
- По мере необходимости (тестовый режим)

### При запуске игры

На старте игра покажет экран с информацией о требуемых правах. Нажатие на кнопку «Запустить игру» означает согласие пользователя на предоставление требуемых разрешений.

Конкретные права и разрешения, которые игра запрашивает и которые будут отображены в списке, вы можете указать в настройке Права доступа при запуске.

О значениях в этом списке мы расскажем ниже, в разделе Подробнее о правах доступа при запуске.

При необходимости игра может запросить дополнительные права в процессе работы.

### По мере необходимости

Игра не показывает информацию о необходимых правах на старте, пользователь сразу переходит к игровому экрану. Игра будет запрашивать права доступа во время своей работы — перед первым использованием функциональности, для которой нужно разрешение. Например, если код игры вызывает событие библиотеки [VK Bridge](https://dev.vk.ru/ru/bridge/overview) для [отправки запроса друзьям пользователя](https://dev.vk.ru/ru/games/promotion/game-mechanics/overview), игровая платформа запросит разрешение пользователя на выполнение таких действий.

Режим По мере необходимости используется в играх по умолчанию.

### По мере необходимости (тестовый режим)

Когда выбрано это значение, режим По мере необходимости будет работать только для пользователей, добавленных в список тестировщиков. Для остальных пользователей права будут запрашиваться в режиме При запуске игры.

## Выбор режима запроса прав

1. Перейдите на страницу [Мои приложения](https://vk.com/apps?act=manage), найдите игру в списке и нажмите на ссылку Редактировать напротив неё.

2. В левом меню переключитесь в раздел Настройки. Прокрутите страницу вниз до блока Запрос прав.

3. Выберите режим запроса прав для игр Direct Games и Web.

4. Если вы выбрали режим При запуске игры для какого-то типа игр, нажмите на ссылку в настройке Права доступа при запуске и в выпадающем списке выберите необходимые разрешения.

Сохраните изменения.

## Подробнее о правах доступа при запуске

Права доступа, которые игра запрашивает во время запуска, определяют, может ли игра выполнить API-запросы, которые оперируют данными пользователя. Ключ доступа, который игра получает при запуске в параметре [`access_token`](https://dev.vk.ru/ru/games/development/parameters), разрешает работу тех или иных API-методов.

Обратите внимание, что настройка Права доступа при запуске работает и для игр Web, и для игр Direct Games, если для них выбран режим При запуске игры.

## Запрос прав во время выполнения

### Общая схема

Чтобы проверить, что у вашей игры есть права на выполнение какого-либо API-метода, вызовите событие [`VKWebAppCheckAllowedScopes`](https://dev.vk.ru/ru/bridge/VKWebAppCheckAllowedScopes) библиотеки [VK Bridge](https://dev.vk.ru/ru/bridge/overview).

Для запроса новых прав используйте событие [`VKWebAppGetAuthToken`](https://dev.vk.ru/ru/bridge/VKWebAppGetAuthToken). При успешном выполнении вызов вернёт новый ключ доступа для использования в API-запросах.

Обратите внимание, что возвращаемый ключ доступа ограничен в действии по времени: он устареет в течение суток. Поэтому не откладывайте API-вызов с использованием ключа.

Ниже в этом разделе приведён пример объекта, который позволяет получать права и вызывать тот или иной API-метод. Общая схема его использования выглядит следующим образом:

```js
// Использование
const requestAPIHelper = new RequestAPIHelper(appId, accessToken,
allowedScopes);
requestAPIHelper.trySendRequest(apiMethodName, scope, paramsMethod)
  .then( (data) => {
    // Обработка данных пользователя,
    // полученных в ответе на запрос к API.
  })
  .catch( (err) => {
    // Обработка ошибки,
    // полученной в ответе на API-запрос.
  })
```

## FAQ

#### Когда лучше запрашивать доступ к данным?

Мы рекомендуем запрашивать доступ к данным непосредственно перед тем, как их использовать.

Накопленная статистика говорит, что если запрашивать все разрешения на экране при первом запуске, игра теряет больший процент аудитории, чем при отдельных запросах в процессе работы.

Можно использовать комбинированный подход: при запуске запрашивать только права, необходимые для старта игры и выполнения первого запроса, а другие права запрашивать позже по мере необходимости.

#### Как узнать, какие права есть у игры в момент запуска?

Информация о доступных правах передаётся в игру при запуске в параметре

[`access_token_settings`](https://dev.vk.ru/ru/games/development/parameters#%D0%9F%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B) [.](https://dev.vk.ru/ru/games/development/parameters#%D0%9F%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B)

#### Что такое первый запрос к API?

Информация устарела. Теперь первый запрос к API не нужен.

Первый запрос к API выполняется при запуске игры. Обычно он используется, чтобы получить некоторые данные о пользователе и отобразить их в интерфейсе игры. Например, можно получить имя и фото профиля пользователя, список его друзей, участвующих в игре, их очки.

Для выполнения первого запроса у игры должны быть права, которые этому запросу требуются для работы. Например, метод [`users.get`](https://dev.vk.ru/ru/method/users.get) будет успешно выполнен в первом запросе к API, так как он не требует дополнительных прав. Но метод [`friends.getAppUsers`](https://dev.vk.ru/ru/method/friends.getAppUsers) будет успешно выполнен только после получения игрой права доступа `friends`.

Что делать, если событие `VKWebAppCheckAllowedScopes` не возвращает данные?

Обновите мобильное приложение ВКонтакте до последней версии.

Также возможно, что версия библиотеки VK Bridge, которую вы используете, не поддерживает событие. Чтобы это проверить, используйте метод `bridge.supportsAsync()`, например:

```js
bridge.supportsAsync('VKWebAppCheckAllowedScopes').then( res => {
    if (res) {
        bridge.send('VKWebAppCheckAllowedScopes');
    }
})
```

[Обновите библиотеку](https://github.com/VKCOM/vk-bridge) при необходимости.
