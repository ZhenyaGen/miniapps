# Добавление рекламы в код игры

**Источник:** документация VK для разработчиков (dev.vk.com)

## Как добавить рекламу в игру

Важно! Пока игра не прошла модерацию и не попала в каталог, вся реклама отображается в тестовом режиме. Чтобы показы рекламы в вашем приложении начали учитываться, зарегистрируйтесь в [кабинете выплат](https://cashout.vk.com/) и пройдите [модерацию](https://dev.vk.ru/ru/games/settings/moderation).

Подробнее о регистрации в кабинете выплат и получении вознаграждения — в разделе [Вывод](https://dev.vk.ru/ru/games/monetization/withdrawal/overview) [средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).

Игры получают рекламные материалы от рекламной сети ВКонтакте. Для их показа используйте библиотеку [VK Bridge](https://dev.vk.ru/ru/bridge/overview). В этом разделе мы рассмотрим, как вы можете вставить рекламные материалы в игру.

## Реклама за вознаграждение и реклама между экранами

### Требования

Для показа рекламы за вознаграждение и рекламы между экранами подключите к игре библиотеку VK Bridge. Пошаговая инструкция — в разделе [Первые шаги](https://dev.vk.ru/ru/bridge/getting-started#%D0%9F%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5%20VK%20Bridge).

### Принцип работы

Чтобы показать рекламу в игре, её контент (изображения, текст, видео) надо загрузить на устройство пользователя. При старте игры библиотека VK Bridge автоматически отправляет запрос платформе ВКонтакте на предзагрузку рекламных материалов. Предзагрузка выполняется в фоновом режиме и незаметна пользователю. Предзагруженные материалы хранятся на стороне пользователя.

В нужный момент времени игра отдаёт команду на показ рекламы, и библиотека показывает её. Если по какой-то причине предзагруженных материалов нет, библиотека отправит платформе запрос на их получение. В общем случае это может приводить к некоторой задержке при старте показа.

После показа рекламы VK Bridge автоматически запрашивает новую порцию рекламных материалов у платформы: ВКонтакте старается разнообразить контент, чтобы пользователи не смотрели один и тот же ролик несколько раз подряд.

### Необходимые события VK Bridge

- [`VKWebAppCheckNativeAds`](https://dev.vk.ru/ru/bridge/VKWebAppCheckNativeAds) — отправьте это событие, чтобы проверить, есть ли на стороне пользователя рекламные материалы, готовые для показа. Если материалов нет, метод отправит запрос платформе на их загрузку.

Такая проверка необходима для показа [рекламы за вознаграждение](https://dev.vk.ru/ru/games/monetization/ad/overview#%D0%A0%D0%B5%D0%BA%D0%BB%D0%B0%D0%BC%D0%B0%20%D0%B7%D0%B0%20%D0%B2%D0%BE%D0%B7%D0%BD%D0%B0%D0%B3%D1%80%D0%B0%D0%B6%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5) (rewarded ad). В соответствии с [нашими требованиями](https://dev.vk.ru/ru/games/monetization/ad/overview#%D0%A0%D0%B5%D0%BA%D0%BB%D0%B0%D0%BC%D0%B0%20%D0%B7%D0%B0%20%D0%B2%D0%BE%D0%B7%D0%BD%D0%B0%D0%B3%D1%80%D0%B0%D0%B6%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5), игра должна получить согласие пользователя на просмотр такой рекламы, например показать запрос «Посмотрите короткий ролик, чтобы прокачать героя».

Вызов `VKWebAppCheckNativeAds` помогает понять, есть ли рекламные материалы, готовые для показа, и можно ли отобразить на экране кнопку «Посмотрите рекламу». Если показать кнопку, когда материалов нет, пользователь ничего не увидит — то есть нажатие на кнопку ни к чему не приведёт.

- [`VKWebAppShowNativeAds`](https://dev.vk.ru/ru/bridge/VKWebAppShowNativeAds) — показывает рекламу пользователю на экране. Метод пытается отобразить предзагруженные материалы. Если по какой-то причине они отсутствуют, метод запросит их у платформы и покажет при получении.

После показа рекламы метод автоматически запрашивает новые рекламные материалы у платформы.

Оба метода возвращают `Promise` -объекты. Результаты надо проверять в `then` - и `catch` - обработчиках этих объектов.

#### Примечания

- Предварительный вызов `VKWebAppCheckNativeAds` и предзагрузка рекламных материалов в общем случае необязательны для работы `VKWebAppShowNativeAds`. Однако предзагрузка позволяет запустить показ без задержек. Кроме того, проверка необходима для показа рекламы за вознаграждение. Подробнее — в разделе Необходимые события VK Bridge.
- Загрузка материалов может занимать какое-то время. Если вы расположите вызовы

`VKWebAppCheckNativeAds` и `VKWebAppShowNativeAds` друг за другом в коде, то не получите выигрыша в скорости при старте показа. Имеет смысл разнести загрузку и показ рекламы и не показывать рекламу слишком часто.
- Запрос на загрузку рекламных материалов может быть не выполнен. Обычно это происходит из- за низкой скорости интернет-соединения или кратковременных сбоев в работе сети.

Чтобы обойти эту проблему, ваша игра может вызывать `VKWebAppCheckNativeAds` по таймеру во время своей работы, чтобы гарантированно получить материалы ко времени показа.

Метод `VKWebAppCheckNativeAds` не запрашивает новые материалы, если предзагруженные ещё не были показаны пользователю.

    if (data.result) {
      // Предзагруженная реклама есть.

## Баннерная реклама

Чтобы добавить баннерную рекламу в игру, используйте событие [`VKWebAppShowBannerAd`](https://dev.vk.ru/ru/bridge/VKWebAppShowBannerAd) библиотеки [VK Bridge](https://dev.vk.ru/ru/bridge/overview). При успешном выполнении платформа вернёт данные рекламного баннера.

```js
bridge.send('VKWebAppShowBannerAd', {
  banner_location: 'bottom'
  })
  .then((data) => {
    if (data.result) {
      // Баннерная реклама отобразилась
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

Подробнее о баннерной рекламе и использовании событий библиотеки VK Bridge — в разделе [Баннерная реклама](https://dev.vk.ru/ru/games/monetization/ad/banners).
