# Параметры запуска приложения

**Раздел:** Использование API → Параметры запуска приложения  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Параметры запуска игр и мини-приложений

При запуске игры или мини-приложения ВКонтакте в него передаются данные об источнике запуска, пользователе, его правах доступа и другая информация.

## Игры

Подробнее о параметрах запуска игр — в разделе [Список параметров](https://dev.vk.ru/ru/games/development/parameters).

Также в разделе [Архив](https://dev.vk.ru/ru/games/development/parameters/old) приведены устаревшие параметры запуска. Архивные параметры не используются в играх, которые были созданы после 8 августа 2024 года.

## Мини-приложения

Подробнее о параметрах запуска мини-приложений — в разделе [Список параметров](https://dev.vk.ru/ru/mini-apps/development/launch-params).
