# Рекламный API

**Раздел:** API ВКонтакте → Реклама → Рекламный API  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Что это такое?

Автоматизируйте работу с таргетированной рекламой ВКонтакте с помощью методов API — создавайте креативы, запускайте объявления и целые рекламные кампании, редактируйте настройки и получайте статистику.

Возможности рекламного API:

- Cоздание и редактирование кампаний и объявлений.
- Автоматизированная выгрузка статистики.
- Управление и обновление аудиторий ретаргетинга.
- Добавление клиентов, наблюдателей и администраторов в рекламный кабинет.

## Работа с API

Перед вызовом методов API необходимо [получить ключ доступа пользователя](https://dev.vk.ru/ru/api/access-token/user-token). После этого вы сможете выполнять любые запросы к API по [стандартной схеме взаимодействия](https://dev.vk.ru/ru/api/api-requests).

Важно! Перед началом работы с рекламным API ознакомьтесь с ограничениями и рекомендациями.

Выбирайте нужные методы для работы в зависимости от задач — [здесь](https://dev.vk.ru/ru/method/ads) мы собрали методы, которые пригодятся для работы с рекламой.

При работе иногда могут возникать ошибки, но не стоит их бояться. Понять, что пошло не так, поможет [список ошибок](https://dev.vk.ru/ru/reference/errors).

## Готовые инструменты

Используйте готовые решения наших партнеров для быстрой настройки и автоматизации рекламы:

- [Active Traffic](https://www.activetraffic.ru/) — массовое создание и настройка объявлений, аналитика и статистика, автоматические тактики.
- [Aori](https://aori.ru/) — единая платформа для управления рекламой с простым интерфейсом.
- [Atuko](https://atuko.ru) — массовое создание и редактирование рекламных кампаний с помощью Excel-генератора, подключение сторонней аналитики, массовое копирование и перенос кампаний из одного аккаунта в другой, гибкая настройка и выгрузка отчетов.
- [eLama](https://elama.ru/tools/) — калькулятор выгодной ставки за клик, быстрый конструктор креативов, импорт лидов.
- [ERESH](https://eresh.zemedia.ru/) — устраняет рутину при подготовке и управлении кампаниями: помогает с медиапланом, с расчётом бюджета. Сегментирует объявления, управляет ставками, показывает расширенную статистику.
- [Kairos](https://kairos.zemedia.ru/) — управляет кампаниями. Позволяет сделать максимальный выкуп горячей аудитории, достичь заданного охвата или заданного расхода бюджета к дедлайну. Рентабелен для месячных бюджетов от 300 тыс. рублей.

- [Marilyn](https://mymarilyn.ru/) — оптимизация рекламных кампаний, управление ставками под заданные KPI, автоматизация рутинных процессов.
- [Plarin](https://www.plarin.net/) — массовое редактирование объявлений. Библиотека шаблонов креативов, их массовое создание. Оптимизация ставок, автоматическая сегментация, графические отчёты.
