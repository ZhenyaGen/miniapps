# API историй

**Раздел:** API ВКонтакте → Истории → API историй  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Статистика историй ВКонтакте — 12 миллионов авторов, 71 миллион историй, 4,4 миллиарда просмотров от 46 миллионов пользователей каждый месяц. Загружать истории с помощью API могут любые пользователи и сообщества.

#### Как работать с API историй

Пошаговая инструкция при работе с API Историй ВКонтакте заключает в себе несколько шагов:

1. Авторизуйте пользователя ВКонтакте [одним из этих способов](https://dev.vk.ru/ru/api/access-token/getting-started) или с помощью наших SDK для [Android](https://dev.vk.ru/ru/sdk/android) и [iOS](https://dev.vk.ru/ru/sdk/ios).

2. Подготовьте историю — фотографию или видео.

3. Если вы разрабатываете мини-приложение, опубликуйте историю с помощью редактора историй (событие [`VKWebAppShowStoryBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowStoryBox)).

4. Если вы работаете над другим приложением, размещайте историю с помощью методов секции [`Stories`](https://dev.vk.ru/ru/method/stories). Сначала получите адрес для загрузки с помощью [`stories.getPhotoUploadServer`](https://dev.vk.ru/ru/method/stories.getPhotoUploadServer) [,](https://dev.vk.ru/ru/method/stories.getPhotoUploadServer) затем загрузите фотографию или видео и сохраните историю, воспользовавшись [`stories.save`](https://dev.vk.ru/ru/method/stories.save) [.](https://dev.vk.ru/ru/method/stories.save)

История появится в новостях у друзей и подписчиков пользователя в зависимости от настроек приватности. [С помощью API](https://dev.vk.ru/ru/method/stories) можно также управлять историями и следить за количеством просмотров.
