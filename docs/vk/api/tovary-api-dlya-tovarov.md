# API для товаров

**Раздел:** API ВКонтакте → Товары → API для товаров  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Добавлять [товары в сообщества](https://dev.vk.ru/ru/api/market/overview) ВКонтакте можно вручную или программно, с помощью API ВКонтакте. Мы объединили такие запросы в группу [`market`](https://dev.vk.ru/ru/method/market). Этот раздел рассказывает, как их использовать.

## Подготовка к работе

### 1. Подготовьте сообщество

Сообщества ВКонтакте могут содержать материалы разных видов. Один из них — товары. По умолчанию товары в сообществах отключены. Для работы API-запросов их необходимо подключить.

Подключить товары может администратор сообщества.

1. Откройте страницу сообщества и в меню справа нажмите на Управление.

2. Перейдите в Настройки → Разделы.

3. Включите раздел Товары.

### 2. Зарегистрируйте приложение

Чтобы выполнить API-запрос ВКонтакте, нужно указать ключ доступа. Для получения ключа зарегистрируйте приложение в сервисе авторизации VK ID. Регистрировать приложение нужно для любого сервиса или сайта, который будет использовать API.

1. В браузере откройте страницу [id.vk.com/business/go](https://id.vk.com/business/go?utm_source=dev_vk&utm_medium=referral&utm_campaign=docs_api_market_getting_Started_link_VKID).

2. Войдите в сервис авторизации под своим аккаунтом VK ID и разрешите запрашивать доступ к данным вашего аккаунта.

Далее возможны варианты:

- Если у вас уже есть [профиль бизнеса в VK Бизнес ID](https://id.vk.ru/about/faq/business/vkbid), сервис авторизации создаст личный кабинет на основе данных из бизнес-профиля и вы сможете перейти к следующему шагу.

Если у вас есть несколько профилей бизнеса, выберите нужный — сервис авторизации создаст личный кабинет на основе данных из бизнес-профиля и вы сможете перейти к следующему шагу.

## • Если вы ранее не пользовались VK Бизнес ID, в сервисе авторизации нажмите Моё пространство и выберите Новый профиль бизнеса. Сервис авторизации перенаправит вас на форму [создания профиля бизнеса](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/intro/plan#Sozdanie-profilya-biznesa). Создайте профиль бизнеса, чтобы перейти к следующему шагу.

3. После создания профиля бизнеса нажмите Добавить приложение. Откроется форма регистрации приложения.

4. Введите название приложения и выберите платформы, на которых оно будет работать, затем нажмите Далее:

| Платформа | Когда использовать |
|---|---|
| Android или iOS | Если запросы будут отправляться из клиентской части мобильных приложений, работающих на Android или iOS. |

Web Если запросы будут отправляться из серверной части приложений или из desktop- приложений.

5. На следующей странице укажите базовый домен и доверенный Redirect URL и нажмите Создать приложение.

На ваше мобильное устройство придёт запрос с подтверждением регистрации. После подтвержения приложение будет добавлено в сервис авторизации VK ID.

Вы можете настроить [способы быстрого входа](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/intro/main) в веб-приложение сразу либо сделать это позже в настройках.

Подробнее — в разделе [Создание приложения](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application#Sozdanie-prilozheniya) документации VK ID.

### 3. Включите доступ к товарам

После создания приложения вы можете настраивать его в [личном кабинете](https://id.vk.com/about/business/go).

Вам необходимо включить расширенный доступ Товары. Чтобы его включить, пройдите [верификацию](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/verification) и напишите на почту [devsupport@corp.vk.com](mailto:devsupport@corp.vk.com).

### 4. Запустите авторизацию

В результате авторизации пользователя вы получите значение `code`, которое нужно обменять на ключ доступа пользователя.

Подготовьте параметры для авторизации и откройте в браузере URL следующего вида:

#### URL

```
https://id.vk.com/authorize?
response_type=code&client_id=12345&scope=email%20phone&redirect_uri=https%3A%2
F%2Fyour.site&state=XXXRandomZZZ&code_challenge=K8KAyQ82WSEncryptedVerifierGYU
Dj8K&code_challenge_method=S256
```

Полное описание параметров — в разделе [Авторизация без SDK](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/auth-without-sdk/auth-without-sdk-web) документации VK ID.

### 5. Получите ключ доступа

После успешного входа в VK ID произойдёт редирект на адрес, указанный в `redirect_uri`. Данные авторизации пользователя вы найдёте в `url` в параметре `payload`.

Чтобы получить ключ доступа, обменяйте значение `code` в параметре `payload` на ключ доступа с помощью запроса:

```bash
curl -X POST 'https://api.vk.ru/method/market.edit' \
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'owner_id=-123456' \
  -F 'item_id=10243117' \
  -F 'main_photo_id=457239024' \
  -F 'v=5.199'
```

После получения ключа доступа вы готовы к работе с API ВКонтакте. Время жизни токена — 1 час. Когда оно истечёт, нужно получить новый.

Подробнее — в разделе [Обработка результата авторизации](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/auth-without-sdk/auth-without-sdk-web#Obrabotka-rezultata-avtorizacii) документации VK ID.

## Работа с товарами

### Добавление товара

#### Подготовка

- Каждый товар должен принадлежать какой-то категории. Идентификатор категории надо будет указать при добавлении товара.
- Чтобы указать картинку товара, изображение надо предварительно загрузить в сообщество. Этот процесс включает несколько шагов. Подробности — в разделе [Загрузка фотографии для](https://dev.vk.ru/ru/api/upload/photo-in-market) [товара в сообществе](https://dev.vk.ru/ru/api/upload/photo-in-market).

Фотографию можно указать при добавлении товара в сообщество или позже, при редактировании свойств товара.

#### Добавление товара в сообщество

Чтобы добавить товар в сообщество, отправьте API-запрос [`market.add`](https://dev.vk.ru/ru/method/market.add). Передайте следующие обязательные параметры:

| Обязательный параметр | Описание |
|---|---|
| `owner_id` | Идентификатор вашего сообщества. |
| Идентификатор сообщества — отрицательное число, поэтому в параметре | указывайте его со знаком «минус». |
| `name` и `description` | Название и описание товара. |
| `category_id` | Идентификатор категории товара. Если вы не знаете идентификатор нужной категории, укажите значение `1`. |

Также в запросе вы можете указать необязательные параметры.

| Необязательный параметр | Описание |
|---|---|
| `price` | Цена товара. Формат данных: строка. |
| `main_photo_id` и `photo_ids` | Идентификаторы основной и дополнительной фотографии товара. |

Идентификаторы — строки в формате

`market{owner_id}_{market_item_id}`, например `market-12345_54321`. Вы получаете их при загрузке фотографий для товаров и подписок.

`deleted` Доступен ли товар пользователям. Если товар пока недоступен, передайте

`deleted = 1`. В этом случае пользователи не будут его видеть.

### Действия с заказами

Чтобы получать информацию о заказах, используйте следующие API-запросы:

| API-запрос | Описание |
|---|---|
| [`market.getGroupOrders`](https://dev.vk.ru/ru/method/market.getGroupOrders) | Возвращает информацию о заказах в сообществе. |
| [`market.getOrderById`](https://dev.vk.ru/ru/method/market.getOrderById) | Возвращает информацию о заказе по его идентификатору. |
| [`market.getOrderItems`](https://dev.vk.ru/ru/method/market.getOrderItems) | Возвращает информацию о товарах в заказе. |

Для редактирования свойств заказа, например изменения его статуса, используйте API-запрос

[`market.editOrder`](https://dev.vk.ru/ru/method/market.editOrder) [.](https://dev.vk.ru/ru/method/market.editOrder)

При создании или изменении заказа ВКонтакте отправляет [события](https://dev.vk.ru/ru/api/community-events/json-schema) `market_order_new` и

`market_order_edit` вашему сообществу. Для обработки этих событий используйте инструменты [Callback API](https://dev.vk.ru/ru/api/callback/getting-started) или [Bots Longpoll API](https://dev.vk.ru/ru/api/bots-long-poll/getting-started). Вы можете сконфигурировать их в настройках сообщества.

### Работа с подборками товаров

Товары в сообществе можно объединять в подборки. Для работы с подборками используйте следующие API-запросы:

| API-запрос | Описание |
|---|---|
| [`market.addToAlbum`](https://dev.vk.ru/ru/market.addToAlbum) | Добавление товара в одну или несколько подборок. |
| [`market.addAlbum`](https://dev.vk.ru/ru/market.addAlbum) | Создание новой подборки товаров. |
| [`market.getAlbums`](https://dev.vk.ru/ru/market.getAlbums) | Получение списка подборок товаров в сообществе. |
| [`market.getAlbumById`](https://dev.vk.ru/ru/market.getAlbumById) | Получение подборки по её идентификатору. |
| [`market.editAlbum`](https://dev.vk.ru/ru/market.editAlbum) | Редактирование параметров подборки. |
| [`market.reorderItems`](https://dev.vk.ru/ru/market.reorderItems) | Сортировка товаров в подборке. |

### Группы товаров

Товары с одинаковыми значениями свойств можно объединять в группы. Для работы с группами используйте следующие API-запросы:

| API-запрос | Описание |
|---|---|
| [`market.groupItems`](https://dev.vk.ru/ru/method/market.groupItems) | Объединение товаров в группу. |
| [`market.ungroupItems`](https://dev.vk.ru/ru/method/market.ungroupItems) | Удаление группы. |

### Свойства товаров

С помощью API-запросов вы можете добавлять свойства, например «Цвет», «Размер» или «Возрастная группа», к товарам, находящимся в одной группе. Для таких свойств вы также можете указывать возможные значения. Используйте для этого следующие API-запросы:

| API-запрос | Описание |
|---|---|
| [`market.addProperty`](https://dev.vk.ru/ru/method/market.addProperty) | Добавляет свойство к товарам в группе, например «Размер» или «Цвет». |
| [`market.editProperty`](https://dev.vk.ru/ru/method/market.editProperty) | Изменяет название или тип свойства товаров в сообществе. |
| [`market.deleteProperty`](https://dev.vk.ru/ru/method/market.deleteProperty) | Удаляет свойство товаров в сообществе. |
| [`market.addPropertyVariant`](https://dev.vk.ru/ru/method/market.addPropertyVariant) | Добавляет возможное значение свойства товаров в сообществе. Например, если вы добавили свойство «Цвет», вы можете добавить его возможные значения — «Красный» или «Фиолетовый в крапинку». |
| [`market.editPropertyVariant`](https://dev.vk.ru/ru/method/market.editPropertyVariant) | Редактирует параметры значения свойства товаров. |

| API-запрос | Описание |
|---|---|
| [`market.deletePropertyVariant`](https://dev.vk.ru/ru/method/market.deletePropertyVariant) | Удаляет возможное значение свойства товаров в сообществе. |
