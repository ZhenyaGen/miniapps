# Ключ доступа сообщества

**Раздел:** Использование API → Ключи доступа → Ключ доступа сообщества  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Ключ доступа (токен) сообщества позволяет вызывать методы VK API от имени сообщества или публичной страницы. Такой ключ доступа нужен в сценариях, где действие должно выполняться от имени сообщества — например, для переписки с подписчиками. При создании ключа доступа сообщества ему предоставляются определённые права.

Способ получения ключа доступа зависит от типа приложения и от того, где выполняется код: в серверной или клиентской части приложения.

| Способ получения | Для каких приложений | Где использовать |
|---|---|---|
| Настройки сообщества Любое приложение или сайт (Standalone-приложение) | Серверная часть | приложения |
| OAuth ВКонтакте — Authorization Code Flow | Любое приложение или сайт (Standalone-приложение) | Серверная часть приложения |
| OAuth ВКонтакте — Implicit Flow Любое приложение или сайт (Standalone-приложение) | Клиентская часть | приложения |
| Событие | Мини‑приложение или плагин ВКонтакте | Клиентская часть приложения |

`VKWebAppGetCommunityToken`

## Особенности работы

- Получить ключ доступа может только администратор этого сообщества.
- Срок действия ключа доступа сообщества не ограничен. Если ключ скомпрометирован, вы можете его отозвать.
- Все созданные ключи доступа отображаются в настройках сообщества.

## Права доступа

Права доступа определяют, с какими разделами данных может работать ключ доступа. Например, для получения фотографий сообщества нужен ключ доступа с правами `photos`. Подробнее — в разделе [Права доступа и приватность](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D0%B4%D0%BB%D1%8F%20%D0%BA%D0%BB%D1%8E%D1%87%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D1%81%D0%BE%D0%BE%D0%B1%D1%89%D0%B5%D1%81%D1%82%D0%B2%D0%B0).

## Получить ключ

### Настройки сообщества

Самый простой способ получить ключ доступа — создать его в настройках вашего сообщества. В настройках можно создать несколько ключей с разным набором прав, а также в любой момент отозвать ключ. Чтобы создать ключ:

1. Откройте сообщество, в котором вы являетесь администратором.

2. В меню справа выберите Управление → Дополнительно → Работа с API.

3. На вкладке Ключи доступа нажмите Создать ключ.

4. Выберите права доступа для ключа и нажмите Создать.

5. Подтвердите действие в мобильном приложении ВКонтакте или по СМС.

После подтверждения ключ появится на вкладке Ключи доступа.

### OAuth ВКонтакте

Этот способ подходит, если вы хотите получать ключ доступа сообщества программно.

1. Получите список сообществ, в которых пользователь является администратором. Для этого необходимо выполнить запрос [`groups.get`](https://dev.vk.ru/ru/method/groups.get) с параметром `filter=admin`.

2. Запросите ключ доступа сообщества при помощи одного из сценариев:

- Если вызовы VK API выполняются на сервере приложения, используйте Authorization Code Flow. Ключ доступа, полученный этим способом, не привязан к IP‑адресу.

Подробнее — в документации VK ID: [Authorization Code Flow для получения Access token](https://id.vk.com/about/business/go/docs/ru/vkid/latest/oauth/oauth-vkontakte/authcode-flow-community) [сообщества](https://id.vk.com/about/business/go/docs/ru/vkid/latest/oauth/oauth-vkontakte/authcode-flow-community).
- Если вызовы VK API выполняются в клиентском коде на устройстве администратора сообщества, используйте Implicit Flow.

Подробнее — в документации VK ID: [Implicit Flow для получения Access token сообщества](https://id.vk.com/about/business/go/docs/ru/vkid/latest/oauth/oauth-vkontakte/implicit-flow-community).

### Событие VK Bridge

Если вы разрабатываете мини‑приложение и вызываете VK API из клиентского кода, ключ доступа сообщества можно запросить через событие `VKWebAppGetCommunityToken` библиотеки VK Bridge. Этот вариант обычно используют в [приложениях сообществ](https://dev.vk.ru/ru/mini-apps/development/community-apps).

Подробнее — в описании события [`VKWebAppGetCommunityToken`](https://dev.vk.ru/ru/bridge/VKWebAppGetCommunityToken) [.](https://dev.vk.ru/ru/bridge/VKWebAppGetCommunityToken)

## Отозвать ключ доступа сообщества

Все созданные ключи доступа отображаются в настройках сообщества в разделе Управление → Дополнительно → Работа с API на вкладке Ключи доступа.

Чтобы отозвать ключ, выберите его из списка и нажмите Удалить ключ или Удалить все ключи приложения.
