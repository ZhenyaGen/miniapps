# account.getAppPermissions

**Раздел:** account.getAppPermissions  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

[Account](https://dev.vk.ru/ru/method/account) account.getAppPermissions

Метод получает настройки пользователя вашего [приложения](https://vk.com/apps?act=manage).

Для вызова метода можно использовать:
- [ключ доступа пользователя](https://dev.vk.ru/ru/api/access-token/getting-started#%D0%9A%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8F)

Параметры

| `user_id` | Идентификатор пользователя, настройки которого необходимо получить. Значение по умолчанию: идентификатор текущего пользователя. |
|---|---|

positive

`Обязательный параметр`

Результат

Метод возвращает битовую маску прав доступа ( `integer`).

Примечание. Чтобы понять, что означает вернувшийся результат, смотрите раздел [Список](https://dev.vk.ru/ru/reference/access-rights) [возможных настроек прав доступа](https://dev.vk.ru/ru/reference/access-rights).

Пример ответа:

```json
{
  "response": 9355263
}
```

### Пример вычисления битовой маски

Битовая маска права на Доступ к друзьям и Доступ к статусам пользователя: `2 + 1024 = 1026`.

Чтобы проверить, какой доступ был выдан, используйте побитовую операцию `&`. Пример: вы имеете битовую маску `1026` и хотите проверить, имеет ли она доступ к друзьям. Выполните операцию `1026 & 2` и выведите результат `alert(1026 & 2);`.
