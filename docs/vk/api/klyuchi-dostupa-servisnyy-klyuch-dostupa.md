# Сервисный ключ доступа

**Раздел:** Использование API → Ключи доступа → Сервисный ключ доступа  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Сервисный ключ доступа используется для выполнения запросов к VK API, когда не требуется авторизация пользователя. Такие запросы считаются выполненными от имени игры, мини- приложения, Standalone-приложения. Сервисный ключ доступа также называют ключом доступа приложения.

Способ получения ключа доступа зависит от типа приложения, из которого выполняется запрос к VK API:

**Способ получения | Для каких приложений | Где использовать**

Панель управления Игра или мини-приложение Серверная часть приложения

| Cервис авторизации VK ID | Любое приложение или сайт (Standalone- приложение) | Серверная часть приложения |
|---|---|---|

## Особенности работы

- Срок действия сервисного ключа доступа не ограничен. Если сервисный ключ скомпрометирован, его можно обновить в настройках приложения.
- В целях безопасности используйте сервисный ключ только для выполнения запросов с серверной стороны вашего приложения. Не передавайте и не храните этот ключ в клиентской части.

## Права доступа

Для сервисного ключа не требуется запрашивать права доступа. Такой ключ используют при вызове методов, предназначенных для работы с играми и мини‑приложениями, например методов из [группы](https://dev.vk.ru/ru/method/apps) [`apps`](https://dev.vk.ru/ru/method/apps) [.](https://dev.vk.ru/ru/method/apps)

## Получить сервисный ключ доступа

### Панель управления dev.vk.com

VK генерирует сервисный ключ доступа при регистрации игры или мини-приложения на [портале](https://dev.vk.com/ru/admin/apps-list) [для разработчиков](https://dev.vk.com/ru/admin/apps-list). Администратор игры или мини-приложения может получить такой ключ в панели управления в разделе Разработка → Ключи доступа.

Подробнее:

- [Ключи доступа (настройки мини-приложений) — Сервисный ключ](https://dev.vk.ru/ru/mini-apps/settings/development/keys#%D0%A1%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BB%D1%8E%D1%87)
- [Ключи доступа (настройки игр) — Сервисный ключ](https://dev.vk.ru/ru/games/settings/development/keys#%D0%A1%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BB%D1%8E%D1%87)

### Сервис авторизации VK ID

VK ID генерирует сервисный ключ доступа при создании приложения в [кабинете сервиса](https://id.vk.com/about/business/go) [авторизации](https://id.vk.com/about/business/go).

Подробнее о параметрах приложения — в [документации VK ID](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application#Parametry-prilozheniya).
