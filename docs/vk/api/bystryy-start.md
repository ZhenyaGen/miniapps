# Быстрый старт

**Раздел:** Использование API → Быстрый старт  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

В статье приведена пошаговая инструкция для начала работы с VK API. Вы узнаете, как зарегистрировать приложение, получить ключ доступа и использовать его для выполнения запроса.

Чтобы начать работать с VK API, вам потребуется:

- Учётная запись VK ID. Подробнее — в [FAQ VK ID](https://id.vk.com/about/faq/users/registration_and_login/new_account/18019).
- Приложение, для которого вы получите ключ доступа к VK API. Подробнее — в разделе [Типы](https://dev.vk.ru/ru/general/app-types) [приложений](https://dev.vk.ru/ru/general/app-types).
- Ключ доступа. Подробнее — в разделе [Ключи доступа. Общие сведения](https://dev.vk.ru/ru/api/access-token/getting-started).

## Шаг 1. Зарегистрируйте приложение

Чтобы получить ключ доступа, сначала зарегистрируйте свой продукт в VK. Способ регистрации зависит от типа приложения:

## • Игра или мини-приложение VK

Такие приложения работают внутри интерфейса ВКонтакте или Одноклассников. Они могут получать информацию о пользователе, который их запустил, и не требуют дополнительной авторизации.

Чтобы зарегистрировать игру или мини-приложение, откройте [панель управления](https://dev.vk.com/ru/admin/apps-list) и в меню слева нажмите Создать приложение.

Подробнее о создании приложений VK:

## • [Игры. Первые шаги](https://dev.vk.ru/ru/games/getting-started) • [Мини-приложения. Первые шаги](https://dev.vk.ru/ru/mini-apps/getting-started) • Standalone‑приложение

Это внешнее приложение, которое использует VK API и работает вне интерфейса ВКонтакте. В таких приложениях пользователю нужно пройти авторизацию.

Чтобы зарегистрировать standalone‑приложение, откройте [кабинет сервиса авторизации VK ID](https://id.vk.com/business/go?utm_source=dev_vk&utm_medium=referral&utm_campaign=docs_api_getting_started_link_standalone) и нажмите Добавить приложение. Подробнее — в документации VK ID в разделе [Создание и](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application) [настройка приложения](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application).

С 10 апреля 2026 года создавать и редактировать standalone‑приложения можно только в сервисе авторизации VK ID.

## Шаг 2. Получите ключ доступа

При обращении к VK API в каждом запросе нужно передавать ключ доступа. Ключ определяет, от чьего имени выполняется запрос, и задаёт набор [прав доступа](https://dev.vk.ru/ru/api/privacy).

Способ получения ключа зависит от типа приложения, необходимых прав и от того, где выполняется запрос (клиент или сервер). В верхней части страницы каждого [метода](https://dev.vk.ru/ru/method) указано, какой

тип ключа подходит для его вызова.

Подробнее о том, как выбрать и получить ключ — в разделе [Ключи доступа. Общие сведения](https://dev.vk.ru/ru/api/access-token/getting-started).

## Шаг 3. Выполните запрос

Передавайте ключ доступа в заголовке `Authorization`. Например, метод [`status.get`](https://dev.vk.ru/ru/method/status.get) требует пользовательский ключ доступа:

```bash
curl -X GET 'https://api.vk.ru/method/status.get' \
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'user_id=743784474' \
  -F 'v=5.199'
```

## Шаг 4. Получите ответ

Ответ API формируется с учётом прав доступа, связанных с ключом.

Например, метод `status.get` вернёт статус только в том случае, если он доступен владельцу ключа. Если пользователь, указанный в параметре `user_id`, ограничил видимость статуса только для друзей, а ключ выдан пользователю, который не является его другом, статус в ответе не вернётся.

Пример ответа:

```json
{
  "response": {
    "text": "Это мой статус!"
  }
}
```
