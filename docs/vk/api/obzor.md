#### Обновление политики использования VK API

ВКонтакте обновляет политику работы с VK API для сторонних сервисов и приложений. Все интеграции должны использовать только методы, опубликованные в [официальной](https://dev.vk.ru/ru/method) [документации](https://dev.vk.ru/ru/method), и соблюдать установленные лимиты. Методы, не входящие в публичную документацию, будут поэтапно ограничены.

ВКонтакте оставляет за собой право ограничивать доступ к API для приложений, которые нарушают [правила платформы](https://dev.vk.ru/ru/rules), создают избыточную нагрузку на инфраструктуру или не обеспечивают надлежащую защиту данных пользователей.

Изменения направлены на повышение безопасности и стабильности платформы для пользователей, авторов и партнёров.

## Обзор

VK API — это набор методов для работы с объектами экосистемы VK. Каждый метод выполняет определённую операцию: получить, создать, изменить или удалить данные. Методы сгруппированы по секциям в соответствии с предметной областью.

У каждого метода есть название и набор входных параметров. Параметры, типы данных и ограничения указаны на странице соответствующего метода.

- [Методы API](https://dev.vk.ru/ru/method)
- [Объекты](https://dev.vk.ru/ru/reference/objects)

При успешном выполнении API возвращает объект в формате JSON с результатом запроса. Если возникает ошибка, API возвращает JSON с описанием ошибки.

- [Коды ошибок](https://dev.vk.ru/ru/reference/errors)

## Авторизация

Для вызова методов VK API используются ключи доступа, полученные по протоколу OAuth 2.1. Ключ доступа передаётся в каждом запросе в заголовке Authorization и определяет:

- Контекст запроса — от имени пользователя, приложения или сообщества.
- Права доступа — набор разрешённых действий, полученных при авторизации.

Используются следующие типы ключей доступа:

- [Сервисный ключ доступа](https://dev.vk.ru/ru/api/access-token/service-token)
- [Ключ доступа пользователя](https://dev.vk.ru/ru/api/access-token/user-token)
- [Ключ доступа сообщества](https://dev.vk.ru/ru/api/access-token/community-token)

Способ получения ключа доступа также зависит от типа приложения. Приложение можно создать либо в [кабинете сервиса авторизации VK ID](https://id.vk.com/about/business/go) (Standalone-приложение), либо на [портале для](https://dev.vk.com/ru/admin/apps-list) [разработчиков dev.vk.com](https://dev.vk.com/ru/admin/apps-list) (игра или мини-приложение).

Подробнее об авторизации — в разделе [Ключи доступа](https://dev.vk.ru/ru/api/access-token/getting-started).

## Права доступа

Права доступа определяют, к каким данным и разделам API может обращаться приложение. Например, чтобы получить номер телефона пользователя, нужен ключ доступа с правом `phone`. Список прав, необходимых приложению, передаётся в параметре `scope` при получении ключа доступа.

Запрашивайте только те права, которые необходимы для работы сценариев приложения. Подробнее — в разделе [Права доступа и приватность](https://dev.vk.ru/ru/api/privacy).

### Данные профиля в VK ID

Отдельно выделяются права доступа, связанные с данными профиля в [VK ID](https://id.vk.ru/).

Базовые права доступны после создания приложения в [сервисе авторизации VK ID](https://id.vk.com/about/business/go/):

- Имя, фамилия, фото профиля, пол, дата рождения, почта.

Расширенные права требуют подтверждения профиля бизнеса в VK ID:

- Номер телефона.

Часть расширенных прав, например доступ к отдельным пользовательским данным, может выдаваться после индивидуального согласования. Для запроса таких прав напишите на [devsupport@corp.vk.com](mailto:devsupport@corp.vk.com).

Подробнее о получении доступа к данным профиля VK ID — в [документации VK ID](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application#Nastrojka-dostupov).
