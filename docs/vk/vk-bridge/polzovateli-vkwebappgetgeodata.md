# VKWebAppGetGeodata

**Раздел:** VK Bridge → Пользователи → VKWebAppGetGeodata  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppGetGeodata` возвращает информацию о местоположении пользователя.

## Пример

```js
bridge.send('VKWebAppGetGeodata')
  .then((data) => {
    if (data.available) {
      // Местоположение получено
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppGetGeodataResult` и `VKWebAppGetGeodataFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. В качестве ответа платформа возвращает объект, поля которого зависят от используемой платформы.

#### Android, iOS

**Поле | Тип | Описание**

`available` `boolean` Доступны ли мини-приложению данные о текущем местоположении пользователя ( `true`) или нет ( `false`). Данные могут быть недоступны, например, если пользователь запретил определять местоположение.

`lat` `double` Географическая широта в градусах: от `-90` (южная) до

`90` (северная).

`long` `double` Географическая долгота в градусах: от `-180` (западная) до `180` (восточная).

`accuracy` `double` Точность определения широты и долготы. Неотрицательное число, которое показывает возможное отклонение в градусах от возвращаемых значений.

`bad_measurement` `boolean` Корректны ли значения координат и точность определения ( `false`) или нет ( `true`).

#### Объект altitude

Содержит информацию о высоте местоположения устройства пользователя над уровнем моря.

**Поле | Тип | Описание**

`available` `boolean` Доступны ли мини-приложению данные о высоте местоположения устройства пользователя над уровнем моря ( `true`) или нет ( `false`).

`value` `double` Высота в метрах над уровнем моря.

**Поле | Тип | Описание**

`accuracy_available` `boolean` Доступны ли мини-приложению данные о точности определения высоты ( `true`) или нет ( `false`).

`accuracy` `double` Точность определения высоты. Неотрицательное число, которое показывает возможное отклонение в метрах от возвращаемых значений.

`bad_measurement` `boolean` Корректны ли значения `altitude` и `accuracy`:
- `false` — значения корректные и им можно доверять.
- `true` — значения некорректные и им нельзя доверять.

#### Объект speed

Содержит информацию о скорости перемещения устройства пользователя.

**Поле | Тип | Описание**

`available` `boolean` Доступны ли мини-приложению данные о скорости перемещения ( `true)` или нет ( `false`).

`value` `double` Cкорость перемещения в метрах в секунду. Значением свойства может быть только неотрицательное число.

`accuracy_available` `boolean` Доступно ли на устройстве значение `speed` `accuracy` ( `true`) или нет ( `false`).

`accuracy` `double` Погрешность скорости. Неотрицательное число, которое показывает возможное отклонение в метрах в секунду от возвращаемых значений.

`bad_measurement` `boolean` Корректны ли значения скорости и погрешности:
- `false` — значения корректные и им можно доверять.
- `true` — значение некорректные и им нельзя доверять.

#### Объект course

Содержит информацию о направлении горизонтального движения устройства пользователя.

**Поле | Тип | Описание**

`available` `boolean` Доступны ли данные о направлении горизонтального движения устройства ( `true`) или нет ( `false`).

`value` `double` Направление горизонтального движения устройства. Измеряется в градусах [0,360), где 0 — строго на север, 90 — строго на восток, 180 — строго на юг, 270 — строго на запад.

**Поле | Тип | Описание**

`accuracy_available` `boolean` Доступны ли данные о погрешности направления ( `true`) или нет ( `false`).

`accuracy` `double` Погрешность направления. Неотрицательное число, которое показывает возможное отклонение в градусах от возвращаемых значений.

`bad_measurement` `boolean` Корректны ли значения направления и погрешности:
- `false` — значения корректные и им можно доверять.
- `true` — значения некорректные и им нельзя доверять.

### События

`VKWebAppGetGeodataResult`

Сигнализирует, что данные о местоположении получены. В обработчик события на стороне пользователя передаются данные:

```js
{
  detail: {
    type: "VKWebAppGetGeodataResult",
    data: {
      available: true,
      lat: 78.0217862,
      long: 76.2881822,
      accuracy: 15.024
    }
  }
}
```

Передаваемый объект подобен объекту, который возвращается при успешном выполнении промиса.

`VKWebAppGetGeodataFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой, или о том, что пользователь не предоставил мини-приложению доступ к данным о своём местоположении.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.

## Особенности использования

При первом вызове события `VKWebAppGetGeodata` ВКонтакте запрашивает разрешение пользователя на доступ к данным о местоположении.

Если пользователь разрешит доступ, его ответ будет сохранён в следующих настройках в зависимости от платформы:

- При работе на десктопном или мобильном сайте ВКонтакте — в настройках браузера. Разрешение на доступ будет привязано к домену, на котором ваше мини-приложение или игра были запущены: vk.com или m.vk.com.
- При работе в мобильном приложении ВКонтакте — в настройках операционной системы Android или iOS. Разрешение будет привязано к мобильному приложению, из которого ваше мини- приложение или игра были запущены: ВКонтакте или VK Мессенджер.

Если пользователь запретит доступ к данным о местоположении, то при повторном вызове

`VKWebAppGetGeodata` платформа ВКонтакте снова запросит разрешение. Чтобы избежать слишком частых запросов, сохраните ответ пользователя на стороне своего приложения и проверяйте сохранённое значение перед вызовом события.
