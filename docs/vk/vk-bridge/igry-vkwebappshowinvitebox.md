# VKWebAppShowInviteBox

**Раздел:** VK Bridge → Игры → VKWebAppShowInviteBox  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppShowInviteBox` открывает диалоговое окно приглашения друзей в [игру](https://dev.vk.ru/ru/games/overview).

Окно показывает друзей, которые ещё не играют в игру. Пользователь может выбрать, кому из них отправить [приглашение](https://dev.vk.ru/ru/games/promotion/game-mechanics/invites).

## Пример

```js
bridge.send('VKWebAppShowInviteBox', {
  requestKey: "key-12345" //  Ключ приглашения
  })
  .then( (data) => {
    if (data.success) {
      // Пользователь нажал «Пригласить»
      // ...
```

```
    // Этим выбранным пользователям
    // не удалось отправить приглашения
    console.log('Приглашения не отправлены', data.notSentIds);
  }
})
.catch( (error) => {
  console.log(error); // Ошибка
});
```

## Параметры

| Поле | Тип | Описание |
|---|---|---|
| `requestKey` необязательное | `string` | Ключ приглашения. Это строка, которая будет передана игре как параметр `vk_request_key` при запуске из приглашения. Его можно использовать, чтобы предусмотреть в игре сценарий, соответствующий |

**Поле | Тип | Описание**

приглашению, и для отслеживания конверсии. Подробнее о параметрах.

Обратите внимание: в настоящее время параметр [`requestKey`](https://dev.vk.ru/ru/games/development/parameters) работает только в играх, запущенных в десктопной или мобильной версии сайта.

| `message` обязательное | `string` Текст сообщения. Параметр используется только в десктопной и мобильной версии сайта Одноклассники. |
|---|---|

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppShowInviteBoxResult` и `VKWebAppShowInviteBoxFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующими полями:

**Поле | Тип | Описание**

`success` `boolean` Возможные значения:
- `true` — игрок выбрал одного или нескольких друзей в списке и нажал на кнопку «Пригласить». Приглашение было отправлено хотя бы одному из выбранных пользователей.
- `false` — в ином случае.

`notSentIds` `array` Список идентификаторов пользователей, которые были выбраны в диалоговом окне, но которым приглашение не было отправлено по какой-либо причине.

Если при обращении к платформе произошла ошибка или если пользователь нажал на кнопку «Отмена» в диалоговом окне, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA), общий для всех событий VK Bridge.

### События

`VKWebAppShowInviteBoxResult`

Сигнализирует, что пользователь нажал «Пригласить» в диалоговом окне и приглашение было отправлено одному или нескольким выбранным пользователям. В обработчик события передаются следующие данные:

```json
{
  "type": "VKWebAppShowInviteBoxResult",
  "data": {
    "success": true,
    "notSentIds": []
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при успешном выполнении промиса.

`VKWebAppShowInviteBoxFailed`

Происходит при ошибке, которая произошла при взаимодействии с платформой, либо если пользователь нажал на кнопку «Отмена» в диалоговом окне.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.

## Примечания

Игры, не добавленные в [каталог ВКонтакте](https://dev.vk.ru/ru/games/catalog/overview), могут присылать приглашения только своим администраторам.

Обратите внимание, что диалоговое окно покажет имя пользователя-администратора, только если он не запускал игру ранее. Если он уже запускал игру, то для тестирования события ему надо [удалить игру из списка своих игр](https://dev.vk.ru/ru/games/promotion/game-mechanics/invites#%D0%9E%D1%81%D0%BE%D0%B1%D0%B5%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D0%B8%20%D0%B8%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F).
