# VKWebAppShowSubscriptionBox

**Раздел:** VK Bridge → Платежи → VKWebAppShowSubscriptionBox  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppShowSubscriptionBox` открывает диалоговое окно покупки [подписки](https://dev.vk.ru/ru/api/payments/overview#%D0%92%D0%B8%D0%B4%D1%8B%20%D0%BF%D0%BB%D0%B0%D1%82%D0%B5%D0%B6%D0%B5%D0%B9), отказа от неё или восстановления подписки в [игре](https://dev.vk.ru/ru/games/overview) или [мини-приложении](https://dev.vk.ru/ru/mini-apps/overview). Выполняемое действие и внешний вид окна задаются параметрами события.

## Пример

### Продажа подписки

```js
bridge.send('VKWebAppShowSubscriptionBox',
  {
    action: 'create',
    item: 'subscription_in-app_id',
  })
  .then( (data) => {
    if (data.success) {
      // Списание голосов прошло успешно
      // ...
  })
  .catch( (e) => {
    console.log(error);   // Ошибка
  });
```

### Отмена подписки

```js
bridge.send('VKWebAppShowSubscriptionBox',
  {
    action: 'cancel',
     subscription_id: '25', // Идентификатор подписки, полученный от площадки
  })
  .then( (data) => {
    if (data.success) {
      // Подписка отменена
      // ...
  })
  .catch( (e) => {
    console.log(error);   // Ошибка
  });
```

### Восстановление подписки

```js
bridge.send('VKWebAppShowSubscriptionBox',
    {
      action: 'resume',
      subscription_id: '25', // Идентификатор подписки, полученный от площадки
    })
    .then( (data) => {
      if (data.success) {
        // Подписка восстановлена
        // ...
    })
    .catch( (e) => {
      console.log(error);   // Ошибка
    })
```

## Совместимость

| Площадки | Платформы |
|---|---|
| ВКонтакте | Android, iOS, Mobile Web, Web |
| Одноклассники | Android, iOS, Mobile Web, Web |

## Параметры

| Поле | Тип | Описание |
|---|---|---|
| `action` обязательное | `string` | Выполняемое действие. Допустимые значения: - `create` — покупка подписки. - `cancel` — отмена подписки. - `resume` — восстановление отменённой подписки. |
| `item` обязательное при продаже подписки | `string` | Параметр используется при продаже подписки. Указывает внутренний идентификатор подписки в приложении. Сервер приложения использует это значение, чтобы вернуть информацию о подписке, которая будет показана в диалоговом окне покупки. |
| Операции отмены и восстановления подписки должны | проходить с использованием другого идентификатора — | того, который приложение получает от площадки. |
| `subscription_id` обязательное при отмене и восстановлении подписки | `integer` | Параметр используется при отмене или восстановлении подписки. Указывает идентификатор экземпляра подписки, проданного пользователю. Приложение получает этот идентификатор от площадки при продаже подписки пользователю. |

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppShowSubscriptionBoxResult` и

`VKWebAppShowSubscriptionBoxFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. Во всех вариантах работы, то есть и при продаже, и при отмене, и при восстановлении подписки, в качестве ответа платформа возвращает объект со следующими полями:

**Поле | Тип | Описание**

`success` `boolean` `true`, если операция была выполнена успешно, `false` — в противном случае.

`subscriptionId` `integer` Идентификатор экземпляра подписки, с которым производится операция.
- При продаже подписки площадка создаёт этот идентификатор автоматически. Используйте его для отмены и восстановления подписки в дальнейшем.
- При отмене или восстановлении подписки это будет тот же самый идентификатор, который был передан в параметре

`subscription_id` события `VKWebAppShowSubscriptionBox`.

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA), общий для всех событий VK Bridge.

### События

`VKWebAppShowSubscriptionBoxResult`

Сигнализирует об успешном выполнении операции. В обработчик события на стороне пользователя передаются следующие данные:

```js
{
  detail: {
    type: "VKWebAppShowSubscriptionBoxResult",
    data: {
      success: true,
      subscriptionId: 25
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при успешном выполнении промиса.

`VKWebAppShowSubscriptionBoxFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.

## Примечания

- Полная информация о продаже, отмене и восстановлении подписок — в разделе [Продажа](https://dev.vk.ru/ru/api/payments/subscriptions/vk) [подписок](https://dev.vk.ru/ru/api/payments/subscriptions/vk).
- Пользователи могут отменять и восстанавливать подписки не только в приложении, но и в настройках своего аккаунта.
- Если пользователь приложения добавлен в список тестировщиков платежей этого приложения, все покупки подписок, сделанные этим пользователем, работают в тестовом режиме. Подробнее — в разделе [Тестирование платежей](https://dev.vk.ru/ru/api/payments/testing).
