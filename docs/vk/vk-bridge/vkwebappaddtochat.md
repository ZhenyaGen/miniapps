# VKWebAppAddToChat

**Раздел:** VK Bridge → VKWebAppAddToChat  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppAddToChat` добавляет [виджет](https://dev.vk.ru/ru/mini-apps/development/integration-into-messenger/overview) мини-приложения в чат.

Доступны два сценария работы события:

- Если мини-приложение было открыто из аттач-пикера (элемента добавления вложения) в чате, то будет показано диалоговое окно с подтверждением. После подтверждения виджет будет добавлен в чат.
- Если мини-приложение было открыто другим способом, то сначала будет показано диалоговое окно с подтверждением, а затем окно с выбором чата для отправки виджета. После этого виджет будет добавлен в выбранный чат.

## Пример

```js
bridge.send("VKWebAppAddToChat", {
    action_title: 'Показать погоду'
});
```

## Совместимость

| Площадки | Платформы |
|---|---|
| ВКонтакте | Android, iOS, Mobile Web, Web |
| Одноклассники | – |

## Параметры

| Поле | Тип | Описание |
|---|---|---|
| `action_title` обязательное | `string` | Заголовок действия для виджета. |
| `close_app` необязательное | `boolean` | - `true` — закрыть мини-приложение после отправки виджета в чат. - `false` — показать снек-бар с кнопкой перехода в чат и не |

| Поле | Тип | Описание |
|---|---|---|
| закрывать мини-приложение. | Параметр применяется только для случая, когда мини-приложение | было открыто из аттач-пикера. Значение по умолчанию — `false`. |
| `hash` необязательное | `string` | Произвольная строка, содержащая хеш мини-приложения, который будет добавляться к URL после символа `#` |

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppAddToChatResult` и `VKWebAppAddToChatFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
|---|---|---|
| `result` | `boolean` | `true`, виджет отправлен в чат. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA), общий для всех событий VK Bridge.

### События

`VKWebAppAddToChatResult`

Сигнализирует, что виджет добавлен в чат. В обработчик события на стороне пользователя передаются следующие данные:

```js
{
  detail: {
    type: "VKWebAppAddToChatResult",
    data: {
      result: true
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при успешном выполнении промиса.

`VKWebAppAddToChatFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.

## Примечания

- Чтобы сообщить мини-приложению, что оно запущено из чата, ВКонтакте передаёт ему URL- параметр `vk_chat_id`, который содержит идентификатор чата.
- Отличить, откуда запущено мини-приложение, можно с помощью параметра `vk_ref`:

- `vk_ref=im_attach_picker` – запуск из аттач-пикера.
- `vk_ref=catalog_messenger_apps_with_action` – запуск из каталога.
- `vk_ref=im_app_action` – запуск из отправленного виджета.
