# VKWebAppShowRequestBox

**Раздел:** VK Bridge → VKWebAppShowRequestBox  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppShowRequestBox` открывает диалоговое окно для отправки запроса о помощи в [игре](https://dev.vk.ru/ru/games/overview) какому-либо пользователю.

Механика запросов от друзей позволяет привлечь новых пользователей в игру или вернуть неактивных игроков. Подробнее о ней можно узнать в разделе [Запросы](https://dev.vk.ru/ru/games/promotion/game-mechanics/requests).

## Пример

```js
bridge.send("VKWebAppShowRequestBox", {
  uid: 142918399, // Идентификатор пользователя — получателя сообщения
  message:    "Мне нужна помощь! Пжл, вышли 20 талеров и алмазную кирку.", //
Текст запроса
  requestKey: "key-12345" //  Ключ запроса
  })
  .then( (data) => {
    if (data.success) {
      // Запрос отправлен.
      // ...
```

```
    // Ключ
    console.log('Ключ переданного запроса: ', data.requestKey);
})
.catch( (error) => {
  console.log(error); // Ошибка
});
```

## Параметры

| Поле | Тип | Описание |
|---|---|---|
| `uid` обязательное | `integer` | Идентификатор пользователя, которому будет отправлен запрос. |

Чтобы получить идентификатор, выполните API-запрос

[`friends.getAppUsers`](https://dev.vk.ru/ru/method/friends.getAppUsers) или [`friends.get`](https://dev.vk.ru/ru/method/friends.get) [.](https://dev.vk.ru/ru/method/friends.get)

| `message` обязательное | `string` Текст запроса. В общем случае это может быть произвольная строка. |
|---|---|

Игра может предлагать вводить текст запроса, но пользователям будет удобнее и быстрее воспользоваться уже готовыми фразами. Мы рекомендуем подумать над хорошо сформулированными запросами, которые подходят вашей игре, и использовать их.

| `requestKey` необязательное | `string` Ключ запроса. Это строка, которая будет передана игре как параметр |
|---|---|
| `vk_request_key` | при запуске из запроса. Его можно использовать, чтобы предусмотреть в игре сценарий, соответствующий запросу, и для отслеживания конверсии. Подробнее — в разделе [Параметры](https://dev.vk.ru/ru/games/development/parameters) [запуска игр](https://dev.vk.ru/ru/games/development/parameters). |

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppShowRequestBoxResult` и `VKWebAppShowRequestBoxFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующими полями:

**Поле | Тип | Описание**

`data.success` `boolean` Равен `true`. Сигнализирует о том, что пользователь нажал на кнопку «Отправить».

`data.requestKey` `string` Ключ отправленного запроса.

Если при обращении к платформе произошла ошибка или если пользователь нажал на кнопку «Отмена» в диалоговом окне, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA), общий для всех событий VK Bridge.

### События

`VKWebAppShowRequestBoxResult`

Сигнализирует, что пользователь нажал «Отправить» в диалоговом окне и приглашение было отправлено одному или нескольким выбранным пользователям. В обработчик события передаются следующие данные:

```json
{
  "type": "VKWebAppShowRequestBoxResult",
  "data": {
    "success": true,
    "requestKey": "key-12345"
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при успешном выполнении промиса.

`VKWebAppShowRequestBoxFailed`

Происходит при ошибке, которая произошла при взаимодействии с платформой, либо если пользователь нажал на кнопку «Отмена» в диалоговом окне.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.

## Примечания

Запросы отправляются отдельно каждому пользователю. Подтверждение у отправителя запрашивается при каждом запросе.
