# Позвонить пользователю

**Раздел:** VK Bridge → Позвонить пользователю  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Чтобы инициировать звонок из приложения, перенаправьте пользователя по ссылке:

```
https://vk.com/call?id={user_id}
```

## Совместимость

| Площадки | Платформы |
|---|---|
| ВКонтакте | Android, iOS |
| Одноклассники | – |

## Параметры

| Поле | Тип | Описание |
|---|---|---|
| `user_id` обязательное | `integer` | Идентификатор пользователя. |
