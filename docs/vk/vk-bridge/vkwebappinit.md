# VKWebAppInit

**Раздел:** VK Bridge → VKWebAppInit  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppInit` — первое событие, которое ваше приложение должно отправить приложению для начала работы с VK Bridge. Если это событие не вызвать, ваше мини-приложение или игра не будет работать.

Обратите внимание! На платформах Web и Mobile Web обрабатывается только первый вызов события `VKWebAppInit`.

## Пример

```js
bridge.send('VKWebAppInit')
  .then((data) => {
    if (data.result) {
      // Приложение инициализировано
    } else {
      // Ошибка
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppInitResult` и `VKWebAppInitFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

**Поле | Тип | Описание**

`result` `boolean` `true`, если приложение инициализировано. `false` — в ином случае.

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA), общий для всех событий VK Bridge.

### События

`VKWebAppInitResult`

Сигнализирует, что приложение инициализировано. В обработчик события на стороне пользователя передаются следующие данные:

```js
{
  detail: {
    type: "VKWebAppInitResult",
    data: {
      result: true
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при успешном выполнении промиса.

`VKWebAppInitFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.

## Особенности использования

С 25 сентября 2023 года на платформах Web и Mobile Web обрабатывается только первый вызов события `VKWebAppInit`. Ранее платформы обрабатывали и повторный вызов события.

Эффекты, которые возникают после вызова `VKWebAppInit`:

- Платформа отправляет приложению событие [`VKWebAppUpdateConfig`](https://dev.vk.ru/ru/bridge/VKWebAppUpdateConfig) [.](https://dev.vk.ru/ru/bridge/VKWebAppUpdateConfig)
- Отображаются всплывающие подсказки, по которым пользователь сможет ориентироваться в приложении.
- При запуске приложения в мобильном браузере фокус перемещается в приложение.

Ранее вы могли использовать эти эффекты при повторных вызовах `VKWebAppInit`. Так как теперь повторные вызовы не обрабатываются, то и эти эффекты не возникают. Имейте это в виду при разработке ваших приложений.
