# VKWebAppShowStoryBox

**Раздел:** VK Bridge → VKWebAppShowStoryBox  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppShowStoryBox` открывает редактор историй. Параметры события задают элементы, которые появятся в редакторе при открытии. Пользователь может изменить их, удалить и добавить новые перед публикацией истории.

## Пример

#### Пример вызова события

```js
bridge.send('VKWebAppShowStoryBox', {
  background_type: 'image',
  url: 'https://sun9-
65.userapi.com/c850136/v850136098/1b77eb/0YK6suXkY24.jpg',
  attachment: {
    text: 'book',
    type: 'photo',
    owner_id: 743784474,
    id: 12345678
  }})
  .then((data) => {
    if (data.code_data) {
      // Редактор историй открыт
      console.log(data);
    }})
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Параметры

| Поле | Тип | Описание |
|---|---|---|
| `background_type` обязательное | `string` | Тип фонового изображения или видео. Допустимые значения: - `image` — фоном истории будет статичное изображение, которое можно указать с помощью параметра `url` (ссылка на картинку в формате PNG или JPEG) или `blob` (двоичные данные). Этот тип фона можно использовать в мобильных приложениях для Android и iOS, в мобильной или десктопной версии сайта. - `video` — фоном истории будет видео, адрес которого указан параметром `url`. Такой тип фона работает в историях, создаваемых в мобильном приложении для Android (WEBM и MP4) и iOS (MP4). - `none` — фоном истории будет видео с камеры мобильного устройства. Этот тип фона применим только в историях, создаваемых в мобильном приложении для Android и iOS. |

Оптимальное разрешение видео — 720×1280.

В Одноклассниках поле поддерживает только значение

`image`.

| `camera_type` необязательное | `string` Тип камеры, используемой в редакторе историй: `back` (задняя) или `front` (фронтальная). Редактор учитывает это значение, только если `"background_type":` `"none"`. Значение по умолчанию: `back`. |
|---|---|
| `url` необязательное | `string` Прямая ссылка на изображение или видео. Медиафайлы должны быть загружены на сервера ВКонтакте. Подробнее — в разделе [Загрузка историй в профиль](https://dev.vk.ru/ru/api/upload/story-in-profile). |
| `blob` необязательное | `string` Используется, когда `"background_type": "image"`, а поле `url` отсутствует. Содержит данные изображения, закодированные как Base64-строка. Перед этими данными необходимо добавить один из префиксов |

`data:image/...` в зависимости от типа изображения, например:
- PNG:    `data:image/png;base64,<base64-image-` `data>`
- JPEG:  `data:image/jpeg;base64,<base64-image-` `data>`

В Одноклассниках поле поддерживает типы изображений: JPEG, PNG, SVG.

| Поле | Тип | Описание |
|---|---|---|
| `locked` необязательное | `boolean` | Информация о том, можно ли перемещать изображение в истории ( `true`) или нет ( `false`). |
| `attachment` обязательное | `attachment` | Объект, который описывает дополнительный ресурс: ссылку, видео или изображение, прикреплённые к истории. Кнопка с ресурсом появится в нижней части экрана. В Одноклассниках параметр `type` поддерживает только значение `url`. |
| `stickers` необязательное | `array` < `sticker_` | Массив стикеров, которые будут добавлены в историю. Пользователь может изменить или удалить их перед публикацией. Каждый стикер представлен объектом |

`container` >

`sticker_container`.

| `service_info` необязательное | `service_info` Дополнительные данные, которые могут использоваться для создания истории. |
|---|---|

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppShowStoryBoxResult`, `VKWebAppShowStoryBoxLoadFinish` и

`VKWebAppShowStoryBoxFailed`.

Возможные ошибки:

- `This action cannot be performed in the background`, если мини-приложение запущено в фоновом режиме.
- `User denied`, если пользователь закрыл окно создания истории.

Подробнее — в разделе [Обработка результата](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
|---|---|---|
| `result` | `boolean` | `true`, если история начала загружаться. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA), общий для всех событий VK Bridge.

### События

`VKWebAppShowStoryBoxResult`

Сигнализирует, что история начала загружаться. В обработчик события на стороне пользователя передаются следующие данные:

```js
{
  detail: {
    type: "VKWebAppShowStoryBoxResult",
    data: {
      result: true
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при успешном выполнении промиса.

`VKWebAppShowStoryBoxLoadFinish`

Сигнализирует, что история была успешно опубликована. В качестве ответа платформа возвращает объект со следующими полями:

| Поле | Тип | Описание |
|---|---|---|
| `story_owner_id` | `integer` | Идентификатор владельца истории. |
| `story_id` | `integer` | Идентификатор истории. |

В обработчик события на стороне пользователя передаются следующие данные:

```js
{
  detail: {
    type: "VKWebAppShowStoryBoxLoadFinish",
    data: {
      story_owner_id: 743784474,
      story_id: 456239018,
    }
  }
}
```

`VKWebAppShowStoryBoxFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.

## Объекты

attachment

Описывает дополнительный ресурс: ссылку, изображение или видео, прикреплённое к истории. Кнопка с ресурсом появится в нижней части экрана.

| Поле | Тип | Описание |
|---|---|---|
| `text` обязательное | `string` | Текст кнопки для открытия ресурса. Возможные значения — такие же, как значения параметра `link_text` в API-методе |

[`stories.getVideoUploadServer`](https://dev.vk.ru/ru/method/stories.getVideoUploadServer) [.](https://dev.vk.ru/ru/method/stories.getVideoUploadServer)

| `type` обязательное | `string` Тип ресурса. Возможные значения: - `url` — ссылка. - `video` — видео. - `photo` — изображение. |
|---|---|

В Одноклассниках параметр `type` поддерживает только значение

`url`.

| `url` необязательное | `string` Ссылка на объект. |
|---|---|

Этот параметр используется, если параметр `type` равен `url`.

| `owner_id` обязательное | `integer` Идентификатор пользователя или сообщества, которому принадлежит видео или изображение. |
|---|---|

Этот параметр используется, если параметр `type` равен `video` либо

`photo`.

Идентификатор пользователя — положительное число, идентификатор сообщества — отрицательное.

Как получить идентификаторы `owner_id` и `id`

| `id` обязательное | `integer` Идентификатор видео или изображения. |
|---|---|

Этот параметр используется, если параметр `type` равен `video` либо

`photo`.

Как получить идентификаторы `owner_id` и `id`

| `access_key` необязательное | `string` Ключ доступа к ресурсу. Может потребоваться, когда для доступа к ресурсу нужны специальные права. |
|---|---|

Как получить `owner_id` и `id`

Чтобы получить значения для параметров `owner_id` и `id`, откройте изображение или видео в десктопной версии сайта. В адресной строке браузера появится URL изображения или видео.

Значение, которое идёт сразу после слова `photo` или `video` в URL, — это `owner_id`. Обратите внимание, что идентификатор сообщества — отрицательное число. Копируйте его вместе со знаком

минус.

Значение, которое следует за `owner_id` после знака подчёркивания, — это `id` изображения или видео.

sticker_container

Содержит свойства стикера, который будет добавлен в историю.

| Поле | Тип | Описание |
|---|---|---|
| `sticker_type` обязательное | `string` | Тип стикера. Возможные значения: - `native` — стикер, который есть в редакторе историй. - `renderable` — стикер, создаваемый разработчиком приложения. |
| `sticker` обязательное | `native_sticker`  или `renderable_sticker` | Объект, содержащий данные cтикера. |

native_sticker

Описывает параметры стикеров, которые есть в редакторе историй и которые используются в создаваемой истории.

Тип стикера описывается полем `action_type`, данные — полем `action`. Эти поля работают в связке. Например, если `action_type` равно `text`, то `action` должно содержать объект

`action_text`, а если `action_type` равно `mention`, то `action`  — `action_mention`.

| Поле | Тип | Описание |
|---|---|---|
| `action_type` обязательное | `string` | Тип стикера. Возможные значения: - `emoji` — символы эмодзи, например различные смайлики. Поддерживается в историях, создаваемых в мобильном приложении для Android. - • `hashtag` — хештег, например `#MakeLoveNotBugs`. Добавление хештега в историю делает эту историю видимой по хештегу для всех пользователей. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS. - • `market_item` — ссылка на товар или услугу. Поддерживается в историях, создаваемых в мобильном приложении для Android. - • `mention` — упоминание пользователя или сообщества в виде |

`@имя`. Создаваемая история будет видна упомянутому пользователю, только если у этого пользователя есть права на просмотр истории. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS.
- • `sticker` — стикер. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS и в десктопной версии сайта.
- • `text` — произвольный текст, например «С днём рождения!». Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS и в десктопной версии сайта.

**Поле | Тип | Описание**

- • `time` — Время или дата. Поддерживается в историях, создаваемых в мобильном приложении для Android.

| `action` обязательное | `object` Данные стикера. Описываются объектом, который соответствует типу, указанному в поле `action_type`. Список возможных объектов — в разделе Объекты `action_*`. |
|---|---|
| `transform` необязательное | `transform` Параметры, описывающие поворот или смещение стикера в создаваемой истории. |
| `can_delete` необязательное | `boolean` Информация о том, может ли пользователь удалить стикер из истории. Значение по умолчанию: `true`. |

renderable_sticker

Объект `renderable_sticker` описывает произвольное изображение, которое будет добавлено в создаваемую историю как объект-стикер. На этом изображении можно размещать дополнительные объекты — ссылки и хештеги.

| Поле | Тип | Описание |
|---|---|---|
| `content_type` обязательное | `string` | Тип объекта-стикера. Возможные значения: - `image` — изображение. Поддерживается в историях, создаваемых в мобильных приложениях для Android и iOS, а также в десктопной версии сайта. - `gif` — анимация в формате WebP. Поддерживается на платформе Android. Используйте это значение для включения в историю анимированных GIF-изображений. В историю можно добавить не более 4 таких картинок. |
| `url` необязательное | `string` | Ссылка на картинку, например, |

`https://mysite.com/img1.png`. Обязательна, если не указано поле `blob`.

| `blob` необязательное | `string` Данные изображения, закодированные как Base64- строка. Перед этими данными необходимо добавить один из префиксов `data:image/...` в зависимости от типа изображения: - PNG:    `data:image/png;base64,<base64-` `image-data>` - JPEG:  `data:image/jpeg;base64,<base64-` `image-data>` |
|---|---|

Поле обязательно, если `url` не указано.

| `transform` необязательное | `transform` Параметры, описывающие поворот или смещение стикера в создаваемой истории. |
|---|---|

| Поле | Тип | Описание |
|---|---|---|
| `clickable_zones` необязательное | `array` < `clickable_zone` > | Массив областей в стикере, нажатие на которые может вызвать какое-либо действие. Каждая область описывается объектом `clickable_zone`. |
| `can_delete` необязательное | `boolean` | Информация о том, может ли пользователь удалить стикер из истории. Значение по умолчанию: `true`. |

clickable_zone

Задаёт параметры области, нажатие на которую приведёт к тем или иным действиям, например к запуску приложения или открытию карточки товара.

Тип области описывается полем `action_type`, данные — полем `action`. Эти поля работают в связке. Например, если `action_type` равно `text`, то `action` должно содержать объект

`action_text`, а если `action_type` равно `mention`, то `action`  — `action_mention`.

| Поле | Тип | Описание |
|---|---|---|
| `action_type` обязательное | `string` | Тип области. Возможные значения: - `app` — запуск мини-приложения. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS, а также в десктопной версии сайта. - `emoji` — символы эмодзи, например различные смайлики. Поддерживается в историях, создаваемых в мобильном приложении для Android. - `hashtag` — хештег, например `#MakeLoveNotBugs`. Добавление хештега в историю делает эту историю видимой по хештегу для всех пользователей. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS. - `link` — ссылка. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS, а также в десктопной версии сайта. - `market_item` — ссылка на товар или услугу. Поддерживается в историях, создаваемых в мобильном приложении для Android. - `mention` — упоминание пользователя или сообщества в виде `@имя`. Создаваемая история будет видна упомянутому пользователю, только если у этого пользователя есть права на просмотр истории. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS. - `sticker` — стикер. Поддерживается в историях, создаваемых в мобильном приложении для Android и iOS и в десктопной версии сайта. |
| `action` обязательное | `object` | Данные области стикера. Описываются объектом, который соответствует типу, указанному в поле `action_type`. Список возможных объектов — в разделе Объекты |

`action_*`.

| Поле | Тип | Описание |
|---|---|---|
| `clickable_area` необязательное | `array` < `clickable_` | Граница области. Указывается как массив объектов |

`clickable_area_coordinate`, каждый из которых соответствует точке внутри области стикера.

`area_` `coordinate` >

Важно: точки должны располагаться по часовой стрелке, образуя замкнутый квадрат.

clickable_area_coordinate

Указывает координаты точки, которая используется для определения границ стикера.

| Поле | Тип | Описание |

transform

Описывает поворот или сдвиг стикера в создаваемой истории.

| Поле | Тип | Описание |
|---|---|---|
| `rotation` необязательное | `integer` | Поворот против часовой стрелки в градусах. Диапазон возможных значений: от `0` до `359`. |
| `relation_width` необязательное | `float` | Желаемая ширина стикера относительно экрана. Диапазон возможных значений: от `0` до `1`. Высота будет рассчитана с учётом сохранения соотношения сторон контента. |
| `translation_x` необязательное | `float` | Сдвиг стикера по оси X от начального положения в плоскости XY. Диапазон возможных значений: от `-1` до `1`. Значение по умолчанию: `0`. |
| `translation_y` необязательное | `float` | Сдвиг стикера по оси Y от начального положения в плоскости XY. Диапазон возможных значений: от `-1` до `1`. Значение по умолчанию: `0`. |
| `gravity` необязательное | `string` | Расположение стикера. Возможные значения: - `left_top` — слева сверху. - `left_center` — слева по центру. - `left_bottom` — слева снизу. - `center_top` — по центру сверху. - `center` — по центру. - `center_bottom` — по центру снизу. - `right_top` — справа сверху. |

**Поле | Тип | Описание**

- `right_center` — справа по центру.
- `right_bottom` — справа снизу.

Значение по умолчанию: `center`.

Чтобы рассчитать итоговую позицию стикера, воспользуйтесь формулами:

```
x = НАЧАЛЬНАЯ_ПОЗИЦИЯ_X + artboard_width * translation_x
y = НАЧАЛЬНАЯ_ПОЗИЦИЯ_Y + artboard_height * translation_y
```

Формулы используют следующие значения:

| Значение | Тип | Описание |
|---|---|---|
| `НАЧАЛЬНАЯ_ПОЗИЦИЯ_X`, `НАЧАЛЬНАЯ_ПОЗИЦИЯ_Y` | `float` | Начальные координаты для расчёта. Значения зависят от поля `gravity` объекта `transform`. Например, координаты (0, 0) соответствуют `"gravity":` `"left_top"`, а (1, 1) — `"gravity": "right_bottom"`. |
| `artboard_width`, `artboard_height` | `integer` | Ширина и высота области, в которой история отрисовывается. Зависит от устройства пользователя. |
| `translation_x`, `translation_y` | `float` | Поля объекта `transform`. |

`x`, `y` `float` Итоговые координаты стикера в истории. Эти значения зависят от поля `gravity`. Например, при `"gravity":` `"left_top"` они определяют координаты верхней левой точки стикера, а при `"gravity": "right_bottom"` — нижней правой.

## Объекты `action_*`

Объекты `action_*` описывают параметры стикеров, которые были добавлены в историю.

action_emoji

Добавляет эмодзи в историю.

#### Особенности

- В стикерах `native_sticker` поддерживается на платформе Android.
- В стикерах `renderable_sticker` поддерживается на платформе Android.
- Максимальное количество в истории не ограничено.

#### Поля

| Поле | Тип | Описание |
|---|---|---|
| `emoji` обязательное | `string` | Код символа-смайлика в Unicode-кодировке, например `U+1F600`. |

Код необходимо указывать в шестнадцатеричном формате, причём все буквенные символы должны быть в верхнем регистре.

Подробнее — в разделе [Список emoji-символов](https://dev.vk.ru/ru/bridge/VKWebAppShowStoryBox/emoji-symbols).

action_hashtag

Описывает параметры хештега, добавленного в историю. Добавление хештега в историю делает эту историю видимой по хештегу для всех пользователей.

#### Особенности

- В стикерах `native_sticker` поддерживается на платформах Android, iOS.
- В стикерах `renderable_sticker` не поддерживается.
- Максимальное количество в истории: 5.

#### Поля

| Поле | Тип | Описание |
|---|---|---|
| `hashtag` обязательное | `string` | Текст хештега. |
| `style` необязательное | `string` | Стиль хештега. Возможные значения: - `transparent` — прозрачный. - `blue_gradient` — синий градиент. Значение используется по умолчанию. |

action_link

Описывает параметры ссылки, которая будет добавлена к истории. Используется для областей стикеров вида `renderable_sticker`.

`action_link` не добавляет какие-то визуальные элементы в историю, а определяет действие: по щелчку появляется меню с одним пунктом, который предлагает пользователю открыть запись, страницу или фотографию.

#### Особенности

- В стикерах `native_sticker` не поддерживается.
- В стикерах `renderable_sticker` поддерживается на платформах Android, iOS, Web.
- Максимальное количество в истории: 3.

#### Поля

| Поле | Тип | Описание |
|---|---|---|
| `link` обязательное | `string` | Ссылка на объект. |
| `tooltip_text_key` необязательное | `string` | Определяет строку, которая будет отображаться в мобильном приложении при нажатии на ссылку. Возможные значения: - `tooltip_open_post` — «Открыть запись». - `tooltip_open_photo` — «Открыть фотографию». - `tooltip_open_page` — «Открыть страницу». - `tooltip_open_default` — «Перейти по ссылке». Значение используется по умолчанию. |
