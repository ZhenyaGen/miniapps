# VKWebAppShowSlidesSheet

**Раздел:** VK Bridge → VKWebAppShowSlidesSheet  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

`VKWebAppShowSlidesSheet` показывает [информационные экраны (слайды)](https://dev.vk.ru/ru/mini-apps/development/information-screens), которые используются для онбординга пользователя и знакомства с новыми возможностями мини- приложения или игры.

## Пример

```js
bridge.send('VKWebAppShowSlidesSheet', {
  slides: [
    {
      media: {
        blob: 'data:image/png;base64,[IMAGE_DATA]',
        type: 'image'
      },
      title: 'Заголовок слайда',
      subtitle: 'Описание слайда под заголовком'
    }
   ]})
  .then((data) => {
    if (data.result) {
      // Слайды показаны
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Параметры

### Параметры события

| Поле | Тип | Описание |
|---|---|---|
| `slides` обязательное | `array[object]` | Слайды. Каждый элемент массива — объект, экран (слайд). Максимальное количество элементов в массиве: 10. |

### Параметры слайда

| Поле | Тип | Описание |
|---|---|---|
| `title` обязательное | `string` | Заголовок слайда. Занимает две строки. |
| `subtitle` обязательное | `string` | Короткое описание слайда. Занимает три строки. |
| `media` обязательное | `object` | Информация об изображении, которое будет показано на слайде. Изображение имеет фиксированное соотношение сторон: 1,5:1. Если указанное изображение имеет другое соотношение, то оно будет обрезано до нужного соотношения. Минимальный рекомендуемый размер изображения: 832×555 px. Максимальный размер файла изображения: 500 Кбайт. |

Поля объекта:
- `type` ( `string`) — тип изображения. В настоящий момент поддерживается только значение `image`.
- `blob` ( `string`) — cодержит данные изображения, закодированные как [Base64](https://vk.cc/5mpsES)-строка. Перед этими данными необходимо добавить один из префиксов `data:image/...` в зависимости от типа изображения, например:
- `data:image/png;base64,<base64-image-data>`.
- `data:image/jpeg;base64,<base64-image-data>`.

## Результат

Проверить результат можно:

- Используя объект `Promise`, который возвращается вызовом `bridge.send(...)`.
- С помощью событий `VKWebAppShowSlidesSheetResult` и

`VKWebAppShowSlidesSheetFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D1%80%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%D0%B0).

### Объект Promise

Если обращение к платформе прошло успешно, управление будет передано в `then` -обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
|---|---|---|
| `result` | `boolean` | `true`, слайды показаны. |

`action` `string` Действие, которое совершил пользователь по отношению к слайдам. Возможные значения:
- `confirm` — пользователь просмотрел все слайды.
- `reject` — пользователь нажал кнопку отмены на любом слайде.
- `cancel` — пользователь закрыл просмотр слайдов любым другим способом, например нажал кнопку возврата.

`slide_index` `integer` Индекс слайда. Нумерация начинается с `0`.

Поле возвращается, если параметр `action` имеет значение `reject`.

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA), общий для всех событий VK Bridge.

### События

`VKWebAppShowSlidesSheetResult`

Сигнализирует, что экраны показаны. В обработчик события на стороне пользователя передаются следующие данные:

```js
{
  detail: {
    type: "VKWebAppShowSlidesSheetResult",
    data: {
      result: true,
      action: "confirm"
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при успешном выполнении промиса.

`VKWebAppShowSlidesSheetFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке,](https://dev.vk.ru/ru/bridge/getting-started#%D0%9E%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) общий для всех методов VK Bridge.
