# Работа с open-source библиотеками ВКонтакте

**Раздел:** Библиотеки → Работа с open-source библиотеками ВКонтакте  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Разработчики ВКонтакте подготовили ряд npm-библиотек с открытым исходным кодом для создания [мини-приложений](https://dev.vk.ru/ru/mini-apps/overview) и [игр](https://dev.vk.ru/ru/games/overview) на платформе VK Mini Apps:

- [create-vk-mini-app](https://dev.vk.ru/ru/mini-apps/getting-started/create-vk-mini-app)
- [vk-mini-apps-examples](https://dev.vk.ru/ru/mini-apps/examples)
- [vk-tunnel-client](https://dev.vk.ru/ru/libraries/tunnel) (или VK Tunnel)
- [vk-bridge](https://dev.vk.ru/ru/bridge/overview) (или VK Bridge)
- [vk-miniapps-deploy](https://dev.vk.ru/ru/mini-apps/development/hosting/overview)
- [vk-mini-apps-router](https://dev.vk.ru/ru/libraries/router)

Исходный код этих библиотек находится на GitHub. Вы можете найти ссылки на репозитории в описании каждой библиотеки.

## Можно ли участвовать в развитии этих библиотек?

Да. Мы приветствуем вклад пользователей в развитие этих библиотек. Если вы столкнулись с ошибкой или у вас появилось предложения по улучшению, создайте сообщение об ошибке (issue) в репозитории или внесите изменения в код и отправьте нам запрос на включение изменений (pull request). Мы обязательно рассмотрим ваше обращение.

## Как создать issue или pull request

Следуйте инструкциям в файле `/docs/CONTRIBUTING.md`, который есть в каждом репозитории.

Важно! Перед тем как сообщить об ошибке или создать запрос на включение изменений, посмотрите на список сообщений и запросов, которые уже созданы. Это позволит избежать повторов.

## Сроки

Исправление ошибки или применение pull request может занять несколько дней или недель. Отнеситесь к этому с пониманием.

Мы постараемся рассмотреть обращение и дать ответ о последующих действиях в течение следующего времени:

| Вид обращения | Ответ |
|---|---|
| Сообщение об ошибке (issue) | В течение 2 рабочих дней |
| Комментарий в ранее созданных issue | В течение 2 рабочих дней |
| Новый pull request | В течение 7 календарных дней |

| Вид обращения | Ответ |
|---|---|
| Обновления в pull request (комментарии и коммиты) | В течение 2 рабочих дней |

## Метки сообщений

Для маркировки сообщений мы используем следующие метки:

**Метка | Описание**

Сообщение об ошибке.

Предложение об улучшении.

Нужна дополнительная информация от разработчика, который создал issue или pull request.

Если вы автор сообщения, обращайте внимание на эту метку.

Выставляется автоматически и является сигналом того, что мы не рассмотрели обращение в установленные сроки.

Разработчики ВКонтакте рассматривают сообщение, проверяют условия возникновения ошибки, анализируют pull request.
