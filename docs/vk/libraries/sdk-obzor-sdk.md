# Обзор SDK

**Раздел:** Библиотеки → SDK → Обзор SDK  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

SDK ВКонтакте — библиотеки для различных платформ, которые помогают добавить в ваше приложение аутентификацию ВКонтакте и выполнять запросы к API ВКонтакте. Библиотеки используют преимущества каждой платформы и сокращают время на интеграцию.

## SDK-библиотеки ВКонтакте

ВКонтакте разработала SDK-библиотеки для различных платформ. Сейчас идёт их обновление и перевод на использование нового механизма аутентификации, VK ID, который пришёл на замену OAuth 2.0, использовавшемуся ранее.

#### Библиотеки, поддерживающие VK ID OAuth 2.1

- [VK ID SDK для Android](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/android/install)
- [VK ID SDK для iOS](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/ios/install)
- [VK ID SDK для Web](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/web/install)

#### Библиотеки, поддерживающие OAuth 2.0

- [Android SDK](https://dev.vk.ru/ru/sdk/android)
- [iOS SDK](https://dev.vk.ru/ru/sdk/ios)
- [Java SDK](https://dev.vk.ru/ru/sdk/java)
- [PHP SDK](https://dev.vk.ru/ru/sdk/php)

При создании новых проектов для ВКонтакте мы рекомендуем использовать библиотеки, ориентированные на VK ID.

## Что дают SDK-библиотеки

Перечисленные выше библиотеки включают поддержку аутентификации ВКонтакте, а также упрощают выполнение API-запросов ВКонтакте. Это позволяет вам:

- Предложить пользователям вход с помощью аккаунта ВКонтакте вместо заполнения отдельной формы регистрации — это быстрее и проще.
- Использовать виджеты и API-методы для добавления фотографий, видео и других материалов ВКонтакте прямо из вашего приложения.
- Использовать список друзей и сообществ пользователя, чтобы оценить его потребности.
- Отправлять сообщения, отображать ленту новостей и выполнять другие действия в вашем приложении, которые становятся доступными при использовании API ВКонтакте.

## Пример использования

Avito использует SDK ВКонтакте, чтобы предложить пользователям вход по имени и паролю аккаунта ВКонтакте.

## Другие библиотеки

Для разработки приложений вы можете использовать следующие библиотеки. Они самостоятельны и не входят в SDK-библиотеки, упомянутые выше.

| Библиотека | Описание |
|---|---|
| [VK Bridge](https://dev.vk.ru/ru/bridge/overview) | Библиотека для взаимодействия с платформой ВКонтакте игр и мини-приложений. |
| [VK UI](https://dev.vk.ru/ru/libraries/vkui) | Библиотека React-компонентов для создания веб-приложений в стиле ВКонтакте. |
| [Виджеты](https://dev.vk.ru/ru/widgets/overview) | Набор JavaScript-компонентов для отображения данных и форм ВКонтакте прямо на страницах вашего вашего веб-приложения и взаимодействия с ВКонтакте со страниц вашего сайта. |
| [VK QR](https://dev.vk.ru/ru/libraries/vk-qr) | Библиотека создания QR-кодов для запуска мини-приложений. |
| [VK Tunnel](https://dev.vk.ru/ru/libraries/tunnel) | Библиотека для тестирования мини-приложений и игр, серверная часть которых работает в вашей локальной сети или на вашем компьютере и недоступна публично. |
