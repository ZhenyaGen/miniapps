## Обработка несуществующих путей (404 Not Found)

В случае перехода на несуществующий адрес библиотека [vk-mini-apps-router](https://dev.vk.ru/ru/libraries/router) покажет специальный экран. По умолчанию он сообщает о том, что страница не найдена, и предлагает перейти на главную страницу ( `/`).

Можно указать свою страницу для ошибки 404 Not Found. Вы можете сделать это несколькими способами.

| Способ | Описание | Приоритет | при одновременном | использовании |
|---|---|---|---|---|
| Атрибут `notFound` компонента  `RouterProvider` | При переходе по несуществующему адресу приложение отобразит React- компонент, указанный в атрибуте. | Низший. |
| Маршрут c `path: '*'` При переходе по несуществующему адресу приложение отобразит React- компоненты, указанные в маршруте c | Средний. |

`path: '*'`.

| Атрибут  `notFoundRedirectPath` компонента `RouterProvider` | При переходе по несуществующему адресу роутер перенаправит пользователя на адрес, указанный в атрибуте. | Высший. |
|---|---|---|

### Способ 1 — атрибут notFound

С помощью атрибута `notFound` компонента [`RouterProvider`](https://dev.vk.ru/ru/libraries/router/reference/components/RouterProvider) вы можете указать JSX-элемент, который будет показан при переходе по адресу, для которого не был определён маршрут.

```ts
<RouterProvider router={router} notFound={<p>Ничегошеньки!</p>}>
  /* Ваше приложение */
</RouterProvider>
```

При одновременном использовании других способов обработки ошибки атрибут `notFound` игнорируется.

### Способ 2 — маршрут path:'*'

Создайте маршрут со свойством `path: '*'`. Роутер будет использовать его, если не найдёт среди созданных маршрутов такого, который бы соответствовал переданному адресу.

```ts
import { RouteWithRoot } from '@vkontakte/vk-mini-apps-router';
```

```
// Массив объектов, указывающих маршруты
const routes: RouteWithRoot[] = [
  {
    path: '/',            // Путь
    panel: 'home_panel',  // Желаемый Panel
    view: 'default_view', // Желаемый View
    root: 'default_root', // Желаемый Root
  },
  {
    path: `/user`,
    modal: 'user_modal', // Модальное окно
    panel: 'home_panel',
    view: 'default_view',
    root: 'default_root',
  },
  {
    path: `*`, // Маршрут, который будет использован,
    tab:  'tab_404', // когда другие маршруты не соответствуют адресу перехода
    panel: 'panel_404',
    view: 'view_404',
    root: 'default_root',
  }
]
```

При одновременном использовании нескольких способов обработки ошибки этот вариант перекрывает способ с использованием атрибута `notFound`.

### Способ 3 — атрибут notFoundRedirectPath

Ещё одна возможность обработать переход по несуществующему адресу — использовать атрибут

`notFoundRedirectPath` компонента [`RouterProvider`](https://dev.vk.ru/ru/libraries/router/reference/components/RouterProvider). С его помощью вы можете указать путь, по которому будет выполнен переход, если изначальный путь не будет найден. Например, если в атрибуте указать стартовую страницу вашего приложения, то при попытке перехода по несуществующему адресу приложение автоматически откроет стартовый экран.

```ts
<RouterProvider router={router} notFoundRedirectPath="/">
  /* Ваше приложение */
</RouterProvider>
```

При одновременном использовании нескольких способов этот способ наиболее приоритетен.

## Обработка ошибок приложения и загрузки данных (5xx)

Библиотека vk-mini-apps-router не работает с данными и отрисовкой страниц. Ошибки со статусом

`5xx` происходят вне её кода. Обработка таких ошибок является ответственностью приложения.
