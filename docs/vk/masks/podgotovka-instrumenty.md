# Инструменты

## test.mask

Приложение для [просмотра и тестирования](https://dev.vk.ru/ru/masks/view) маски на компьютере.

- [Скачать test.mask для Windows](https://mask.vk.me/app/test.mask3_windows.zip)
- [Скачать test.mask для macOS](https://mask.vk.me/app/test.mask3_macos.zip)

## Blender

Свободное и открытое программное обеспечение для работы с 3D-графикой.

- [Скачать Blender](https://www.blender.org/download/)
- [Справочное руководство Blender](https://docs.blender.org/manual/ru/dev/)
- [Уроки по Blender](https://www.blender.org/support/tutorials/)

## Urho3D-Blender

Плагин для [экспорта 3D-моделей](https://dev.vk.ru/ru/masks/export) из Blender в формат движка Urho3D.

- [Скачать Urho3D-Blender](https://github.com/reattiva/Urho3D-Blender)
- [Справочное руководство Urho3D-Blender](https://github.com/reattiva/Urho3D-Blender/blob/master/guide.txt)

## Pngyu

Приложение для сжатия PNG-изображений.

- [Скачать Pngyu для Windows](https://mask.vk.me/app/pngyu_windows.zip)
- [Скачать Pngyu для macOS](https://mask.vk.me/app/pngyu_macos.zip)
