# Конфигурационный файл

**Раздел:** Маски → Создание → Конфигурационный файл  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Конфигурационный файл `mask.json` является входной точкой для запуска маски. В этом файле с помощью языка разметки JSON описываются все необходимые параметры маски.

Так как файл конфигурации представляет из себя объект (в нашем случае объектом является маска), то, согласно синтаксису языка разметки JSON, он должен содержать фигурные скобки  `{...}`, внутри которых размещается описание параметров в виде пар `"ключ":` `значение`.

```json
{
  "icon": "Icon.png",
  "num_faces": 1,
  "gallery_asset_required": false,
  "script": "main.as",
  "user_hint": "open_mouth",
  "mouse_input": true,
  "gestures_required": false,
  "effects": [...],
  "plugins": [...]
}
```

Возможные параметры маски описаны ниже. Каждому параметру соответствует одно поле в JSON- файле.

Мы рекомендуем работать с конфигурационным файлом в текстовом редакторе с подсветкой синтаксиса.

## Параметры

| Параметр | Описание |
|---|---|
| `icon` | Имя файла, используемого для иконки маски в каталоге приложения. Этот файл должен лежать в каталоге с файлом |
| `mask.json` | и иметь расширение `.png`. Тип данных: `string`. |

**Параметр | Описание**

`num_faces` Количество одновременно распознаваемых лиц, на которые рассчитана маска. Допустимые значения:
- `0` — детектор лица отключен;
- `1` — детектор ограничивается поиском только одного лица;
- `2` — детектор ищет два лица.

Если в масĸе нет эффеĸтов, завязанных на лице, то для увеличения быстродействия стоит уĸазать `0`. Если не указать это поле, то по умолчанию будет распознано только одно лицо. Подробнее: Маска на два лица. Тип данных: `integer`.

`script` Имя файла [скрипта](https://dev.vk.ru/ru/masks/development/script-creation), запускаемого маской. Файл скрипта должен лежать в папке с файлом `mask.json` и называться `main.as`. Расширение `.as` говорит о том, что это файл скриптового языка программирования AngelScript. Тип данных: `string`.

`user_hint` Всплывающая подсказка о действии с маской при её запуске. Если в маске присутствует какой-либо триггер, который меняет её состояние, то необходимо сообщить об этом пользователю. Допустимые значения:
- `"open_mouth"` — «Откройте рот»;
- `"tap_change"` — «Коснитесь экрана»;
- `"with_friends"` — «Попробуйте с другом»;
- `start_recording` — «Начните запись».

Касания экрана отслеживаются, если для маски указан параметр

`"mouse_input": true`.

Тип данных: `string`.

`mouse_input` Указывает, отслеживает ли маска касание экрана. Касание может являться триггером событий в [эффектах](https://dev.vk.ru/ru/masks/effects/overview) или [плагинах](https://dev.vk.ru/ru/masks/plugins/overview) или обрабатываться в [скриптах](https://dev.vk.ru/ru/masks/development/script-creation) с помощью события [`MouseEvent`](https://dev.vk.ru/ru/masks/development/events/MouseEvent) [.](https://dev.vk.ru/ru/masks/development/events/MouseEvent)

Если `"mouse_input": true`, двойное касание экрана (double tap) не приводит к переключению камер.

Тип данных: `boolean`.

`gestures_required` Указывает, распознаёт ли движок масок жесты рук. Для обработки жестов используйте [скрипты](https://dev.vk.ru/ru/masks/development/script-creation) — создайте обработчик события

[`UpdateHandGesture`](https://dev.vk.ru/ru/masks/development/events/UpdateHandGesture) [.](https://dev.vk.ru/ru/masks/development/events/UpdateHandGesture)

Тип данных: `boolean`.

| Параметр | Описание |
|---|---|
| `gallery_asset_required` | Указывает, будет ли движок масок показывать меню для выбора компонентов маски ( `true`) или нет ( `false`). |

Сейчас параметр используется только с плагином [`pickerui`](https://dev.vk.ru/ru/masks/plugins/pickerui) [.](https://dev.vk.ru/ru/masks/plugins/pickerui)

Тип данных: `boolean`. Значение по умолчанию: `false`.

`effects` Поле, в котором перечисляются все необходимые [эффекты](https://dev.vk.ru/ru/masks/effects/overview) маски. Тип данных: `array<obj>`.

`plugins` Поле, в котором перечисляются все необходимые [плагины](https://dev.vk.ru/ru/masks/plugins/overview) маски. Тип данных: `array<obj>`.

## Маска на два лица

Чтобы наложить маску на два лица, в файл конфигурации mask.json добавьте поле `"num_faces":` `"2"` и в параметре `nface` укажите, какой эффект какому лицу будет принадлежать. Например:

```json
{
    "icon": "Icon.png",
    "num_faces": 2,
    "effects": [
        {
            "name": "beautify",
            "nface": 0,
            "mix": 0.6
        },
        {
            "name": "beautify",
            "nface": 1,
            "mix": 0.6
        },
        {
            "name": "patch",
            "anchor": "fullscreen",
            "texture": "Textures/Dust.png"
        },
        {
            "name": "colorfilter",
            "lookup": "ColorFilter/lookup.png",
            "intensity": 0.75
        }
    ]
}
```

По умолчанию параметр `nface` имеет значение `0` (индекс лица начинается с нуля, соответственно второе лицо имеет индекс под номером `1`).

Важно! Распознавание двух лиц для мобильного устройства является ресурсоёмким процессом, который негативно сказывается на плавности изображения камеры.
