# Обзор возможностей

**Раздел:** Маски → Продвинутые возможности → Обзор возможностей  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

В качестве 3D-движка для масок используйте [Urho3D](https://urho3d.io/).

Взаимодействие с Urho3D осуществляется с помощью [AngelScript API](https://github.com/urho3d/Urho3D/blob/master/Docs/AngelScriptAPI.h). Если вы умеете программировать, то можете расширить возможности создания масок с помощью [скриптов](https://dev.vk.ru/ru/masks/development/script-creation) на языке AngelScript и доступных [событий](https://dev.vk.ru/ru/masks/development/events/overview).
