# Просмотр маски

**Раздел:** Маски → Подготовка → Просмотр маски  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Для просмотра маски необходимо мобильное устройство или компьютер с камерой. На мобильном устройстве должно быть установлено официальное приложение ВКонтакте.

## Просмотр маски на компьютере

### Шаг 1. Установите приложение для просмотра

#### Windows

1. Скачайте приложение [test.mask для Windows](https://mask.vk.me/app/test.mask3_windows.zip). Извлеките содержимое архива.

2. Найдите `test.mask3_windows` — это и есть основной файл приложения. Щёлкните дважды по файлу, чтобы запустить приложение.

Рекомендуем сразу создать ярлык приложения на рабочем столе.

#### Запуск test.mask с консолью

Если маска работает неправильно или вовсе не запускается, то разобраться в проблеме помогут сообщения об ошибках и другая информация, которую приложение выводит в консоль. По умолчанию консоль скрыта.

Чтобы приложение test.mask открывалось с консолью, необходимо изменить его настройки:

1. Создайте ярлык приложения test.mask.

2. Откройте правой кнопкой мыши свойства ярлыка.

3. В конце строки `Объект` через пробел допишите: `-console`.

4. Сохраните настройки.

#### macOS

1. Скачайте приложение [test.mask для macOS](https://mask.vk.me/app/test.mask3_macos.zip). Извлеките содержимое архива.

2. Найдите `test.mask3_macos` — это и есть основной файл приложения. Щёлкните дважды по файлу, чтобы запустить приложение.

В macOS консоль с сообщениями об ошибках запускается по умолчанию.

### Шаг 2. Откройте маску в приложении

#### Windows

1. В приложении test.mask нажмите на кнопку Open mask.

2. Зайдите через проводник в каталог с вашей маской, выберите файл `mask.json` и нажмите Открыть. Если вы всё сделали правильно, то увидите маску на своём лице.

#### macOS

1. В меню приложения test.mask выберите File → Open Mask....

2. Выберите каталог с проектом маски и нажмите Open. Если вы всё сделали правильно, то увидите маску на своем лице.

## Просмотр маски в мобильном приложении

1. Откройте на компьютере папку с проектом вашей маски и упакуйте все файлы и папки внутри неё в ZIP-архив. Обратите внимание, необходимо архивировать не папку проекта, а файлы и папки внутри проекта.

2. Откройте сообщество [Маски ВКонтакте](https://vk.com/msx) и нажмите Написать сообщение.

3. Прикрепите ZIP-архив к сообщению и отправьте его. В ответ бот пришлёт вам ссылку на маску. Например такую:

```
https://vk.com/mask66629999_17689
```

4. Откройте ссылку на мобильном устройстве. Если вы всё сделали правильно, то увидите маску на своём лице. Маска будет видна только вам, её автору (см. раздел [Уровни доступа](https://dev.vk.ru/ru/masks/publication/overview)).

## FAQ

### Как получить ссылку на маску?

Нужно отправить архив с готовой маской боту.

### Моя маска не открывается у друзей.

Сначала маску может тестировать только её автор. Если вы хотите показать свою маску друзьям, сперва её нужно [отправить на модерацию](https://dev.vk.ru/ru/masks/publication/moderation).

### Моя маска не отображается в каталоге.

Чтобы ваша маска появилась в каталоге, её нужно [отправить на модерацию](https://dev.vk.ru/ru/masks/publication/moderation).

### После загрузки архива не появляется ни ссылка на маску, ни ошибка.

Чаще всего ссылку на маску не получается создать из-за проблем с архивом. Попробуйте найти и исправить проблему так:

1. Удалите файлы скриптов. Если в вашей маске не используются скрипты, удалите все файлы с расширением `.as` — обычно это файл `main.as`, а также содержимое папок `Scripts` и

`ScriptEngine`.

2. Проверьте формат изображений. Чаще всего такая ошибка случается в macOS, если при сохранении изображения в графическом редакторе не указать формат файла явно. Проверьте, что все изображения сохранены в формате PNG. Не полагайтесь только на название файла — расширение `.png` не гарантирует, что используется именно PNG. Один из признаков неверного формата — большой вес файла.

### Маска загрузилась, но не отображается в камере, хотя в приложении для тестирования всё было в порядке.

Обычно такая проблема связана с чувствительностью мобильных устройств к регистру символов. Например, текстура расположена по адресу `Textures/Stars.png`, а в файле конфигурации путь к ней описан в нижнем регистре (маленькими буквами), как в примере ниже. Такая маска не будет работать на мобильном устройстве. Чтобы решить проблему, поправьте описание пути к текстуре с учётом регистра.

```json
{
        ...
        "effects" : [
            {
                "name" : "patch",
                "textures" : "textures/stars.png",
                ...
            }
        ]
    }
```

### [Ошибка] ZIP-архив содержит повторяющиеся имена файлов

Ошибка возникает в следующих случаях:

## • В архиве присутствует папка верхнего уровня, в которой находятся файлы маски. Перепакуйте архив, не включая в него папку верхнего уровня. Добавьте файлы так, как описано в вопросе В корне архива не найден файл `mask.json`. • Проблема связана с встроенным архиватором macOS. Он создаёт скрытые файлы с повторяющимися именами. Попробуйте использовать другой архиватор, например бесплатный [архиватор Keka](https://www.keka.io/ru/). Скачайте его, запустите и в настройках установите галочку Исключить вилки ресурсов Mac. После этого перетащите нужные файлы в окно архиватора Keka, чтобы создать архив маски.

### [Ошибка] в корне архива не найден файл mask.json

Эта ошибка может возникнуть в двух случаях: либо в вашем архиве действительно отсутствует файл `mask.json`, либо вы упаковали в ZIP-архив лишние папки.

Если все файлы маски находятся, например, в папке `Stars`, то в архив надо поместить именно содержимое `Stars`, а не саму папку. В примерах ниже показано, как архивировать правильно, а как — неправильно.
