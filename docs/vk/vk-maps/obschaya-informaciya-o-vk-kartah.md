# О VK Картах

**Раздел:** VK Карты → Общая информация → О VK Картах  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

VK Карты – картографический продукт компании VK, использующий базу открытых данных OpenStreetMap. Возможности продукта применяются в Mail, ВКонтакте, Юле и других продуктах корпорации. VK Карты также доступны широкому кругу разработчиков для использования в приложениях на различных платформах.

[Получите ключ и начните использовать VK Карты сейчас →](https://maps.vk.com/ru/welcome/)

## Решаемые задачи

Ниже — примеры типичных задач, которые вы можете выполнить с помощью VK Карт:

- [Отобразить карту в приложении](https://dev.vk.ru/ru/vkmaps/map-display-services/javascript-sdk/about).
- Помочь пользователям с [поиском адресов и интересных мест](https://dev.vk.ru/ru/vkmaps/search-and-geocoding/places).
- [Построить пешеходные, велосипедные и автомобильные маршруты](https://dev.vk.ru/ru/vkmaps/routing/direction) между точками.
- [Выбрать оптимальный маршрут](https://dev.vk.ru/ru/vkmaps/routing/optimal-route) для посещения нескольких мест.
- Помочь курьерам [найти оптимальные пути](https://dev.vk.ru/ru/vkmaps/routing/distance-matrix) к складам, а затем к заказчикам.
- [Определить область](https://dev.vk.ru/ru/vkmaps/routing/iso), достижимую в течение заданного времени.
- [Определить местоположение по IP-адресу](https://dev.vk.ru/ru/vkmaps/additional-services/ip2geo).
- Определить [высоту над уровнем моря](https://dev.vk.ru/ru/vkmaps/additional-services/elevation), [часовой пояс](https://dev.vk.ru/ru/vkmaps/additional-services/timezone) или [почтовый индекс точки](https://dev.vk.ru/ru/vkmaps/additional-services/postcode).

## Поддерживаемые языки

Мы стремимся к созданию полнофункциональных карт всего мира с максимальной поддержкой языков, интересующих наших клиентов. На текущий момент доступность того или иного языка определяется непосредственно самим языком и географическим регионом. Основные поддерживаемые языки — русский, английский и локальный в регионе.

## API

С помощью API VK Карт вы можете получать и использовать данные сервиса в любых приложения. Подробности — в разделе [Использование API VK Карт](https://dev.vk.ru/ru/vkmaps/general-information/api-key).

## С чего начать?

С получения ключа доступа. Он необходим для работы с SDK или API VK Карт.

[Получите ключ сейчас →](https://maps.vk.com/ru/welcome/)

## Демосервер

Чтобы опробовать работу с VK Картами, вы можете воспользоваться демонстрационным сервером по адресу: `https://demo.maps.vk.com/api/{endpoint}?{params}`. Для отправки запросов к нему ключ доступа не требуется.

Этот сервер нельзя использовать для продуктовой эксплуатации ваших приложений. Его работоспособность не гарантируется, а суммарное число запросов в секунду к нему ограничено.

## Техническая поддержка

Если вам необходима помощь или возникли вопросы при использовании сервисов VK Карт, отправьте нам сообщения по адресу `support.maps@lists.vk.team`. Обращайтесь по этому же адресу для получения актуальной информации по имеющимся у вас ключам доступа и действиям с ними.
