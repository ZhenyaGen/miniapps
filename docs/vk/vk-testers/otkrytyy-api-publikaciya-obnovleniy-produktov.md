# Публикация обновлений продуктов

**Раздел:** VK Testers → Открытый API → Публикация обновлений продуктов  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

На платформе тестировщик всегда работает с наиболее свежей версией продукта, поэтому все создаваемые отчёты прикрепляются к последней версии. Добавить новую версию продукта можно вручную через [интерфейс](https://vk.com/bugs) платформы VK Testers или автоматизировать процесс, используя метод API.

## Автоматическая публикация

Чтобы автоматизировать создание и публикацию версий продукта, используйте метод

[`bugtracker.saveProductVersion`](https://dev.vk.ru/ru/method/bugtracker.saveProductVersion) [.](https://dev.vk.ru/ru/method/bugtracker.saveProductVersion)

Добавьте вызов метода в скрипт, который отправляет обновления продукта на домен, в магазин приложений или систему дистрибуции. Заполните поля `title` и `release_notes`, тогда данные о новой версии продукта на платформе заполнятся автоматически.

После выполнения метода тестировщики продукта сразу получат уведомление о появлении обновления.

## Ручная публикация

Чтобы вручную опубликовать новую версию:

1. Откройте страницу продукта.

2. В блоке Версии нажмите Добавить.

После публикации тестировщики продукта сразу получат уведомление о появлении обновления.

## Скрытые обновления

Если сразу после добавления новой версии продукта нужно проверить и скорректировать описание, то можно создать скрытую версию продукта, передав параметр `visible=0`. В этом случае ответственный за публикацию сотрудник получит возможность заранее проверить содержимое текста и внести правки, а после — опубликовать обновление на тестировщиков.

При создании скрытой версии через API всем участникам продукта с правами на публикацию отправляется уведомление для быстрого перехода к редактированию версии.

## Автоматическая смена статусов

Если все исправленные в ближайшем обновлении ошибки находятся в статусе Исправлен, при передаче параметра set_rft=1 в момент публикации версии все такие отчёты будут автоматически переводиться в статус Готов к тестированию.

Если вы публикуете обновление вручную, установите соответствующий флажок.
