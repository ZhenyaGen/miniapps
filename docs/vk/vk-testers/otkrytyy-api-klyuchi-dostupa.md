# Ключи доступа

**Раздел:** VK Testers → Открытый API → Ключи доступа  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Для обращения к API платформы необходимо использовать ключи доступа компании или продукта. Ключ доступа продукта позволяет выполнять все действия в продукте с максимальным уровнем прав. Ключ доступа компании позволяет выполнять действия во всех продуктах компании.

Пример [запроса](https://dev.vk.ru/ru/api/api-requests) с ключом доступа компании:

```bash
curl -X POST 'https://api.vk.ru/method/bugtracker.getProductBuildUploadServer'
\
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'product_id=<ИДЕНТИФИКАТОР_ПРОДУКТА>' \
  -F 'v=5.199'
```

Есть ограничение на количество обращений с ключами доступа одной компании в сутки. Оно зависит от подключённого [тарифа](https://mcs.mail.ru/vk-testers/#price). Счётчик запросов проверяется и увеличивается до проверки параметров запроса. Доступное число запросов к API и статистику обращений можно найти в управлении компанией.

## Как получить ключ доступа компании

Чтобы получить ключ доступа компании, нужно иметь права руководителя компании.

Выполните следующие действия:

1. Откройте стартовую страницу баг-трекера в десктопной версии сайта ВКонтакте: [https://vk.com/bugs](https://vk.com/bugs).

2. Перейдите на вкладку Мои компании и выберите нужную компанию.

3. Перейдите на вкладку Управление и затем на вкладку Ключ доступа.

4. Скопируйте ключ доступа из текстового поля. Если вы получаете ключ впервые, нажмите на кнопку Получить ключ.

## Как получить ключ доступа продукта

Чтобы получить ключ доступа продукта, нужно иметь права менеджера продукта.

Выполните следующие действия:

1. Откройте стартовую страницу баг-трекера в десктопной версии сайта ВКонтакте: [https://vk.com/bugs](https://vk.com/bugs).

2. Перейдите на вкладку Мои продукты и выберите нужный продукт.

3. Перейдите на вкладку Управление и затем на вкладку Ключ доступа.

4. Скопируйте ключ доступа из текстового поля. Если вы получаете ключ впервые, нажмите на кнопку Получить ключ.
