## Урок 4. Дизайн UI мини-приложения

## Главное в уроке

- Переход от прототипов к разработке включает ряд шагов: разработку концепций, дизайн UI для основных сценариев, разработку дизайн-системы и стилей.
- На этапе создания дизайн-концепций продумайте внешний вид и структуру нескольких ключевых экранов, не пытайтесь охватить всю функциональность.
- При создании финального дизайна используйте стили, разработанные при создании концептов. Учитывайте разные состояния приложения. Подумайте о навигации, работе на больших и маленьких экранах, использовании светлых и тёмных цветовых схем, отображении сообщений об ошибках.
- Для разработки дизайна мы рекомендуем использовать [Figma](https://figma.com) и библиотеку [VKUI](https://vkui.io).
- Дизайн-система — набор правил, шаблонов, стилей и компонентов. Она значительно ускоряет создание макетов и продуктов, но трудоёмка в создании и поддержке. В небольших проектах можно обеспечить единство стиля без неё с помощью готовых библиотек, таких как VKUI.
- Для передачи разработчикам подготовьте материалы правильно: объедините их по пользовательским сценариям, используйте понятные имена. Отдельно соберите изображения и другие загружаемые файлы, чтобы их можно было легко скачать.
- Организуйте регулярные встречи с разработчиками, чтобы демонстрировать дизайн, объяснять идеи, получать отзывы. Предусмотрите несколько итераций до того, как макеты уйдут в разработку.
