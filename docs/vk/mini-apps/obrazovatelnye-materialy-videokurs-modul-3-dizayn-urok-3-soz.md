## Урок 3. Создание прототипа

## Главное в уроке

- Прототипы представляют путь пользователя в виде схематичных экранов. Они помогают понять, где будут расположены элементы UI, как они будут выглядеть, как будет работать навигация.
- Прототипы помогают команде выработать общее видение UI и сценариев работы пользователя, сформировать набор компонентов, используемых для дизайна и для UI приложения.
- Для создания прототипов можно использовать любые современные инструменты, например Figma, Axure или Miro. Выбранный инструмент должен обеспечивать лёгкий доступ к создаваемым прототипам, например через браузер, и быстрое внесение изменений.
- Этап прототипирования можно опустить и сразу после создания user flow перейти к дизайну UI. Однако, как показывает практика, в этом случае вам надо быть готовым к большему количеству переделок.
