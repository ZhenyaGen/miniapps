## Урок 4. Принципы запуска рекламной кампании

## Главное в уроке

- Чтобы определить оптимальную цену продвижения, экспериментируйте на минимальных бюджетах.
- Для создания успешных рекламных креативов используйте информацию о разных сегментах вашей целевой аудитории и проблемах, которые решает продукт.
- При запуске креативов на целевые аудитории отслеживайте их эффективность в рекламном кабинете пару раз в день, чтобы быстро отключать те, которые работают плохо.
- Для эффективной работы с ретаргетингом добавьте пиксель ретаргетинга в исходный код своего продукта. С его помощью вы сможете показывать рекламу тем пользователям, которые уже заходили в ваше приложение.
