## Модуль 4. Разработка

Модуль рассказывает, как создать код мини-приложения на примере проекта «Блюдо дня». Мы будем использовать Node.js и TypeScript. Вы узнаете, как создать проект, сверстать экраны приложения, добавить навигацию, вызывать и обрабатывать события VK Bridge, отправлять уведомления и сообщения, создавать истории, использовать VK Карты, работать с API ВКонтакте. А ещё разберётесь в инструментах, упрощающих отладку приложений на мобильных устройствах.

Мы разместили исходный код [клиентской](https://github.com/VKCOM/vk-mini-apps-course-frontend) и [серверной](https://github.com/VKCOM/vk-mini-apps-course-backend) частей мини-приложения в публично доступных GitHub-репозиториях.

Фрагменты кода, которые соответствуют тому или иному уроку, отмечены комментариями с хештегами вида #M4L9, где M4 — указатель на модуль 4, L9 — указатель на номер урока.
