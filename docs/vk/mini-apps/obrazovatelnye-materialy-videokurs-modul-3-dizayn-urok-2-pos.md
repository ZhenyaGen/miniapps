## Урок 2. Построение пути пользователя

## Главное в уроке

- User flow — это схема работы пользователя в приложении: с чего он начинает, через какие этапы проходит, что получает, какие могут возникнуть препятствия. В хорошей схеме продуманы все пути взаимодействия пользователя с приложением.
- Для визуализации схемы чаще всего достаточно использовать прямоугольники, стрелки и линии.
- Начните составлять схему с основного пути пользователя. Затем продумайте возможные ответвления, дополнительные сценарии.
- Простая схема может предусматривать только безотказную работу приложения. В реальности пользователь может столкнуться с ошибками. Предусмотрите эти ситуации в схеме решения.
- Если в дальнейшей работе вы нашли ошибки в сценариях, вернитесь к схеме user flow и проработайте её заново, прежде чем продолжать создание приложения.
