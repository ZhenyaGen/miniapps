## Урок 2. Процесс создания мини-приложения

## Главное в уроке

- Создание мини-приложения состоит из нескольких этапов. Каждому этапу мы посвятили отдельный модуль. Чтобы разработать качественное приложение, рекомендуем проходить модули последовательно:

- [Выбор идеи](https://dev.vk.ru/ru/mini-apps/learning/course/2-idea)
- [Дизайн](https://dev.vk.ru/ru/mini-apps/learning/course/3-design)
- [Разработка](https://dev.vk.ru/ru/mini-apps/learning/course/4-development)
- [Тестирование](https://dev.vk.ru/ru/mini-apps/learning/course/5-testing)
- [Модерация](https://dev.vk.ru/ru/mini-apps/learning/course/6-moderation)
- [Монетизация](https://dev.vk.ru/ru/mini-apps/learning/course/7-monetization)
- [Продвижение](https://dev.vk.ru/ru/mini-apps/learning/course/8-promotion)
- Сразу после регистрации ваше мини-приложение может быть доступно по прямой ссылке. Это удобно, если нужно протестировать гипотезу с помощью вашего сервиса.
