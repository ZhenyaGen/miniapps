## Урок 3. Формируем команду для создания мини-приложений

## Главное в уроке

- При формировании команды для создания мини-приложений отталкивайтесь от навыков её участников. Исходя из своего опыта, мы определили, что оптимальная команда для создания мини-приложения выглядит так:

- 2 фронтенд-разработчика с базовыми навыками веб-разработки (HTML, JavaScript и CSS).
- 2 бэкенд-разработчика со знанием PHP или Node.js (GoLang — опционально).
- UX/UI-дизайнер с опытом создания интерфейсов веб-приложений.
- Для разработки клиентской части мы рекомендуем использовать библиотеку React, чтобы вам было проще работать с нашей библиотекой компонентов VKUI.
- Один из участников должен взять на себя роль лидера команды и координировать работу над сервисом. А с дальнейшим развитием мини-приложения всё больше уходить от разработки и заниматься развитием навыков участников, постановкой целей и масштабированием сервиса.
- Также для развития и продвижения мини-приложения могут потребоваться компетенции специалистов по маркетингу и контенту.
