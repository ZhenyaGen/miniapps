## Значения параметра запуска vk_ref для мини-приложений

В параметре `vk_ref` передаются данные об источнике запуска. Параметр может принимать следующие значения:

- Категории в каталоге:

## • `catalog_recent` — категория Недавние. • `catalog_recommendation` — категория Рекомендации. • `catalog_friends_recommendations` — категория Рекомендации друзей. • `catalog_top_dau` — категория Популярное. • `catalog_sport` — категория Спорт. • `catalog_entertainment` — категория Развлечения. • `catalog_communication` — категория Общение. • `catalog_tools` — категория Инструменты. • `catalog_shopping` — категория Покупки. • `catalog_lifestyle` — категория Образ жизни. • `catalog_travel` — категория Путешествия. • `catalog_finance` — категория Финансы. • `catalog_food` — категория Еда и напитки. • `catalog_events` — категория Мероприятия. • `catalog_education` — категория Образование. • `catalog_social` — категория Социальные. • `catalog_payments` — категория Оплата услуг. • `catalog_health` — категория Красота и здоровье. • `catalog_job` — категория Новости, работа. • `catalog_realty` — категория Недвижимость. • `catalog_business` — категория Бизнес. • `catalog_taxi` — категория Транспорт. • `catalog_favorites` — категория Избранное. • `catalog_admin` — категория Созданные. • Плагины:

## • `community_installed_app_settings` — панель управления сообществом. • `community_installed_app_popup` — меню Действия в плагине или событие [`VKWebAppAddToCommunity`](https://dev.vk.ru/ru/bridge/VKWebAppAddToCommunity) [.](https://dev.vk.ru/ru/bridge/VKWebAppAddToCommunity) • Обсуждения в сообществе:

- `board_topic_all` — предварительный просмотр обсуждений, где перечислены все обсуждения сообщества.
- `board_topic_view` — экран обсуждения, где отображены все комментарии обсуждения.

- Лента:

## • `feed` — вкладка Новости ленты новостей. • `feed_post` — ссылка записи без сниппета. • `feed_comments` — комментарий к записи. • Фичеринг:

## • `featuring_discover` — блок рекомендаций в ленте новостей. • `featuring_menu` — блок Мини-приложения в мобильной версии сайта (m.vk.com). • `featuring_new` — виджет на вкладке Для вас приложения ВКонтакте. • `catalog_messenger_apps_with_action` – запуск приложения, интегрированного в мессенджер, из каталога. • Закладки:

## • `fave` — общий список закладок. • `fave_links` — вкладка Ссылки закладок. • `fave_posts` — вкладка Записи закладок. • Сообщества:

- `group` — стена сообщества.
- `group_menu` — меню сообщества (Android).
- `group_messages` — сообщения сообщества.
- `group_addresses` — адрес сообщества.
- Сниппеты:

- `snippet_post` — сниппет записи.
- `snippet_im` — сниппет в личных сообщениях.
- Клипы:

- `clips` — экран клипов (iOS).
- `comments_list_clip` — из комментариев к клипу (Android).
- Чаты:

- `im` — предварительный просмотр чата.
- `im_chat` — экран чата.
- `im_attach_picker` – запуск из аттач-пикера.
- `im_app_action` – запуск из виджета приложения, интегрированного в мессенджер.
- Уведомления:

- `notifications` — заблокированный экран, где сгруппированы уведомления.
- `notifications_grouped` — экран сгруппированных уведомлений.
- `notifications_auto` — одно или сгруппированное автоматическое уведомление.
- Поиск:

- `search_all` — поисковая выдача на общей странице поиска (Android, iOS, мобильная версия сайта ВКонтакте).

- `search_all_recommendation` — рекомендации, когда задан пустой поисковый запрос (Android, iOS, мобильная версия сайта ВКонтакте).
- `search_all_block` — поисковая выдача на отдельной странице поиска по мини- приложениям (Android, iOS, мобильная версия сайта ВКонтакте).

## • Вкладка «Сервисы»: • `showcase` — меню. • `recs` — виджет «Для вас». • `mini_widget_<id>` — мини-виджет. • `promo_widget_<state>` — промо-виджет. • `widget_<id>` или `widget_<id>_<state>` — плиточный виджет. • `section_<id>` или `section_<id>_<state>` — секция. • `super_app` — вкладка Сервисы приложения ВКонтакте. • `profile` — записи профиля. • `group_apps_block` — блок Приложения справа на странице сообщества. • `article_read` — статья сообщества. • `music_playlist` — музыкальный плейлист. • `video_carousel` — видео (iOS). • `photo_browser` — экран просмотра фотографий записи (iOS). • `shopping_center` — лента товаров (iOS). • `market_item` — экран товара. • `story${user_id}_${params}` — история. • `widget` — виджет на вкладке Сервисы приложения ВКонтакте. • `showcase` — витрина на вкладке Сервисы приложения ВКонтакте. • `home_screen` — домашний экран устройства (Android). • `left_nav` — левое меню в десктопной версии сайта ([vk.com](https://vk.com)). • `quick_search` — результаты быстрого поиска. • `menu` — блок Мини-приложения на вкладке Ещё в мобильной версии сайта ([m.vk.com](https://m.vk.com)).

- `other` — прочие источники.
