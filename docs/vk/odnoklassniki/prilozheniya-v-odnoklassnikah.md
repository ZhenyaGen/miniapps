# Приложения в Одноклассниках

**Раздел:** Приложения в Одноклассниках  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Приложения и игры, созданные на платформе VK Mini Apps, можно опубликовать в [Одноклассниках](https://ok.ru). Вся настройка выполняется в панели управления игры или мини-приложения на [единой платформе](https://dev.vk.com/ru/admin/apps-list).

При создании приложений для Одноклассников важно учитывать их отличия от приложений, размещённых ВКонтакте.

## Требования

- Не используйте внешние ссылки — они не должны уводить пользователя из Одноклассников. Проверьте, что при шаринге приложения ссылки не ведут ВКонтакте или на другие сайты.
- Храните прогресс для каждой соцсети отдельно. Прогресс пользователей Одноклассников сохраняйте на бэкенде приложения и синхронизируйте между устройствами.

## Разработка

### Библиотека VK Bridge

Учитывайте особенности событий VK Bridge при работе на платформе Одноклассники. В [таблице](https://dev.vk.ru/ru/ok/development/bridge) мы указали все события, которые поддерживаются в Одноклассниках.

Рекомендуем обратить особое внимание на [методы социальных механик](https://dev.vk.ru/ru/ok/development/bridge#%D0%A1%D0%BE%D1%86%D0%B8%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5%20%D0%BC%D0%B5%D1%85%D0%B0%D0%BD%D0%B8%D0%BA%D0%B8%20%D0%B8%20%D0%B2%D0%B7%D0%B0%D0%B8%D0%BC%D0%BE%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B5), а также:

- [`VKWebAppGetClientVersion`](https://dev.vk.ru/ru/bridge/VKWebAppGetClientVersion)
- [`VKWebAppCallAPIMethod`](https://dev.vk.ru/ru/bridge/VKWebAppCallAPIMethod)
- [`VKWebAppGetAuthToken`](https://dev.vk.ru/ru/bridge/VKWebAppGetAuthToken)

### API Одноклассников

Чтобы обратиться к API Одноклассников:

1. Вызовите сначала событие [`VKWebAppGetAuthToken`](https://dev.vk.ru/ru/bridge/VKWebAppGetAuthToken) для получения ключа доступа. В параметре `append_local` укажите значение `true`. Ключ доступа для Одноклассников вернётся в ответе в поле `local_access_token`.

2. Вызовите нужный метод API c помощью события [`VKWebAppCallAPIMethod`](https://dev.vk.ru/ru/bridge/VKWebAppCallAPIMethod), указав нужный метод. В параметре `use_local` укажите значение `true`.

### Параметры запуска

Если приложение работает в Одноклассниках, оно получает другие значения параметров запуска. Подробнее — в разделе [Параметры запуска в Одноклассниках](https://dev.vk.ru/ru/ok/development/launch-parameters).

## Публикация

Опубликовать мини-приложения и игры можно сразу и ВКонтакте, и в Одноклассниках. Для этого в панели управления подайте заявки на модерацию на платформы Web и Mobile и выберите площадки для публикации: ВКонтакте или Одноклассники. Игры в Одноклассниках будут размещены в каталоге, мини-приложения станут доступны по ссылке всем пользователям.

Подробнее — в разделе [Публикация в Одноклассниках](https://dev.vk.ru/ru/ok/publishing).

## Монетизация

### Реклама

Если в вашем приложении ВКонтакте уже подключена рекламная монетизация, объявления автоматически будут показываться и в Одноклассниках.

Подробнее — в разделах:

- [VK Games | Монетизация | Реклама в играх](https://dev.vk.ru/ru/games/monetization/ad/overview)
- [Мини-приложения | Монетизация | Реклама в мини-приложениях](https://dev.vk.ru/ru/mini-apps/monetization/ad/overview)

### Голоса и ОКи

ВКонтакте и Одноклассники используют [голоса](https://dev.vk.ru/ru/mini-apps/glossary#%D0%93%D0%BE%D0%BB%D0%BE%D1%81) и [ОКи](https://dev.vk.ru/ru/mini-apps/glossary#%D0%9E%D0%9A%D0%B8) — условные единицы, которые пользователи могут обменять на виртуальные ценности.

Код и настройки приложения нужно адаптировать под каждую социальную сеть, чтобы голоса использовались только ВКонтакте, а ОКи — в Одноклассниках.

Подробнее об использовании ОКов в Одноклассниках — в разделах:

- [Продажа виртуальных ценностей](https://dev.vk.ru/ru/api/payments/virtual-goods/ok)
- [Продажа подписок](https://dev.vk.ru/ru/api/payments/subscriptions/ok)
- [Обработка платёжных уведомлений](https://dev.vk.ru/ru/api/payments/notifications/ok)

## Продвижение

- Используйте социальные механики — обратите внимание на соответствующие [события библиотеки](https://dev.vk.ru/ru/ok/development/bridge#%D0%A1%D0%BE%D1%86%D0%B8%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5%20%D0%BC%D0%B5%D1%85%D0%B0%D0%BD%D0%B8%D0%BA%D0%B8%20%D0%B8%20%D0%B2%D0%B7%D0%B0%D0%B8%D0%BC%D0%BE%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B5) [VK Bridge](https://dev.vk.ru/ru/ok/development/bridge#%D0%A1%D0%BE%D1%86%D0%B8%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5%20%D0%BC%D0%B5%D1%85%D0%B0%D0%BD%D0%B8%D0%BA%D0%B8%20%D0%B8%20%D0%B2%D0%B7%D0%B0%D0%B8%D0%BC%D0%BE%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B5).
- После размещения игры в каталоге Одноклассников вы сможете продвигать её через фичеринг, добавление в подборки и другие доступные способы продвижения.

Подробнее — в разделе [Продвижение](https://dev.vk.ru/ru/ok/promotion/overview).
