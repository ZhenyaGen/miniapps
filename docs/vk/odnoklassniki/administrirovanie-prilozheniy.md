# Администрирование приложений

**Раздел:** Одноклассники → Администрирование приложений  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Администрирование игр и мини‑приложений, опубликованных в социальных сетях VK, осуществляется в панели управления на [единой платформе](https://dev.vk.com/ru/admin/apps-list). В этой статье описаны роли администраторов, требования для работы с площадкой Одноклассники (ok.ru), а также шаги по привязке OK ID и получению прав разработчика.

Чтобы запустить приложение в Одноклассниках, необходимо опубликовать его в разделе Другие площадки. Эта возможность доступна только создателю приложения. Подробнее — в разделе [Публикация в Одноклассниках](https://dev.vk.ru/ru/ok/publishing#%D0%A8%D0%B0%D0%B3%202.%20%D0%9F%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D0%B5%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%BA%20%D0%9E%D0%B4%D0%BD%D0%BE%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%BD%D0%B8%D0%BA%D0%B0%D0%BC).

## Роли и права

Администраторы — пользователи, авторизованные на [единой платформе](https://dev.vk.com/ru/admin/apps-list) по VK ID, которые занимаются разработкой, тестированием и поддержкой работы приложения. Чтобы администратор мог работать с приложением в Одноклассниках, он должен связать VK ID и OK ID и получить права разработчика.

Ниже описаны основные роли и их возможности по управлению приложением в Одноклассниках.

Подробнее о том, как назначить администраторов и настроить их права в панели управления:

- [Администраторы (настройки игр)](https://dev.vk.ru/ru/games/settings/managers)
- [Администраторы (настройки мини-приложений)](https://dev.vk.ru/ru/mini-apps/settings/managers)

### Создатель

Создатель — это главный администратор приложения. Он имеет полный доступ к настройкам в панели управления и может тестировать приложение на всех площадках. Также у создателя есть права, недоступные другим администраторам:

- Вывод средств, полученных за показы рекламы или продажу товаров.
- Удаление приложения с единой платформы.
- Публикация приложения на других социальных площадках VK.
- Тестирование инструментов монетизации до прохождения модерации.

Если приложение подключено к Одноклассникам, назначить новым создателем можно только пользователя, у которого связаны VK ID и OK ID и получены права разработчика.

Если вы измените создателя в панели управления, необходимо также указать актуального исполнителя в кабинете выплат. Подробнее о работе с кабинетом выплат — в разделе [Вывод](https://dev.vk.ru/ru/games/monetization/withdrawal/overview) [средств](https://dev.vk.ru/ru/games/monetization/withdrawal/overview).

### Администратор с полным доступом

Администратор с полным доступом может управлять настройками приложения, но не имеет исключительных прав создателя.

Права администратора с полным доступом:

- Настройка приложения в панели управления.
- Тестирование приложения до прохождения модерации на всех подключённых площадках.

### Администратор с частичным доступом

Права администратора с частичным доступом складываются из одного или нескольких прав, которые им выдал создатель или администратор с полным доступом.

Например, администратор с частичным доступом с правом «Тестирование» может запускать приложение до прохождения модерации на всех подключённых площадках.

## Связать аккаунты разработчика VK ID и OK ID

1. Авторизуйтесь в [аккаунте VK ID](https://id.vk.com/about/id) администратора приложения, который будет работать с приложением в Одноклассниках.

2. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list) и откройте настройки нужного приложения.

3. Чтобы связать ваши аккаунты VK ID и OK ID, в виджете справа нажмите Привязать.

4. Откроется раздел [Сервисы и сайты](https://id.vk.com/account/#/services) в личном кабинете VK ID. Выберите OK и следуйте инструкциям на экране, чтобы связать аккаунты.

5. После того как аккаунты связаны, администратор должен принять оферту и получить права разработчика в Одноклассниках. Для этого в панели управления на виджете справа нажмите Получить.

6. На экране появится диалоговое окно с соглашением о предоставлении вам прав разработчика. Прочитайте соглашение и нажмите Получить права разработчика.
