# Опрос

**Раздел:** Интеграция → Виджеты → Опрос  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

При помощи виджета для опросов вы можете за 5 минут организовать опрос пользователей своего сайта, расположив соответствующий блок в любом месте страницы.

Посетители одним нажатием кнопки мыши могут выразить своё мнение и моментально поделиться им с друзьями, опубликовав результат на своей странице ВКонтакте. Для этого пользователю не придётся самому вводить какую-либо информацию, поэтому ссылка на статью с таким опросом сможет распространиться максимально быстро.

## Подключение виджета

Чтобы добавить на свой сайт виджет сообщества ВКонтакте, выполните эти шаги:

Шаг 1. Создайте опрос. Укажите тему опроса и несколько вариантов ответов. Нажмите кнопку Получить код, чтобы увидеть идентификатор опроса.

Шаг 2. В тег `<head>` на странице вашего сайта добавьте подключение `openapi.js`:

```html
<script src="https://vk.ru/js/api/openapi.js?169" type="text/javascript">
</script>
```

Шаг 3. В тело страницы сайта добавьте код для инициализации Open API:

```html
<script type="text/javascript">
      VK.init({
        apiId: ВАШ_API_ID,
        onlyWidgets: true
      });
</script>
```

Более подробно про инициализацию транспорта вы можете узнать на [этой странице](https://dev.vk.ru/ru/api/open-api/getting-started).

В тело страницы добавьте элемент `<div>`, в котором будут отображаться комментарии, задайте ему уникальный `id`, и добавьте в него код инициализации виджета. Например:

```html
<div id="vk_poll"></div>
<script type="text/javascript">
    VK.Widgets.Poll('vk_poll', {}, POLL_ID);
</script>
```

Вместо `POLL_ID` необходимо указать идентификатор опроса, полученный на начальном этапе.

Этот код добавляет блок опроса стандартного вида. Ширина блока будет подобрана автоматически в зависимости от положения элемента `vk_poll`.

Если на вашем сайте уже используется [Open API](https://dev.vk.ru/ru/api/open-api/getting-started), добавить виджет ещё проще. Достаточно просто добавить инициализацию виджета.

Обратите внимание, что код для встраивания виджета вы можете получить из любого опроса на сайте. Достаточно открыть опрос и нажать Получить код.

## Дополнительные настройки

Метод `VK.Widgets.Poll` принимает три параметра:

- `element_id` — ( `string`), обязательный параметр — id элемента, который будет являться контейнером для блока с виджетом. В нашем конструкторе по умолчанию используется значение

`vk_poll`.
- `options` ( `object`) — опции блока с виджетом. Объект, который может содержать поля:

- `width` ( `integer`) — ширина блока в пикселях. Минимальное значение: `300`.
- `pageUrl` ( `string`) — адрес страницы (для отображения в превью записей на стене ВКонтакте). Указывайте в том случае, если адрес, по которому можно посмотреть опрос, отличается от адреса текущей страницы.
- `poll_id` ( `string`), обязательный параметр — идентификатор опроса. Вы можете получить его с помощью формы на этой странице или с помощью кнопки «Получить код» в уже существующем опросе.

## Пример

```html
<div id="vk_poll"></div>
<script type="text/javascript">
    window.onload = function () {
        VK.init({apiId: 111});
        VK.Widgets.Poll('vk_poll', {width: 500},
'6564504_c2a6ccb7df15aff473');
    }
</script>
```

## Использование с AMP

AMP — это технология, расширяющая HTML для ускоренной загрузки контента на мобильных устройствах. Она позволяет владельцам сайтов быстро и просто генерировать отдельные версии страниц для просмотра с мобильных устройств или встраивания на другие ресурсы.

Вы можете встроить виджет опроса в AMP-версию страницы своего сайта с помощью тега `<amp-` `vk>`. Он поддерживает следующие атрибуты:

- `layout` — определяет положение контента в документе. Поддерживаются значения `responsive`, `flex-item`, `fixed`;
- `width` — ширина элемента в `px` (не учитывается для `layout = responsive` или `flex-item`);
- `height` — высота элемента в `px` (не учитывается для `layout = responsive` или `flex-item`);
- `data-embedtype` — тип контента, для виджета опроса всегда содержит `poll`;
- `data-api-id` — идентификатор вашего приложения ВКонтакте;

- `data-poll-id` — идентификатор опроса.

Например:

```html
<amp-vk
    layout="responsive"
    width="400"
    height="300"
    data-embedtype="poll"
    data-api-id="6183531"
    data-poll-id="274086843_1a2a465f60fff4699f">
</amp-vk>
```

Описание расширения AMP-VK на [GitHub](https://github.com/ampproject/amphtml/blob/main/extensions/amp-vk/amp-vk.md).
