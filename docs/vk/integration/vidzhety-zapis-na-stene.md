# Запись на стене

**Раздел:** Интеграция → Виджеты → Запись на стене  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

При помощи виджета записей вы можете встроить на свой сайт отдельную запись пользователя или сообщества ВКонтакте.

Виджет позволяет пользователям вашего сайта не только ознакомиться с самой записью, но также моментально оценить её, поделиться с друзьями или подписаться на страницу автора. А благодаря широким мультимедийным возможностям виджета вы сможете послушать прикреплённые аудиозаписи, посмотреть видео и рассмотреть фотографии не уходя со страницы с виджетом.

## Подключение виджета

Чтобы добавить на ваш сайт виджет записи ВКонтакте, необходимо у интересующей записи или комментария нажать кнопку Поделиться, в открытом окне в правом нижнем углу нажать на ссылку Экспорт записи и из открывшегося окна экспорта скопировать код для вставки. Этот код нужно вставить на страницу, где должен находиться виджет.

## Дополнительные настройки

Метод `VK.Widgets.Post` принимает пять параметров:

- `element_id` ( `string`), обязательный параметр — `id` элемента, который будет являться контейнером кнопки для связи. В нашем конструкторе по умолчанию используется значение

`vk_post_{owner_id}_{post_id}`.
- `owner_id` ( `integer`), обязательный параметр — идентификатор владельца стены, на которой размещена запись.
- `post_id` ( `integer`), обязательный параметр — идентификатор записи на стене.
- `hash` ( `string`), обязательный параметр — служебный параметр. Получить `hash` можно только в конструкторе виджета или в окне «Поделиться» для выбранной записи.
- `options` ( `object`) — опции виджета. Объект, который может содержать следующее поле:

- `width` ( `integer`) — ширина блока в пикселях. По умолчанию блок с записью растягивается на всю ширину страницы.

## Пример

```html
<div id="vk_post_1_45616"></div>
<script type="text/javascript">
  (function(d, s, id) { var js, fjs = d.getElementsByTagName(s)[0]; if
(d.getElementById(id)) return; js = d.createElement(s); js.id = id; js.src =
"https://vk.ru/js/api/openapi.js?169"; fjs.parentNode.insertBefore(js, fjs); }
(document, 'script', 'vk_openapi_js'));
  (function() {
    window.VK && VK.Widgets && VK.Widgets.Post &&
VK.Widgets.Post("vk_post_1_45616", 1, 45616, 'ZMk4b98xpQZMJJRXVsL1ig', {width:
500}) || setTimeout(arguments.callee, 50);  }());
</script>
```

## Использование с AMP

AMP — это технология, расширяющая `HTML` для ускоренной загрузки контента на мобильных устройствах. Она позволяет владельцам сайтов быстро и просто генерировать отдельные версии страниц для просмотра с мобильных устройств или встраивания на другие ресурсы.

Вы можете встроить виджет записи в AMP-версию страницы своего сайта с помощью тега `<amp-` `vk>`. Он поддерживает следующие атрибуты:

- `layout` — определяет положение контента в документе. Поддерживаются значения `responsive`, `flex-item`, `fixed`;
- `width` — ширина элемента в `px` (не учитывается для `layout = responsive` или `flex-item`);
- `height` — высота элемента в `px` (не учитывается для `layout = responsive` или `flex-item`);
- `data-embedtype` — тип контента, для виджета записи всегда содержит `post`;
- `data-owner-id` — идентификатор владельца записи;
- `data-post-id` — идентификатор записи;
- `data-hash` — `hash` записи.

Например:

```html
<amp-vk
    layout="responsive"
    width="500"
    height="300"
    data-embedtype="post"
    data-owner-id="1"
    data-post-id="45616"
    data-hash="Yc8_Z9pnpg8aKMZbVcD-jK45eAk">
</amp-vk>
```

Описание расширения AMP-VK на [GitHub](https://github.com/ampproject/amphtml/blob/main/extensions/amp-vk/amp-vk.md).
