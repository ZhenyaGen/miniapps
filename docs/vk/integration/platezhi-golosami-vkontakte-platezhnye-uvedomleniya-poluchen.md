# Получение информации о товаре

**Раздел:** Интеграция → Платежи голосами ВКонтакте → Платёжные уведомления → Получение информации о товаре  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Получение информации о товаре (get_item)

ВКонтакте отправляет уведомление `get_item` серверу приложения (игры или мини-приложения) перед показом окна [покупки](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%9E%D0%B1%D0%BC%D0%B5%D0%BD%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%BC%D0%B8%20%D0%BC%D0%B5%D0%B6%D0%B4%D1%83%20%D0%92%D0%9A%D0%BE%D0%BD%D1%82%D0%B0%D0%BA%D1%82%D0%B5%20%D0%B8%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%D0%BC). Сервер в своём ответе должен предоставить информацию, которая будет отображена в окне покупки.

## Уведомление

Данные приходят в теле запроса в виде строки, содержащей пары `параметр=значение`. Пары разделены символами `&`.

### Пример

```
app_id=1524456&item=sale_item_1&lang=ru_RU&notification_type=get_item_test&ord
er_id=2044594&receiver_id=1&user_id=1&version=5.132&sig=a71ec5b6c78940fa47a837
96ee983ab6
```

### Параметры

| Параметр | Тип | Примечание |
|---|---|---|
| `app_id` | `integer` | Идентификатор приложения, в котором происходит покупка. |

Значение должно совпадать с идентификатором, который отображается в [настройках приложения](https://dev.vk.ru/ru/mini-apps/management/settings#%D0%9D%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8).

`item` `string` Идентификатор товара, который использует ваше приложение и который оно передало событию [`VKWebAppShowOrderBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowOrderBox) библиотеки VK Bridge. [Пример вызова события](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%A8%D0%B0%D0%B3%203.%20%D0%92%D1%8B%D0%B7%D0%BE%D0%B2%D0%B8%D1%82%D0%B5%20%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D0%B5%20VK%20Bridge%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D0%B0%20%D0%BE%D0%BA%D0%BD%D0%B0%20%D0%BF%D0%BE%D0%BA%D1%83%D0%BF%D0%BA%D0%B8).

Сервер в своём ответе должен предоставить информацию о покупаемом товаре, которая будет отображена в окне покупки.

`lang` `string` Язык пользователя, создавшего заказ. Возможно одно из следующих значений:
- `ru_RU` — русский
- `uk_UA` — украинский
- `be_BY` — белорусский
- `en_US` — английский.

Ваш сервер может проверять значение этого параметра, чтобы [возвращать описание товара на языке пользователя](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%BA%D0%B0%20%D0%BC%D0%BD%D0%BE%D0%B3%D0%BE%D1%8F%D0%B7%D1%8B%D1%87%D0%BD%D1%8B%D1%85%20%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D1%84%D0%B5%D0%B9%D1%81%D0%BE%D0%B2).

`notification_type` `string` Тип уведомления. В рабочем режиме прохождения платежей параметр равен `get_item`, в [тестовом](https://dev.vk.ru/ru/api/payments/testing) — `get_item_test`.

`order_id` `integer` Идентификатор заказа в системе платежей ВКонтакте.

**Параметр | Тип | Примечание**

`receiver_id` `integer` Идентификатор пользователя, который получит заказ. В данный момент совпадает с `user_id`, но в будущем может отличаться.

`user_id` `integer` Идентификатор пользователя, создавшего заказ.

`version` `string` Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе Платежи в поле [Версия API](https://dev.vk.ru/ru/api/payments/subscriptions#%D0%A8%D0%B0%D0%B3%202.%20%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20%D0%B0%D0%B4%D1%80%D0%B5%D1%81%20%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D0%BE%D0%B3%D0%BE%20%D0%B2%D1%8B%D0%B7%D0%BE%D0%B2%D0%B0%20%D0%B2%20%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0%D1%85%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F).

Параметр используется только для версии `5.132` и более поздних.

`site` `string` Площадка, на которой пользователь совершает покупку.

`VK` — ВКонтакте. Значение по умолчанию `OK` — в Одноклассниках.

`sig` `string` Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D0%BE%D0%B2) [и её проверке](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D0%BE%D0%B2).

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A0%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%20%D1%81%D0%BE%20%D1%81%D1%82%D1%80%D0%BE%D0%BA%D0%BE%D0%B2%D1%8B%D0%BC%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%BC%D0%B8) перед обработкой.

## Ответ сервера

По идентификатору товара, указанному в параметре запроса `item`, сервер должен вернуть информацию о товаре. Если запрашиваемый товар отсутствует, надо вернуть ошибку с [кодом](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9A%D0%BE%D0%B4%D1%8B%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) [`20`](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9A%D0%BE%D0%B4%D1%8B%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) («Товара не существует»).

### Пример ответа

```json
{
  "response": {
    "title": "300 изумрудов",
    "price": 27,
    "photo_url": "https://my-app.example.com/sale-item-1.png",
    "discount": 3,
    "item_id": "sale_item_1",
    "expiration": 3600
  }
}
```

### Поля

| Поле | Тип | Описание |
|---|---|---|
| `title` обязательное | `string` | Название товара для отображения в диалоговом окне покупки. Максимальная длина — 48 символов. |

`photo_url` `string` Полный URL изображения товара (включая адрес сервера и протокол). Рекомендуемый размер изображения — 75×75 px.

| `price` обязательное | `integer` Стоимость товара в [голосах ВКонтакте](https://dev.vk.ru/ru/mini-apps/glossary#%D0%93%D0%BE%D0%BB%D0%BE%D1%81). |
|---|---|
| `discount` | `integer` Размер скидки на товар в голосах. Значение скидки должно быть в пределах от `1` до `1 000` и должно быть меньше, чем стоимость товара, указанная в поле `price`. Если скидка не предусмотрена, верните `0` или не указывайте параметр в ответе. |
| `item_id` | `string` Идентификатор товара, используемый в вашем приложении. Передайте то же значение, которое было получено в параметре `item` уведомления. |
| `expiration` | `integer` Временной период, в течение которого платформа будет хранить информацию о товаре в кеше. Период указывается в секундах. Допустимый диапазон — от `600` до `604 800`. Если значение меньше нижней или больше верхней границы, то будет установлено минимальное или максимальное значение. `0` означает отказ от кеширования. |

Совет. Мы рекомендуем всегда использовать [кеширование](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9A%D0%B5%D1%88%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%B8%D0%BD%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%86%D0%B8%D0%B8%20%D0%BE%20%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0%D1%85%20%D0%B8%20%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D0%BA%D0%B0%D1%85). Это ускоряет процесс покупки для пользователей, а также уменьшает количество обращений к серверу приложения. Пока информация о товаре хранится в кеше, ВКонтакте использует данные из кеша и не отсылает уведомления `get_item` серверу.

Значения в полях ответа можно изменять в зависимости от языка пользователя, указанного в параметре `lang` запроса. То есть для одного и того же идентификатора товара можно возвращать разные названия и изображения в зависимости от языка.

Данные для разных языков пользователя кешируются отдельно друг от друга.

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:

```json
{
  "error": {
        "error_code": 20,
        "error_msg": "Товара не существует",
        "critical": true
    }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A4%D0%BE%D1%80%D0%BC%D0%B0%D1%82%20%D0%BE%D1%82%D0%B2%D0%B5%D1%82%D0%B0%20%D0%BF%D1%80%D0%B8%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B5).
