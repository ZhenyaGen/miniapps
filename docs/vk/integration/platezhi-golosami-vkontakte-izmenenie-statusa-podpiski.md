# Изменение статуса подписки

**Раздел:** Интеграция → Платежи голосами ВКонтакте → Изменение статуса подписки  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Изменение статуса подписки (subscription_status_change)

ВКонтакте отправляет это уведомление серверу приложения (игры или мини-приложения), когда пользователь подтвердил операцию покупки, отмены или возобновления подписки в этом приложении.

Подробная информация о покупке подписок и об обмене данными между ВКонтакте и серверами игр и мини-приложений — в разделе [Продажа подписок](https://dev.vk.ru/ru/api/payments/subscriptions/vk).

## Уведомление

### Пример

```
app_id=12345678&item_id=sale_item_subscription_1&item_price=24&next_bill_time=
1656971381&notification_type=subscription_status_change_test&status=chargeable
&subscription_id=subscr_internal_id_123&user_id=1&version=5.132&sig=59829d05b4
20870e94207024ef0b5e61
```

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `app_id` | `integer` | Идентификатор приложения, в котором происходит покупка. |

Значение должно совпадать с идентификатором, который отображается в [настройках приложения](https://dev.vk.ru/ru/mini-apps/management/settings#%D0%9D%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8).

`cancel_reason` `string` Используется в случаях, когда параметр `status` равен

`active` или `cancelled`. Указывает причину отмены подписки. Возможные значения:
- `user_decision` — подписка отменена по инициативе пользователя.
- `app_decision` — подписка отменена по инициативе приложения (вызов API-запроса

[`orders.cancelSubscription`](https://dev.vk.ru/ru/orders.cancelSubscription)).
- `payment_fail` — подписка отменена из-за ошибки платежа.
- `unknown` — отмена по другой причине, либо подписка была возобновлена.

`item_id` `string` Идентификатор подписки, используемый в вашем мини- приложении или игре. Это то же значение, которое использовалось для окна покупки и которое ваш сервер передал в поле `item_id` ответа на уведомление

[`get_subscription`](https://dev.vk.ru/ru/api/payments/notifications/get-subscription) [.](https://dev.vk.ru/ru/api/payments/notifications/get-subscription)

**Параметр | Тип | Описание**

`item_price` `integer` Стоимость подписки за период. Это то же значение, которое ваш сервер передал в поле `price` ответа на уведомление

[`get_subscription`](https://dev.vk.ru/ru/api/payments/notifications/get-subscription) [.](https://dev.vk.ru/ru/api/payments/notifications/get-subscription)

`notification_type` `string` Тип уведомления. В рабочем режиме прохождения платежей параметр равен `subscription_status_change`, в [тестовом](https://dev.vk.ru/ru/api/payments/testing)
— `subscription_status_change_test`.

`status` `string` Статус подписки. Возможные значения:
- `chargeable` — подписка готова к оплате. Необходимо оформить заказ пользователю внутри приложения. После получения ответа об успехе платёжная система зачислит голоса на счёт приложения. Если в ответе будет передано сообщение об ошибке, заказ будет отменён.
- `active` — подписка оформлена и активна. Это уведомление приходит спустя некоторое время после

`chargeable` как подтверждение того, что подписка была оформлена успешно на стороне ВКонтакте. В этом случае параметр `cancel_reason` равен `unknown`. Также `active` приходит при отмене подписки. В этом случае

`cancel_reason` сообщает причину отмены. Отменённую подписку можно восстановить до окончания оплаченного периода.
- `cancelled` — подписка отменена. Восстановить такую подписку нельзя.

`next_bill_time` `integer` Дата следующего платежа. Указана в Unix-формате. То есть это число — количество секунд, прошедших с 00:00:00 1 января 1970 года.

`pending_cancel` `integer` Используется в случае, когда параметр `status=active`). Если `1`, то подписка действует до конца периода.

`subscription_id` `integer` Идентификатор экземпляра подписки.

Важно! Это значение сгенерировано ВКонтакте автоматически. Оно используется для дальнейшей работы с подпиской, например для отмены и восстановления. Мы рекомендуем сохранить это значение на стороне сервера вашего приложения, чтобы в дальнейшем давать правильные ответы на запросы платформы.

`user_id` `integer` Идентификатор пользователя, создавшего заказ.

`version` `string` Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе Платежи в поле [Версия API](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%A8%D0%B0%D0%B3%202.%20%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20%D0%B0%D0%B4%D1%80%D0%B5%D1%81%20%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D0%BE%D0%B3%D0%BE%20%D0%B2%D1%8B%D0%B7%D0%BE%D0%B2%D0%B0%20%D0%B2%20%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0%D1%85%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F).

Параметр используется только для версии `5.132` и более поздних.

**Параметр | Тип | Описание**

`sig` `string` Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D0%BE%D0%B2) [и её проверке](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D0%BE%D0%B2).

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A0%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%20%D1%81%D0%BE%20%D1%81%D1%82%D1%80%D0%BE%D0%BA%D0%BE%D0%B2%D1%8B%D0%BC%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%BC%D0%B8) перед обработкой.

## Ответ сервера

Обработчик уведомления должен выполнить следующие задачи:

- В случае, когда параметр `status` равен `chargeable`, сервер должен предоставить пользователю подписку и отправить ответ о подтверждении покупки. Перевод голосов со счёта пользователя на счёт игры или мини-приложения произойдёт только после того, как ВКонтакте получит положительный ответ на это уведомление.
- В случае, когда параметр `status` равен `cancelled`, сервер должен отменить преимущества, предлагаемые подпиской, и отправить ответ об успешном прохождении операции.
- Случай, когда параметр `status` равен `active`, а `cancel_reason` равен `user_decision` означает, что подписка была отменена по инициативе пользователя. В этом случае ваше приложение может выполнить какие-либо действия, чтобы показать преимущества подписки пользователю и подтолкнуть его к возврату.

Чтобы избежать повторных оформлений подписок, реализуйте на сервере проверку по уникальному `order_id` и статусу заказа:

- Оформляйте подписку по каждому `order_id` только один раз.
- Если получаете повторные уведомления, в которых статус заказа прежний, а по `order_id` уже оформлена подписка, возвращайте тот же успешный ответ, что и при первом начислении.

### Пример ответа

При успешном выполнении операции в ответе надо вернуть объект следующей структуры:

```json
{
  "response": {
    "subscription_id": 12345,
    "app_order_id": 6492
  }
}
```

### Поля

| Поле | Тип | Описание |
|---|---|---|
| `subscription_id` обязательное | `integer` | Идентификатор экземпляра подписки, сгенерированный ВКонтакте. |

`app_order_id` `integer` Идентификатор заказа в приложении. Должен быть уникальным для каждого заказа. Используется для отмены.

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:

```json
{
  "error": {
    "error_code": 1,
    "error_msg": "При обработке произошла ошибка на сервере. Попробуйте ещё
раз позже.",
    "critical": true
    }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A4%D0%BE%D1%80%D0%BC%D0%B0%D1%82%20%D0%BE%D1%82%D0%B2%D0%B5%D1%82%D0%B0%20%D0%BF%D1%80%D0%B8%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B5).
