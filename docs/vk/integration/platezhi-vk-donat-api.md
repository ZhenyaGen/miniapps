# VK Донат API

**Раздел:** Интеграция → Платежи → VK Донат API  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

API ВКонтакте позволяет получать информацию о платных подписках и подписчиках в сообществах, использующих [VK Донат](https://vk.com/@donut-faq), а также публиковать в них платный контент.

## Для кого этот раздел

Этот раздел для разработчиков приложений, которые хотят использовать API ВКонтакте. Вам будет проще, если вы уже знакомы с [API ВКонтакте](https://dev.vk.ru/ru/api/getting-started), методами [авторизации](https://dev.vk.ru/ru/api/access-token/getting-started) и знаете, что такое [VK Донат](https://vk.com/@donut-faq).

Если вы уже используете [VK Донат](https://vk.com/@donut-faq) и разобрались, как получить [ключ доступа](https://dev.vk.ru/ru/api/access-token/getting-started) к API ВКонтакте, переходите к разделу Методы. Если нет, сначала прочитайте раздел Подготовка.

## Подготовка

1. Подключите [VK Донат](https://vk.com/@donut-faq) в настройках сообщества.

2. [Создайте приложение](https://dev.vk.ru/ru/api/getting-started). API можно использовать в приложении любого типа. Чтобы получить ключ доступа к API на следующем шаге, вам понадобится идентификатор приложения.

3. Получите [ключ доступа](https://dev.vk.ru/ru/api/access-token/getting-started). Ключ доступа нужно будет указывать во всех запросах из приложения. Получить его можно разными способами. Всё зависит от того, какие [права доступа](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) вам нужны и как вы будете отправлять запросы (от имени пользователя или сообщества, со стороны клиента или сервера).

Совет. Если у вас есть мини-приложение, отправлять запросы можно из [песочницы](https://dev.vk.ru/ru/method/donut.isDon) внизу страницы. Идентификатор приложения и ключ доступа указывать не понадобится, достаточно войти в свой аккаунт ВКонтакте.

## Методы

В описании каждого метода в [справочнике методов](https://dev.vk.ru/ru/method) указано, к какой версии API относится метод, какие ещё параметры есть у метода и какие нужны [права доступа](https://dev.vk.ru/ru/reference/access-rights).

В [запросе](https://dev.vk.ru/ru/api/api-requests) нужно указать:

- Метод. В таблице ниже собраны методы, которые понадобятся для работы с сообществами, использующими VK Донат. Название метода может начинаться с префиксов: [`donut`](https://dev.vk.ru/ru/method/donut.isDon) [,](https://dev.vk.ru/ru/method/donut.isDon) [`groups`](https://dev.vk.ru/ru/method/groups.getMembers) [,](https://dev.vk.ru/ru/method/groups.getMembers)

[`wall`](https://dev.vk.ru/ru/method/wall.post) [.](https://dev.vk.ru/ru/method/wall.post)
- Ключ доступа. Передайте ключ в HTTP-заголовке Authorization:

`Authorization: Bearer <КЛЮЧ_ДОСТУПА>`
- Параметры. В [справочнике методов](https://dev.vk.ru/ru/method) написано, к какой версии API относится каждый метод, какие ещё параметры есть у метода и какие нужны [права доступа](https://dev.vk.ru/ru/api/privacy#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0). В запросе нужно указать тот ключ доступа, права доступа которого соответствуют методу.

### Пример

Чтобы узнать, является ли пользователь доном (так мы называем получателей платного контента в сообществе), отправьте запрос:

```bash
curl -X GET 'https://api.vk.ru/method/donut.isDon' \
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'owner_id=-1' \
  -F 'v=5.199'
```

В этом примере замените `-1` на идентификатор сообщества (со знаком минуса), а `42` — на ключ доступа пользователя.

Совет. Войдите в свой аккаунт ВКонтакте и отправьте запрос прямо из [документации](https://dev.vk.ru/ru/method/donut.isDon).

### Методы, которые относятся к работе VK Донат

| Метод | Результат |
|---|---|
| [`donut.isDon`](https://dev.vk.ru/ru/method/donut.isDon) | Подписан ли пользователь на платный контент (является ли доном). |
| [`donut.getSubscription`](https://dev.vk.ru/ru/method/donut.getSubscription) | Стоимость подписки, статус, дата следующего платежа. |
| [`donut.getSubscriptions`](https://dev.vk.ru/ru/method/donut.getSubscriptions) | Подписки пользователя. |
| [`donut.getFriends`](https://dev.vk.ru/ru/method/donut.getFriends) | Список донов из числа друзей пользователя. |
| [`groups.getMembers`](https://dev.vk.ru/ru/method/groups.getMembers) | Список донов сообщества по ключу пользователя (ключ должен принадлежать как минимум редактору сообщества) и по ключу сообщества (см. параметр `filter`). |
| [`wall.post`](https://dev.vk.ru/ru/method/wall.post) | Публикует на стене запись только для донов. Позволяет задать время, через которое запись появится для всех подписчиков, то есть станет бесплатной (см. параметр `donut_paid_duration`). |
| [`wall.edit`](https://dev.vk.ru/ru/method/wall.edit) | Меняет значение параметра `donut_paid_duration`. |

- [Callback API](https://dev.vk.ru/ru/api/callback/getting-started). Мы будем отправлять на ваш сервер уведомление о каждом новом событии.

## FAQ

#### Зачем нужен VK Донат?

VK Донат позволяет руководителям сообществ принимать платежи от подписчиков.

#### Где ещё можно прочитать про VK Донат?

В [сообществе](https://vk.com/donut) есть [правила публикаций](https://vk.com/@donut-pravila) и подробный FAQ, в котором мы рассказали, например, про [платежи](https://vk.com/@donut-faq?anchor=chto-vybrat-kartu-ili-vk-pay).

#### Кто такие доны?

Доны — это получатели платного контента, которые подписываются на него с помощью VK Донат.

#### Как выглядит идентификатор сообщества?

Идентификатор сообщества — это целое число (порядковый номер). Например, на странице нашего официального сообщества указан `ID:` [192668858](https://vk.com/donut). Но при работе с API используется отрицательное число -192668858, чтобы отличить идентификатор сообщества от идентификатора пользователя.

Почему в примере идентификатор сообщества: `-1`?

Пользователи и сообщества нумеруются по порядку, поэтому у пользователя и сообщества может быть одинаковый идентификатор. Например, есть [пользователь](https://vk.com/id1) и [сообщество](https://vk.com/apiclub) с `ID:` 1. Если метод требует передать идентификатор пользователя, нужно указывать `owner_id=1` (положительное число), если идентификатор сообщества, то `owner_id=-1` (отрицательное число).

В запросах можно передавать `lang`?

Да. [Параметры, общие для всего API](https://dev.vk.ru/ru/api/api-requests#%D0%9E%D0%B1%D1%89%D0%B8%D0%B5%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B), можно использовать во всех методах API ВКонтакте.

#### Можно ли сделать платным бесплатный контент?

Нет, если запись уже опубликована. Можно, если вы создали [отложенную запись](https://dev.vk.ru/ru/api/posts#%D0%9F%D1%83%D0%B1%D0%BB%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D0%B8%20%D0%B8%D0%B7%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B9) и она ещё не опубликована.

#### Можно ли сделать бесплатным платный контент?

Да. Используйте метод [`wall.post`](https://dev.vk.ru/ru/method/wall.post), в запросе укажите идентификатор записи ( `post_id`). Обратите внимание, что в этом случае создастся бесплатная копия платной записи. Но только одна

— создать больше копий не получится.

Я создал запись для донов, но потом решил сделать её бесплатной пораньше. Можно ли изменить время, указанное в donut_paid_duration?

Да. Чтобы изменить значение `donut_paid_duration` (время, через которое платная запись должна стать бесплатной), нужно задать новое значение этого параметра с помощью метода

[`wall.edit`](https://dev.vk.ru/ru/method/wall.edit). Обратите внимание, что когда время истечёт, появится копия платной записи.
