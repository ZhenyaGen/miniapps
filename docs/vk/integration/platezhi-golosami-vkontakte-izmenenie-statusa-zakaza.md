# Изменение статуса заказа

**Раздел:** Интеграция → Платежи голосами ВКонтакте → Изменение статуса заказа  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Изменение статуса заказа (order_status_change)

ВКонтакте отправляет уведомление `order_status_change` серверу приложения (игры или мини- приложения) в следующих случаях:

- После того как пользователь подтвердил оплату в [окне покупки](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%9E%D0%B1%D0%BC%D0%B5%D0%BD%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%BC%D0%B8%20%D0%BC%D0%B5%D0%B6%D0%B4%D1%83%20%D0%92%D0%9A%D0%BE%D0%BD%D1%82%D0%B0%D0%BA%D1%82%D0%B5%20%D0%B8%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%D0%BC) в этом приложении.
- При возврате заказа. Уведомление о возврате доступно при использовании версии `5.132` платёжного API или более поздних версий.

## Уведомление

Данные приходят в теле запроса в виде строки, содержащей пары `параметр=значение`. Пары разделены символами `&`.

### Пример

```
app_id=12345678&date=1656358147&item=sale_item_1&item_discount=3&item_id=sale_
item_1_internal_id&item_photo_url=http%3A%2F%2Fmy-app.example.com%2Fsale-item-
images%2Fsale-item-1.png&item_price=24&item_title=%D0%A7%D1%83%D0%B4%D0%BE-
%D0%B7%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5&notification_type=order_status_change_tes
t&order_id=2044861&receiver_id=1&status=chargeable&user_id=1&version=5.132&sig
=ab87f7355c523ed8c52482b69723eef4
```

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `app_id` | `integer` | Идентификатор приложения, в котором происходит покупка. |

Значение должно совпадать с идентификатором, который отображается в [настройках приложения](https://dev.vk.ru/ru/mini-apps/management/settings#%D0%9D%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8).

`date` `integer` Дата создания заказа в Unix-формате, то есть как целое число
— количество секунд, прошедших с 00:00:00 1 января 1970 года.

`item` `string` Идентификатор товара, который используется в вашем приложении и который оно передало событию

[`VKWebAppShowOrderBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowOrderBox) библиотеки VK Bridge. [Пример](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%A8%D0%B0%D0%B3%203.%20%D0%92%D1%8B%D0%B7%D0%BE%D0%B2%D0%B8%D1%82%D0%B5%20%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D0%B5%20VK%20Bridge%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D0%B0%20%D0%BE%D0%BA%D0%BD%D0%B0%20%D0%BF%D0%BE%D0%BA%D1%83%D0%BF%D0%BA%D0%B8) [вызова события](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%A8%D0%B0%D0%B3%203.%20%D0%92%D1%8B%D0%B7%D0%BE%D0%B2%D0%B8%D1%82%D0%B5%20%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D0%B5%20VK%20Bridge%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D0%B0%20%D0%BE%D0%BA%D0%BD%D0%B0%20%D0%BF%D0%BE%D0%BA%D1%83%D0%BF%D0%BA%D0%B8).

`item_discount` `integer` Размер скидки на товар в [голосах ВКонтакте](https://dev.vk.ru/ru/mini-apps/glossary#%D0%93%D0%BE%D0%BB%D0%BE%D1%81), если скидка применяется. Это то же значение, которое ваш сервер передал в поле `discount` ответа на уведомление [`get_item`](https://dev.vk.ru/ru/api/payments/notifications/get-item) [.](https://dev.vk.ru/ru/api/payments/notifications/get-item)

**Параметр | Тип | Описание**

`item_id` `string` Идентификатор проданного товара, который сгенерировал ВКонтакте.

Это значение используется для последующих операций с заказом. Сохраните этот идентификатор на стороне своего сервера, чтобы правильно обрабатывать запросы ВКонтакте.

`item_photo_url` `string` Полный URL изображения товара (включая адрес сервера и протокол). Это то же значение, которое ваш сервер передал в поле `photo_url` ответа на уведомление [`get_item`](https://dev.vk.ru/ru/api/payments/notifications/get-item) [.](https://dev.vk.ru/ru/api/payments/notifications/get-item)

`item_price` `integer` Стоимость товара в [голосах ВКонтакте](https://dev.vk.ru/ru/mini-apps/glossary#%D0%93%D0%BE%D0%BB%D0%BE%D1%81). Это то же значение, которое ваш сервер передал в поле `price` ответа на уведомление [`get_item`](https://dev.vk.ru/ru/api/payments/notifications/get-item) [.](https://dev.vk.ru/ru/api/payments/notifications/get-item)

`item_title` `string` Название товара. Это то же значение, которое ваш сервер передал в поле `title` ответа на уведомление [`get_item`](https://dev.vk.ru/ru/api/payments/notifications/get-item) [.](https://dev.vk.ru/ru/api/payments/notifications/get-item)

`notification_type` `string` Тип уведомления. В рабочем режиме прохождения платежей параметр равен `order_status_change`, в [тестовом](https://dev.vk.ru/ru/api/payments/testing) —

`order_status_change_test`.

`order_id` `integer` Идентификатор заказа в системе платежей ВКонтакте.

`receiver_id` `integer` Идентификатор пользователя, который получит заказ. В данный момент совпадает с `user_id`, но в будущем может отличаться.

`status` `string` Статус заказа. Возможны следующие значения:
- `chargeable` — Пользователь подтвердил оплату в окне продажи. Необходимо оформить заказ внутри приложения. В случае ответа об успехе платёжная система перечислит голоса на счёт приложения. Если в ответе будет сообщение об ошибке, заказ отменится автоматически.
- `refunded` — Заказ отменён. Необходимо забрать игровые ценности, выданные пользователю за платежи. Это значение доступно в уведомлениях, [использующих формат](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%A8%D0%B0%D0%B3%202.%20%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20%D0%B0%D0%B4%D1%80%D0%B5%D1%81%20%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D0%BE%D0%B3%D0%BE%20%D0%B2%D1%8B%D0%B7%D0%BE%D0%B2%D0%B0%20%D0%B2%20%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0%D1%85%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F) версии

`5.132` или более поздний.

`user_id` `integer` Идентификатор пользователя, создавшего заказ.

`version` `string` Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе Платежи в поле [Версия API](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%A8%D0%B0%D0%B3%202.%20%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20%D0%B0%D0%B4%D1%80%D0%B5%D1%81%20%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D0%BE%D0%B3%D0%BE%20%D0%B2%D1%8B%D0%B7%D0%BE%D0%B2%D0%B0%20%D0%B2%20%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0%D1%85%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F).

Параметр используется только для версии `5.132` и более поздних.

`sig` `string` Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D0%BE%D0%B2)

**Параметр | Тип | Описание**

и её проверке.

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A0%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%20%D1%81%D0%BE%20%D1%81%D1%82%D1%80%D0%BE%D0%BA%D0%BE%D0%B2%D1%8B%D0%BC%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%BC%D0%B8) перед обработкой.

## Ответ сервера

Обработчик уведомления должен выполнить следующие задачи:

- В случае, когда параметр `status` равен `chargeable`, сервер должен предоставить пользователю купленный товар и отправить ответ о проведении платежа. ВКонтакте переведёт голоса со счёта пользователя на счёт вашего приложения после того, как получит положительный ответ на это уведомление.
- В случае, когда параметр `status` равен `refunded`, сервер должен отменить покупку и отправить ответ об успешном прохождении этой операции. После этого ВКонтакте переведёт голоса со счёта вашего приложения на счёт пользователя. На счёте приложения должна быть достаточное количество голосов для перевода.

Чтобы избежать повторных начислений товаров, реализуйте на сервере проверку по уникальному `order_id` и статусу заказа:

- Начисляйте товар по каждому `order_id` только один раз.
- Если получаете повторные уведомления, в которых статус заказа прежний, а по `order_id` уже начислен товар, возвращайте тот же успешный ответ, что и при первом начислении.

### Пример ответа

При успешном выполнении операции в ответе надо вернуть объект следующей структуры:

```json
{
  "response": {
    "order_id": 207184,
    "app_order_id": 6492
  }
}
```

### Поля

| Поле | Тип | Описание |
|---|---|---|
| `order_id` обязательное | `integer` | Идентификатор заказа в системе платежей ВКонтакте. |

`app_order_id` `integer` Идентификатор заказа в приложении. Это значение должно быть уникальным для каждого заказа. Оно используется для отмены заказа.

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:

```json
{
  "error": {
        "error_code": 21,
        "error_msg": "Нет в наличии",
        "critical": true
    }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A4%D0%BE%D1%80%D0%BC%D0%B0%D1%82%20%D0%BE%D1%82%D0%B2%D0%B5%D1%82%D0%B0%20%D0%BF%D1%80%D0%B8%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B5).
