# Тестирование платежей

**Раздел:** Интеграция → Платежи виртуальной валютой → Тестирование платежей  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Тестовый режим доступен до модерации игры или мини-приложения и позволяет проверить [получение виртуальных ценностей и подписок](https://dev.vk.ru/ru/api/payments/virtual-goods/vk) за голоса и ОКи. При этом виртуальная валюта не будет списываться со счёта пользователя и начисляться на счёт игры или мини‑приложения.

## Назначение тестировщиков платежей

Чтобы тестировщики платежей могли выполнять операции с виртуальной валютой и проверять их обработку, добавьте их аккаунты в панели управления.

Для тестирования операций с голосами ВКонтакте тестировщику платежей не нужны дополнительные разрешения.

Тестировать операции с ОКами в Одноклассниках могут администраторы с правами:

- Создатель.
- Администратор с полным доступом.
- Администратор с частичным доступом, с правом «Тестирование».

Администраторам и тестировщикам платежей в Одноклассниках нужно связать профили VK ID и OK ID и получить права разработчика в Одноклассниках. Подробнее — в разделе [Администрирование приложений](https://dev.vk.ru/ru/ok/administrators).

### Шаг 1. Добавьте пользователей в список администраторов

Управлять списком администраторов может:

- Создатель.
- Администратор с полным доступом.

Чтобы добавить пользователей в список администраторов:

1. Перейдите в [список приложений](https://dev.vk.ru/admin/apps-list).

2. Откройте настройки нужной игры или мини-приложения.

3. В меню слева откройте раздел Администраторы и добавьте нужных пользователей. Пользователь получит права администратора после того, как подтвердит действие в панели управления.

Подробнее о том, как назначить администраторов и настроить их права в панели управления:

- [Администраторы (настройки игр)](https://dev.vk.ru/ru/games/settings/managers)
- [Администраторы (настройки мини-приложений)](https://dev.vk.ru/ru/mini-apps/settings/managers)

### Шаг 2. Добавьте администраторов в список тестировщиков платежей

Управлять списком тестировщиков платежей может:

- Создатель.
- Администратор с полным доступом.

- Администратор с частичным доступом, с правом «Платежи».

Чтобы добавить администраторов в список тестировщиков платежей:

1. Перейдите в [список приложений](https://dev.vk.ru/admin/apps-list).

2. Откройте настройки нужной игры или мини-приложения.

3. В меню слева выберите Платежи → Подключение.

4. В поле Тестировщики платежей выберите нужных пользователей из списка администраторов.

5. Нажмите Сохранить. Роли администраторов в Одноклассниках обновляются в течение 5 минут.

Подробнее о настройке платежей в панели управления:

- [Подключение платежей в играх](https://dev.vk.ru/ru/games/settings/payments/setting-up)
- [Подключение платежей в мини-приложениях](https://dev.vk.ru/ru/mini-apps/settings/payments/setting-up)

## Переход платежей из тестового в рабочий режим

В панели управления нет переключателя тестового режима: если пользователь добавлен в список тестировщиков платежей, все его операции с виртуальной валютой происходят в тестовом режиме.

Платежи переходят в рабочий режим автоматически после того, как:

- Мини-приложение пройдёт [модерацию](https://dev.vk.ru/ru/mini-apps/settings/moderation).
- Игра пройдёт [модерацию](https://dev.vk.ru/ru/games/settings/moderation) и [попадёт в каталог](https://dev.vk.ru/ru/games/catalog/moderation).

После публикации приложения платежи в нём становятся доступны всем пользователям, но для тестировщиков платежей из списка в панели управления они продолжают работать в тестовом режиме.

## Обработка уведомлений

В тестовом режиме к названию [уведомлений](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A2%D0%B8%D0%BF%D1%8B%20%D1%83%D0%B2%D0%B5%D0%B4%D0%BE%D0%BC%D0%BB%D0%B5%D0%BD%D0%B8%D0%B9) добавляется постфикс `_test`. Например, вместо

`get_item` сервер вашего приложения будет получать уведомление `get_item_test`. Учитывайте это при разработке серверной части вашего приложения.

Ответы на тестовые уведомления должны быть такими же, как ответы на обычные уведомления.

Обратите внимание:

- При тестировании голоса не списываются со счёта тестировщика.
- В тестовом режиме баланс пользователя не проверяется. Платёж пройдёт, даже если стоимость покупки больше количества голосов на счёте тестировщика.
- Идентификаторы заказов в тестовом режиме — параметры `order_id` у уведомлений — могут совпадать с идентификаторами заказов в рабочем режиме.
- Для тестирования подписок работает специальный режим — после создания каждая подписка продлевается автоматически 5 раз со следующими интервалами:

- Каждые 10 минут для подписок с `period = month`.
- Каждые 2 минуты для других значений параметра `period`. После этого подписка автоматически отменяется.
- Уведомления приходят только при изменении статуса подписки, в случае продления уведомления не приходят.
