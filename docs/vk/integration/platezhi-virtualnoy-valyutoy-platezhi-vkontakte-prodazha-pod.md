# Продажа подписок

**Раздел:** Интеграция → Платежи виртуальной валютой → Платежи ВКонтакте → Продажа подписок  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Продажа подписок работает аналогично [продаже товаров](https://dev.vk.ru/ru/api/payments/virtual-goods/vk), но имеет особенности, которые связаны с тем, что подписка предполагает периодические списания [голосов](https://dev.vk.ru/ru/mini-apps/glossary#%D0%93%D0%BE%D0%BB%D0%BE%D1%81) со счёта пользователя на счёт приложения (игры или мини-приложения).

ВКонтакте берёт на себя отслеживание периода и периодические списания. Голоса со счёта пользователя списываются в начале каждого периода.

При невозможности продлить подписку ВКонтакте автоматически отменит её. Пользователь может прекратить подписку и по своей инициативе. Прекращённую подписку можно восстановить. Подробнее — в разделе Отмена и восстановление подписки.

При изменении статуса подписки ВКонтакте отправляет уведомления серверу вашего мини- приложения или игры.

## Как реализовать продажу подписки

#### Шаг 1. Подготовьте серверную часть приложения

1. На сервере приложения определите URL, который будет использоваться для приёма уведомлений, поступающих от ВКонтакте. Используйте [тот же URL](https://dev.vk.ru/ru/api/payments/virtual-goods/vk#%D0%A8%D0%B0%D0%B3%201.%20%D0%9F%D0%BE%D0%B4%D0%B3%D0%BE%D1%82%D0%BE%D0%B2%D1%8C%D1%82%D0%B5%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%BD%D1%83%D1%8E%20%D1%87%D0%B0%D1%81%D1%82%D1%8C%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F), который вы используете для приёма уведомлений о продаже товаров.

2. На стороне сервера реализуйте обработку следующих уведомлений:

| Уведомление | Описание |
|---|---|
| [`get_subscription`](https://dev.vk.ru/ru/api/payments/notifications/get-subscription) | ВКонтакте отсылает это уведомление, чтобы получить информацию о подписке для отображения в окне покупки: название подписки, её стоимость, иконку, период действия, длительность пробного периода. |
| [`subscription_status_change`](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change) | Это уведомление используется при покупке, отмене и возобновлении подписки. |
| 3. Реализуйте на сервере проверку оформления подписки по уникальному `order_id` и статусу | заказа: |

- Оформляйте подписку по каждому `order_id` только один раз.
- Если получаете повторные уведомления, в которых статус заказа прежний, а по `order_id` уже оформлена подписка, возвращайте тот же успешный ответ, что и при первом оформлении. Это поможет избежать повторных оформлений подписок.

#### Шаг 2. Укажите адрес обратного вызова в настройках приложения

В настройках вашего приложения ВКонтакте надо указать выбранный вами URL, используемую версию уведомлений, а также пользователей, которые смогут проводить платежи за уведомления в тестовом режиме:

Добавление администраторов в этот список обязательно для тестирования. Без этого тестирование платежей недоступно даже администраторам с полным доступом. Подробнее о настройках для тестирования — в разделе [Тестирование платежей](https://dev.vk.ru/ru/api/payments/testing).

#### Шаг 3. Вызовите событие VK Bridge для показа окна покупки

Для вызова окна продажи подписки на стороне пользователя используйте событие

[`VKWebAppShowSubscriptionBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowSubscriptionBox) библиотеки VK Bridge, например:

```js
bridge.send('VKWebAppShowSubscriptionBox', {
  action: 'create',
  item: 'sale_item_subscription_1', // Идентификатор подписки в приложении
  })
  .then( (data) => {
    console.log('Покупка прошла успешно', data);
  })
  .catch( (e) => {
    console.log('Ошибка!', e);
  })
```

## Обмен данными

После вызова события `VKWebAppShowSubscriptionBox` происходит следующее:

1. Библиотека VK Bridge отправляет запрос платформе ВКонтакте, которая, в свою очередь, отправляет серверу вашего приложения уведомление [`get_subscription`](https://dev.vk.ru/ru/api/payments/notifications/get-subscription) [.](https://dev.vk.ru/ru/api/payments/notifications/get-subscription)

В ответе на уведомление сервер передаёт информацию о подписке, которая затем отображается в окне покупки.

2. После того как пользователь подтверждает оплату в окне покупки, платформа отправляет серверу приложения уведомление [`subscription_status_change`](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change) [.](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change)

При обработке этого уведомления сервер должен предоставить пользователю преимущества подписки и отправить ответ об успешном выполнении операции. После получения ответа ВКонтакте считает подписку оформленной.

## Важные замечания, касающиеся работы с подписками

- ВКонтакте отправляет уведомления только при продаже, отмене или возобновлении подписки.

Уведомления не приходят про регулярном продлении подписки. В этом случае ВКонтакте просто списывает деньги со счёта пользователя на счёт вашего приложения.
- Для сообщения об изменении статуса подписки ВКонтакте отсылает уведомление вида

[`subscription_status_change`](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change). Это уведомление используется и для покупки, и для отмены, и для возобновления подписки. Для определения конкретного действия нужно анализировать параметр `status` этого уведомления:

Параметр  status Описание

`chargeable` Пользователь оплатил подписку. При обработке уведомления ваше приложение должно предоставить пользователю преимущества подписки.

`active` Подписка активна. Это уведомление приходит спустя некоторое время после `chargeable` как подтверждение того, что серверы ВКонтакте получили ответ на `chargeable` -уведомление.

Кроме того, это уведомление приходит при отмене подписки. В этом случае параметр `cancel_reason` уведомления указывает причину отмены.

Отменённая подписка продолжает действовать до конца оплаченного периода. В это время её можно возобновить.

`cancelled` Подписка отменена. После получения этого сообщения возобновить подписку нельзя. Можно продать новую.

- Для отслеживания конкретного экземпляра подписки ВКонтакте автоматически генерирует его идентификатор. Сервер вашего приложения получает его при продаже подписки в уведомлении

`subscription_status_change` в параметре `subscription_id`.

Этот идентификатор впоследствии используется для отмены и возобновления подписки. Сохраните его на стороне сервера приложения, чтобы тот мог предоставить информацию об экземпляре подписки, когда ВКонтакте будет её запрашивать.
- В случае получения повторного уведомления `subscription_status_change` с тем же параметром `subscription_id`, ответ вашего сервера должен повторять ответ для уведомления, полученного ранее.

Например, если ваш сервер отправил положительный ответ на уведомление, но этот ответ не дошёл до серверов ВКонтакте, или если ВКонтакте не удалось перевести голоса пользователя на счёт приложения сразу после получения ответа, то ВКонтакте отправит уведомление

`subscription_status_change` повторно.

При этом ваш сервер приложения не должен выполнять новый заказ. Достаточно будет прислать тот же ответ, что был отправлен в предыдущий раз. Для этого надо сохранить на стороне сервера параметр `subscription_id` и проверить по нему, что такое уведомление уже приходило.

## Как проверить статус подписки

Информация о заказах, платежах и подписках сохраняется на серверах ВКонтакте. Для работы со списком купленных товаров и подписок вы можете использовать API-операции группы [Orders](https://dev.vk.ru/ru/method/orders).

Для получения информации о подписке отправьте API-запрос

[`orders.getUserSubscriptionById`](https://dev.vk.ru/ru/method/orders.getUserSubscriptionById) [.](https://dev.vk.ru/ru/method/orders.getUserSubscriptionById)

## Отмена и восстановление подписки

Отмена подписки возможна в следующих случаях:

- Если при очередном списании на счёте пользователя недостаточно голосов.

ВКонтакте сначала попытается пополнить счёт с банковской карты, электронного кошелька или счёта VK Pay, привязанного к аккаунту пользователя ВКонтакте. Привязанное платёжное средство можно увидеть в настройках аккаунта, в разделе [Платёжные сервисы](https://vk.com/settings?act=payments&section=subscriptions).

Если пополнить количество голосов не удаётся, ВКонтакте отменит подписку.

Если пользователь пополнит свой счёт в течение 5 дней, ВКонтакте восстановит подписку автоматически. Сервер приложения в таком случае должен возобновить именно существующую подписку по сохранённому `subscription_id`, новую подписку создавать не нужно.
- Если пользователь отменил подписку по собственной инициативе.

Пользователь может это сделать в настройках своего аккаунта ВКонтакте в разделе [Платёжные](https://vk.com/settings?act=payments&section=subscriptions) [сервисы](https://vk.com/settings?act=payments&section=subscriptions) либо из вашего приложения, если оно предоставляет такую возможность.

При такой отмене не происходит возврата средств за оплаченные периоды. Отмена означает, что списания не будут осуществляться в дальнейшем.

Отменённая подписка продолжает оставаться активной до окончания оплаченного периода. В это время её можно возобновить. Сделать это можно в настройках аккаунта ВКонтакте в разделе [Платёжные сервисы](https://vk.com/settings?act=payments&section=subscriptions) либо из приложения, если оно предоставляет такую возможность.

### Как отменить подписку из приложения

Для отмены подписки используйте событие [`VKWebAppShowSubscriptionBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowSubscriptionBox) VK Bridge. В параметре `subscription_id` укажите идентификатор подписки, который был сгенерирован ВКонтакте и который вы получили при продаже.

```js
bridge.send('VKWebAppShowSubscriptionBox',
  {
    action: 'cancel',
    subscription_id: 25, // Идентификатор подписки, полученный от ВКонтакте
  })
  .then( (data) => {
    console.log('Отмена прошла успешно', data);
  })
  .catch( (e) => {
    console.log('Ошибка!', e);
  })
```

На стороне сервера для отмены используйте обработчик уведомления

[`subscription_status_change`](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change) [.](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change)

#### Как возобновить подписку из приложения

Отменённую подписку можно возобновить. Для этого вызовите [`VKWebAppShowSubscriptionBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowSubscriptionBox) и используйте следующие параметры:

```js
bridge.send('VKWebAppShowSubscriptionBox',
  {
    action: 'resume',
    subscription_id: '25', // Идентификатор подписки, полученный от ВКонтакте
  })
  .then( (data) => {
    console.log('Подписка восстановлена.', data);
  })
  .catch( (e) => {
    console.log('Ошибка!', e);
  });
```

На стороне сервера для возобновления используйте обработчик уведомления

[`subscription_status_change`](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change) [.](https://dev.vk.ru/ru/api/payments/notifications/subscription-status-change)
