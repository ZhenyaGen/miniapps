# Приложение

**Раздел:** Интеграция → Виджеты → Приложение  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

Виджет приложения позволит в один клик добавить на ваш сайт возможность быстро перейти в игру из каталога ВКонтакте.

Используйте полноценную карточку приложения или компактную кнопку, показывайте пользователям играющих друзей — виджет аккуратно впишется в любой дизайн и привлечёт новых игроков.

Обратите внимание, URL приложения сообщества должен быть указан в формате

`https://vk.ru/app123456_-654321`. Для таких приложений доступен только вид «Кнопка».

## Подключение виджета

Чтобы добавить на свой сайт виджет приложения, выполните эти три шага:

В тег `<head>` на странице вашего сайта добавьте подключение `openapi.js`:

```html
<script src="https://vk.ru/js/api/openapi.js?169" type="text/javascript">
</script>
```

В тело страницы добавьте элемент `<div>`, в котором будут отображаться комментарии, задайте ему уникальный id, и добавьте в него код инициализации виджета. Например:

```html
<div id="vk_app_5327745"></div>
<script type="text/javascript">
    VK.Widgets.App('vk_app_5327745', 5327745);
</script>
```

Если на вашем сайте уже используется [Open API](https://dev.vk.ru/ru/api/open-api/getting-started), добавить виджет ещё проще. Достаточно просто добавить инициализацию виджета.

## Дополнительные настройки

Метод для создания виджета `VK.Widgets.App` принимает три параметра:

- `element_id` ( `string`), обязательный параметр — `id` элемента, который будет являться контейнером виджета. В нашем конструкторе по умолчанию используется значение `"vk_app_" +` `{app_id}`.
- `app_id` ( `integer`), обязательный параметр — идентификатор приложения.
- `option` ( `object`) — опции блока с виджетом. Может содержать поля:

- `mode` ( `integer`) — тип виджета. Возможные значения:

- `1` — карточка (обложка, название, жанр, число участников и кнопка «Играть»), по умолчанию;

- `2` — участники (дополнительно показываются аватары участников-друзей пользователя, если есть);
- `3` — кнопка (только кнопка). Для приложений сообществ (с URL в формате `app123456_-654321` доступен только этот режим).
- `height` ( `integer`) — высота кнопки (для `mode = 3`).

## Пример

```html
<script type="text/javascript" src="//vk.ru/js/api/openapi.js?149"></script>
<span class="wk_comment"> VK Widget </span>
<div id="vk_app_5327745"></div>
<script type="text/javascript">
    VK.Widgets.App('vk_app_5327745', 5327745, {"mode":3});
</script>
```
