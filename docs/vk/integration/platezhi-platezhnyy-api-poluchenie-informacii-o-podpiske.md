# Получение информации о подписке

**Раздел:** Интеграция → Платежи → Платёжный API → Получение информации о подписке  
**Источник:** документация VK для разработчиков (dev.vk.com)

---

## Получение информации о подписке (get_subscription)

ВКонтакте отправляет уведомление `get_subscription` серверу приложения (игры или мини- приложения) перед показом диалогового окна покупки [подписки](https://dev.vk.ru/ru/api/payments/subscriptions/vk). Сервер в своём ответе должен предоставить информацию о подписке, которая будет отображена в окне покупки.

## Уведомление

Данные приходят в теле запроса в виде строки, содержащей пары `параметр=значение`. Пары разделены символами `&`.

### Пример

```
app_id=1524456&item=subscription_item_1&lang=ru_RU&notification_type=get_item_
test&order_id=104659&receiver_id=1&user_id=1&version=5.132&sig=b5aec4bdc12340a
f74a83796ee357cd3
```

### Параметры

**Параметр | Тип | Описание**

`app_id` `integer` Идентификатор приложения, в котором происходит действие с подпиской.

Значение должно совпадать с идентификатором, который отображается в [настройках приложения](https://dev.vk.ru/ru/mini-apps/management/settings#%D0%9D%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8).

`item` `string` Идентификатор подписки, который используется в вашем приложении и который оно передало событию

[`VKWebAppShowSubscriptionBox`](https://dev.vk.ru/ru/bridge/VKWebAppShowSubscriptionBox) библиотеки VK Bridge. [Пример вызова события](https://dev.vk.ru/ru/api/payments/subscriptions#%D0%A8%D0%B0%D0%B3%203.%20%D0%92%D1%8B%D0%B7%D0%BE%D0%B2%D0%B8%D1%82%D0%B5%20%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D0%B5%20VK%20Bridge%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D0%B0%20%D0%BE%D0%BA%D0%BD%D0%B0%20%D0%BF%D0%BE%D0%BA%D1%83%D0%BF%D0%BA%D0%B8).

`lang` `string` Язык пользователя, создавшего заказ. Возможно одно из следующих значений:
- `ru_RU` — русский
- `uk_UA` — украинский
- `be_BY` — белорусский
- `en_US` — английский.

Ваш сервер может проверять значение этого параметра, чтобы [возвращать описание товара на языке пользователя](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%BA%D0%B0%20%D0%BC%D0%BD%D0%BE%D0%B3%D0%BE%D1%8F%D0%B7%D1%8B%D1%87%D0%BD%D1%8B%D1%85%20%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D1%84%D0%B5%D0%B9%D1%81%D0%BE%D0%B2).

`notification_type` `string` Тип уведомления. В рабочем режиме прохождения платежей параметр равен `get_subscription`, в [тестовом](https://dev.vk.ru/ru/api/payments/testing) —

`get_subscription_test`.

`order_id` `integer` Идентификатор заказа в системе платежей ВКонтакте.

**Параметр | Тип | Описание**

`receiver_id` `integer` Идентификатор пользователя, который получит заказ. В данный момент совпадает с `user_id`, но в будущем может отличаться.

`user_id` `integer` Идентификатор пользователя, создавшего заказ.

`version` `string` Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе Платежи в поле [Версия API](https://dev.vk.ru/ru/api/payments/subscriptions#%D0%A8%D0%B0%D0%B3%202.%20%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20%D0%B0%D0%B4%D1%80%D0%B5%D1%81%20%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D0%BE%D0%B3%D0%BE%20%D0%B2%D1%8B%D0%B7%D0%BE%D0%B2%D0%B0%20%D0%B2%20%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0%D1%85%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F).

Параметр используется только для версии `5.132` и более поздних.

`sig` `string` Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D0%BE%D0%B2) [и её проверке](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D0%BE%D0%B2).

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A0%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%20%D1%81%D0%BE%20%D1%81%D1%82%D1%80%D0%BE%D0%BA%D0%BE%D0%B2%D1%8B%D0%BC%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%BC%D0%B8) перед обработкой.

## Ответ сервера

По идентификатору подписки, указанному в параметре запроса `item`, сервер должен вернуть информацию о подписке. Если запрашиваемая подписка отсутствует, надо вернуть ошибку с [кодом](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9A%D0%BE%D0%B4%D1%8B%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA)

[`20`](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9A%D0%BE%D0%B4%D1%8B%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) («Товара не существует»).

### Пример ответа

```json
{
  "response": {
    "item_id": "subscription_id_1",
    "title":"+2 радиус обзора (на месяц)",
    "photo_url":"http://my-app.example.com/sale-item-images/subscription-
1.png",
    "price": 24,
    "period": 7,
    "trial_duration": 3,
    "expiration": 3600
  }
}
```

### Поля

**Поле | Тип | Описание**

`item_id` `string` Идентификатор подписки, используемый в вашем приложении. Передайте то же значение, которое было получено в параметре

`item` уведомления.

| `title` обязательное | `string` Название подписки. В названии можно указать период подписки. |
|---|---|

Максимально допустимая длина `title` — 48 символов.

`description` `string` Описание подписки.

`photo_url` `string` Полный URL изображения подписки (включая адрес сервера и протокол). Рекомендуемый размер изображения — 75×75 px.

| `period` обязательное | `integer` Период действия подписки в днях. Используйте одно из следующих значений: - `7` - `30` - `90` |
|---|---|
| `price` обязательное | `integer` Стоимость подписки за указанный период в [голосах ВКонтакте](https://dev.vk.ru/ru/mini-apps/glossary#%D0%93%D0%BE%D0%BB%D0%BE%D1%81). |

`trial_duration` `integer` Длительность бесплатного пробного периода в днях. Используйте одно из следующих значений:
- `3`
- `7`
- `30`

`expiration` `integer` Временной период, в течение которого платформа будет хранить информацию о подписке в кеше. Период указывается в секундах. Допустимый диапазон — от `600` до `604800`. Если значение меньше нижней или больше верхней границы, то будет установлено минимальное или максимальное значение. `0` означает отказ от кеширования.

Совет. Мы рекомендуем всегда использовать [кеширование](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%9A%D0%B5%D1%88%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%B8%D0%BD%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%86%D0%B8%D0%B8%20%D0%BE%20%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0%D1%85%20%D0%B8%20%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D0%BA%D0%B0%D1%85). Это ускоряет процесс покупки для пользователей, а также уменьшает количество обращений к серверу приложения. Пока информация о подписке хранится в кеше, ВКонтакте использует данные из кеша и не отсылает уведомления `get_subscription` серверу.

Поля `title`, `price`, `period` должны обязательно присутствовать в ответе вашего сервера. Иначе подписка не будет оформлена.

Значения в полях ответа можно изменять в зависимости от языка пользователя, указанного в параметре `lang` запроса. То есть для одного и того же идентификатора подписки можно возвращать разные названия и изображения в зависимости от языка.

Данные для разных языков пользователя кешируются отдельно друг от друга.

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:

```json
{
  "error": {
    "error_code": 1,
    "error_msg": "Ошибка обновления информации на сервере. Попробуйте ещё раз
позже.",
    "critical": true
  }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](https://dev.vk.ru/ru/api/payments/notifications/vk#%D0%A4%D0%BE%D1%80%D0%BC%D0%B0%D1%82%20%D0%BE%D1%82%D0%B2%D0%B5%D1%82%D0%B0%20%D0%BF%D1%80%D0%B8%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B5).
