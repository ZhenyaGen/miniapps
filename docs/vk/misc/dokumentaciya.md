### [Типы приложений](https://dev.vk.ru/ru/general/app-types)

## Создание приложений

### [Мини-приложения](https://dev.vk.ru/ru/mini-apps/overview)

Создавайте полезные сервисы на каждый день с помощью кросс-платформенных приложений на базе веб-технологий: HTML, JavaScript, CSS.

### [Игры](https://dev.vk.ru/ru/games/overview)

Увлекайте миллионы игроков своими идеями. Ни паролей, ни скачиваний — игры мгновенно запускаются прямо из интерфейса ВКонтакте.

### [VK Bridge](https://dev.vk.ru/ru/bridge/overview)

Используйте API ВКонтакте и API операционной системы, установленной на устройстве пользователя, с помощью одной библиотеки.

## Бизнес-инструменты

### [VK Pay](https://dev.vk.ru/ru/pay/getting-started)

Принимайте оплату за товары и услуги — прямо в чатах, сообществах и мини-приложениях, с баланса VK Кошелька или банковских карт, привязанных к аккаунту VK ID.

### [VK Донат](https://dev.vk.ru/ru/api/donut/getting-started)

Управляйте платной подпиской и разнообразными программами лояльности в сообществе.

### [Рекламный API](https://dev.vk.ru/ru/api/ads/getting-started)

Автоматически запускайте объявления и целые рекламные кампании, обновляйте аудитории ретаргетинга и получайте статистику.

### [VK ID Captcha](https://dev.vk.ru/ru/vkcaptcha/overview)

Подключите VK ID Captcha SDK, чтобы определять, кем является пользователь вашего сервиса: человеком или компьютером.

## Интеграция контента

### [Виджеты для сайтов](https://dev.vk.ru/ru/widgets/overview)

Предоставьте посетителям сайта возможность авторизовываться через ВКонтакте, добавлять комментарии и плейлисты, общаться в сообщениях.

### [Публикации ВКонтакте](https://dev.vk.ru/ru/api/posts)

Предложите пользователям делиться ВКонтакте статьями или комментариями с вашего сайта или из приложения.

### [Маски](https://dev.vk.ru/ru/masks/overview)

Создавайте маски — развивайте персональный бренд, заявляйте о себе и привлекайте подписчиков на личную страницу или в сообщество.

### [Чат-боты](https://dev.vk.ru/ru/api/bots/getting-started)

Автоматизируйте рутинные и похожие задачи с помощью чат-бота ВКонтакте.
