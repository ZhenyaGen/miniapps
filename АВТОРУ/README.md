# Автору

Рабочие материалы проекта: что публиковать, что говорить, что и когда
продавать. Всё, что не нужно ни пользователю приложения, ни тому, кто
будет разбираться в коде.

| Файл | Когда открывать |
|---|---|
| [ПЛАН-ЗАПУСКА.md](ПЛАН-ЗАПУСКА.md) | раскатка по этапам: тестировщики → каталог → первые сто человек → деньги |
| [ТЕКСТЫ-ПОСТОВ.md](ТЕКСТЫ-ПОСТОВ.md) | пять готовых постов на стену, от анонса до перевода в услугу |
| [СТОРИС-И-ОТЗЫВЫ.md](СТОРИС-И-ОТЗЫВЫ.md) | две серии сторис с подписями, счётчик посещений, куда складывать отзывы |
| [ТЕКСТЫ-ДЛЯ-КАТАЛОГА.md](ТЕКСТЫ-ДЛЯ-КАТАЛОГА.md) | название, описание и все картинки для карточки приложения |
| [ОБЛОЖКА-И-КАТАЛОГ.md](ОБЛОЖКА-И-КАТАЛОГ.md) | требования ВК к изображениям и что смотрит модерация |
| [АНКЕТА-ОБРАТНОЙ-СВЯЗИ.md](АНКЕТА-ОБРАТНОЙ-СВЯЗИ.md) | вопросы обеих форм и как читать ответы |

Картинки ко всему этому — в `apps/vk-audit/docs/brand/`:
иконки и обложки каталога, две серии сторис, обложки анкет, скриншоты
приложения. Пересобираются скриптами из `scripts/brand/`.

Инструкция для пользователей лежит отдельно, в корне —
[КАК-ПОЛЬЗОВАТЬСЯ.md](../КАК-ПОЛЬЗОВАТЬСЯ.md): её вы публикуете,
а не читаете.

---

**Папка — не сейф.** Репозиторий публичный, так что цены, план продаж
и заготовки постов видит любой, кто сюда заглянет. Ничего страшного
в этом нет — это материалы, а не секреты, — но помните об этом,
когда будете дописывать сюда что-то личное: договорённости с клиентами,
суммы по конкретным сделкам, чужие контакты. Такому здесь не место.
