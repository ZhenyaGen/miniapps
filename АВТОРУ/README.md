# Автору

Всё, что не код: как запустить, что публиковать, что говорить, что и
когда продавать, чем защищено авторство. В корне репозитория остался
только сам проект.

## Для пользователей

[КАК-ПОЛЬЗОВАТЬСЯ.md](КАК-ПОЛЬЗОВАТЬСЯ.md) — единственный документ
отсюда, который вы **публикуете**, а не читаете: разбор приложения
по экранам, на примере личной страницы.

---

Картинки ко всему этому — в `../apps/vk-audit/docs/brand/`: иконки
и обложки каталога, две серии сторис, обложки анкет, скриншоты
приложения. Пересобираются скриптами из `../scripts/brand/`.

**Папка — не сейф.** Репозиторий публичный, так что цены, план продаж
и заготовки постов видит любой, кто сюда заглянет. Ничего страшного
в этом нет — это материалы, а не секреты, — но помните об этом,
когда будете дописывать сюда что-то личное: договорённости с клиентами,
суммы по конкретным сделкам, чужие контакты. Такому здесь не место.
