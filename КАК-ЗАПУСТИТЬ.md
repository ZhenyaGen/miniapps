# Как запустить за 10 минут

Самый короткий путь: **без терминала, без установки программ**. Если что-то
не сходится — смотрите [что могло пойти не так](#что-могло-пойти-не-так)
в конце.

---

## Сначала — главное

Мини-приложение это **сайт**, а не программа. Его нельзя «установить»
и нельзя открыть двойным кликом по файлу: браузер запрещает страницам
с диска подгружать свои же файлы, поэтому получается пустой экран.

Работает оно только по веб-адресу. Значит порядок такой:

```
файлы  →  выложить в интернет  →  получить адрес  →  сказать этот адрес ВКонтакте
```

Всего три шага. Ниже они по пунктам.

---

## Шаг 1. Взять файлы

Скачайте архив `vk-audit-app.zip` (я присылал его в переписке) и **распакуйте**
в любую папку. Внутри должно лежать:

```
index.html
assets/
favicon.svg
```

> Если скачивали архив всего репозитория с GitHub — там **исходники**,
> а не готовое приложение. Из них приложение нужно сначала собрать,
> и без установки Node.js это не сработает. Проще взять готовый архив.

**Не открывайте `index.html` двойным кликом.** Вы увидите страницу
с объяснением — это нормально, так и задумано. Идём дальше.

---

## Шаг 2. Выложить в интернет

Бесплатно и без регистрации:

1. Откройте [**app.netlify.com/drop**](https://app.netlify.com/drop)
2. Перетащите мышью **всю распакованную папку** прямо на страницу
3. Подождите 10–20 секунд

Netlify покажет адрес вида:

```
https://willowy-narwhal-4a2b1c.netlify.app
```

**Скопируйте его.** Это и есть адрес вашего приложения.

Откройте этот адрес в браузере — приложение должно открыться и показать
экран «Аудит страницы ВК». Нажмите **«Открыть демо-отчёт»**: если отчёт
показался, значит всё работает.

> Вход через ВКонтакте на этом адресе ещё не заработает — приложение должно
> быть открыто **внутри** ВК. Это следующий шаг.

---

## Шаг 3. Сказать адрес ВКонтакте

1. Откройте [dev.vk.ru](https://dev.vk.ru/) → ваше приложение (**54693601**)
   → **Настройки**
2. Заполните два поля адресом из шага 2:

   | Поле | Что вписать |
   |---|---|
   | Адрес приложения | `https://willowy-narwhal-4a2b1c.netlify.app` |
   | Адрес для мобильных | тот же самый |

3. Заодно в поле **Доверенный redirect URI** впишите:

   ```
   http://localhost:8910/callback
   ```

   Это для десктопной версии — чтобы она работала на том же приложении.

4. Сохраните.

---

## Шаг 4. Открыть

Перейдите по адресу:

```
https://vk.com/app54693601
```

Приложение откроется внутри ВКонтакте. Нажмите **«Войти»** — ВК спросит
разрешение на доступ к сообществам и статистике. После этого появится список
ваших сообществ: нажимаете любое и получаете аудит.

Готово.

## Что могло пойти не так

**Открыл `index.html`, вижу текст «Файл открыт напрямую с диска».**
Всё правильно, так и должно быть. Файлы нужно выложить (шаг 2), а не
открывать с диска.

**Открыл `index.html`, вижу пустой белый экран.**
То же самое, но архив старый — в новом вместо белого экрана подсказка.
Идите к шагу 2.

**Скачал репозиторий, открываю — ничего не работает.**
В репозитории лежат исходники: набор файлов, из которых приложение собирается.
Возьмите готовый архив из переписки либо соберите сами — для этого нужен
Node.js и две команды (`npm install`, `npm run build`), подробности
в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

**Приложение открылось, но кнопка «Войти» ничего не делает.**
Вы открыли приложение по прямому адресу (`…netlify.app`), а не внутри ВК.
Вход работает только на `vk.com/app54693601` — ВКонтакте передаёт приложению
данные о пользователе, когда открывает его сам.

**В ВК открывается пустая рамка или «Приложение недоступно».**
Адрес в настройках приложения не совпадает с тем, где лежат файлы. Проверьте,
что в поле «Адрес приложения» стоит ровно тот адрес, который выдал Netlify,
вместе с `https://`.

**Демо-отчёт открывается, а реальная страница — нет.**
Проверьте, что сообщество открытое. Закрытые сообщества и удалённые страницы
ВК не отдаёт никому, кроме участников.

**Хочу свой адрес вместо `willowy-narwhal.netlify.app`.**
Нужен домен, 200–300 ₽ в год. Как привязать — в
[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md#сколько-стоит-и-где-это-брать).
