Файл открыт напрямую с диска

Так приложение не заработает: браузер запрещает страницам с диска загружать свои же файлы. Нужен веб-адрес — любой из трёх:

  1. Выложить за минуту. Перетащите папку целиком на app.netlify.com/drop — получите адрес вида https://…netlify.app.
  2. Открыть внутри ВКонтакте. Адрес из первого пункта впишите в настройки приложения на dev.vk.ru и откройте vk.com/app… — так работают вход и сбор данных.
  3. Запустить у себя. В папке с исходниками: npm install, затем npm run dev, и открыть http://localhost:8910.

Подробности — файл ИНСТРУКЦИЯ.md в репозитории.
