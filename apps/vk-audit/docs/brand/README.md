### Экран запуска

Его видно, пока приложение не отправило `VKWebAppInit`. Загружается
`ekran-zapuska.json`, **флажок «Анимация» обязателен** — без него ВК
покажет первый кадр и остановится.

Рядом задаётся HEX фонового цвета. Подойдёт белый `#FFFFFF`: сама
плитка цветная, и на белом она читается как иконка приложения,
а не как пятно.

Ограничения ВК: 96×96, файл до 24 Кбайт. Текущий — 5 КБ.

Анимация нарочно собрана из того, что понимают все три библиотеки
(Android — `lottie-android`, iOS — `rlottie`, сайт — `lottie-web`):
шейповые слои, градиент с анимацией точек, trim path. Ни масок,
ни матовых слоёв, ни 3D — на Android 3D в этих экранах не работает.

`ekran-zapuska-kadry.png` — раскладка восьми кадров, чтобы посмотреть
на анимацию, не заливая файл на сторонний сайт.

## Пересобрать

```bash
npm install                                   # playwright и lottie-web

npm --prefix apps/vk-audit run build          # скриншоты снимаются с живой сборки
node scripts/brand/screens.mjs                # каталог 1080×1920 + веб 540×960
node scripts/brand/story-guide.mjs            # сторис-инструкция из этих кадров

node scripts/brand/render.mjs                 # иконки, обложка, сниппет, сторис
node scripts/brand/splash-lottie.mjs          # экран запуска
node scripts/brand/lottie-preview.mjs         # и раскладка его кадров
node scripts/brand/donut.mjs                  # обложки уровней доната
```

Порядок важен для первых трёх: сторис-инструкция берёт готовые
скриншоты, а те снимаются с собранного приложения. Изменили интерфейс —
прогоняйте всю тройку, иначе кадры разойдутся с тем, что человек
увидит на самом деле.

Веб-версии скриншотов уезжают не сюда, а в `apps/vk-audit/public/screens`:
их показывает вкладка «Инструкция» внутри приложения.
