# CLAUDE.md

## apps/vk-audit

Мини-приложение «Аудит страницы ВК». `src/engine/` — порт движка из десктопной
программы vk-audit (репозиторий `presentation`, ветка
`claude/vk-audit-android-apk`, пакет `vk_audit`). Числа и формулировки в exe,
APK и мини-аппе должны совпадать, поэтому:

- движок держим чистым TS: без React, без VK Bridge, без обращений к сети;
- любое изменение правил или метрик — сначала в питоновской версии, потом здесь;
- `npm test` в `apps/vk-audit` сверяет расчёт с эталонами `demo-golden.json`
  (метрики, зоны роста, план) и `demo-rivals.json` (сравнение с конкурентами).
  Если тест упал, разошлись версии — это не повод править эталон.

Ключи доступа в бандл не кладём: он распаковывается. `VITE_VK_APP_ID` — не
секрет, это ID приложения. Адрес возврата `http://localhost:8910/callback`
зашит в `src/oauth.ts` и общий с десктопной версией.

Модули сбора (`src/vk/`) не должны зависеть от `src/config.ts`: его читает
и бот, а `import.meta.env` в Node не существует. Общие константы — в
`src/vk/defaults.ts`.

Расчёты, которых нет в питоновской версии, в `src/engine/` не кладём —
иначе эталоны перестанут сходиться. Для них отдельные папки: `src/video/`
(ролики, клипы и комментарии), `src/photos/` (фотографии), `src/report/`
(бриф для ИИ, профиль контента, «чего нет»), `src/vk/niche.ts`
(ниша страницы). Они читают данные движка, но его чисел не пересчитывают.

Вкладка «Видео» считает только обычные ролики, «Клипы» — только клипы:
охват у них из разных лент, и общая медиана врёт. Разделение живёт
в `analyzeVideos`, которая сама отбрасывает клипы, — не дублируйте
фильтр в интерфейсе.

Выводы по формату, которого почти нет, не делаем: `src/report/mix.ts`
считает профиль страницы (клипы/видео/фото/текст) и помечает форматы,
где единиц меньше `MIN_SAMPLE`. Новые разделы должны эту пометку
уважать — иначе на трёх клипах приложение начнёт вещать про тренды.

`node scripts/smoke.mjs` открывает собранное приложение в браузере,
обходит все вкладки и проверяет консоль: юнит-тесты рантайм не ловят.

Скачивание файлов внутри приложения ВКонтакте не работает: `link.click()`
там молча ничего не делает и ошибку не бросает, так что «сохранено»
показать честно нельзя. Выгрузки поэтому нет — весь отчёт уходит текстом
через `VKWebAppCopyText`. Возвращать сохранение только вместе со способом
проверить, что файл действительно уехал.

## apps/vk-bot

Бот сообщества с разборами в личных сообщениях. Движок импортирует из
`apps/vk-audit/src/engine` — не копируем, иначе цифры в личке разойдутся
с отчётом. DeepSeek только пересказывает готовые числа: системный промпт
запрещает считать и выдумывать метрики.

Ключи (`VK_GROUP_TOKEN`, `VK_SERVICE_TOKEN`, `VK_LLM_KEY`) — только из
окружения. Стены читаются сервисным ключом: ключу сообщества `wall.get`
недоступен (ошибка 27).

## База знаний по VK Mini Apps

`docs/vk/` — офлайн-копия документации dev.vk.ru (499 страниц Markdown).
Перед тем как отвечать на вопросы по платформе ВКонтакте или писать код под
неё, ищи ответ здесь, а не по памяти: события VK Bridge, параметры запуска,
права доступа и лимиты API часто отличаются от того, что кажется очевидным.

Точки входа:

- `docs/vk/README.md` — навигация по всем разделам;
- `docs/vk/vk-bridge/EVENTS.md` — все 96 событий `VKWebApp*` с описанием;
- `docs/vk/index.json` — машиночитаемый индекс (`category`, `title`,
  `breadcrumb`, `path`), удобно для грепа по хлебным крошкам.

Поиск: `grep -ril "VKWebAppGetLaunchParams" docs/vk`.

Страницы — конвертация PDF-экспорта, поэтому вёрстка местами приблизительная
(склеенные ячейки таблиц, потерянные картинки). Ссылки на оригинальные
страницы `dev.vk.ru` внутри текста сохранены — при сомнениях сверяйся с ними.
Документы не редактируем вручную: они пересобираются скриптами из
`tools/vk-docs/`.
