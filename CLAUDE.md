# CLAUDE.md

## apps/vk-audit

Мини-приложение «Аудит страницы ВК». `src/engine/` — порт движка из десктопной
программы vk-audit (репозиторий `presentation`, ветка
`claude/vk-audit-android-apk`, пакет `vk_audit`). Числа и формулировки в exe,
APK и мини-аппе должны совпадать, поэтому:

- движок держим чистым TS: без React, без VK Bridge, без обращений к сети;
- любое изменение правил или метрик — сначала в питоновской версии, потом здесь;
- `npm test` в `apps/vk-audit` сверяет расчёт с эталоном `demo-golden.json`.
  Если тест упал, разошлись версии — это не повод править эталон.

Ключи доступа в бандл не кладём: он распаковывается. `VITE_VK_APP_ID` — не
секрет, это ID приложения. Адрес возврата `http://localhost:8910/callback`
зашит в `src/oauth.ts` и общий с десктопной версией.

## База знаний по VK Mini Apps

`docs/vk/` — офлайн-копия документации dev.vk.ru (499 страниц Markdown).
Перед тем как отвечать на вопросы по платформе ВКонтакте или писать код под
неё, ищи ответ здесь, а не по памяти: события VK Bridge, параметры запуска,
права доступа и лимиты API часто отличаются от того, что кажется очевидным.

Точки входа:

- `docs/vk/README.md` — навигация по всем разделам;
- `docs/vk/vk-bridge/EVENTS.md` — все 96 событий `VKWebApp*` с описанием;
- `docs/vk/index.json` — машиночитаемый индекс (`category`, `title`,
  `breadcrumb`, `path`), удобно для грепа по хлебным крошкам.

Поиск: `grep -ril "VKWebAppGetLaunchParams" docs/vk`.

Страницы — конвертация PDF-экспорта, поэтому вёрстка местами приблизительная
(склеенные ячейки таблиц, потерянные картинки). Ссылки на оригинальные
страницы `dev.vk.ru` внутри текста сохранены — при сомнениях сверяйся с ними.
Документы не редактируем вручную: они пересобираются скриптами из
`tools/vk-docs/`.
